# 碑纹跳切　文案习惯（humanize 0.9）

书写习惯是站点的，不是人物标签。改口、漏字段、重复嘱咐都留着。不灌水，不加金句。

| 站点 | 习惯 | 怎么写 |
|---|---|---|
| 值班条 `introduction.html` | B 冷陈述体 | 人、单子、第一张拓、可点浅磨。不抒情。 |
| 数字化台 `desk/*` | B + 台内短句 | 翁苔复述字段、改口。路值短讯。空查找也用台内话。 |
| 拓片/志石库 `rub/*` `zhi/*` | D 史笔半文 | 著录、能证/不能证。不把刀口写成鬼。 |
| 所站 `gov/*` | B 公文 | 须知、样张、同形旧备注。短，不解释心情。 |
| 赤土石作 `shop/*` | B 回单体 | 工种、颜料、不接磨字。石满字丑、不解释。 |
| 纪氏房头 `family/*` | A 絮叨漏白 | 柏舟改口，怕清明，求别投旧名。 |
| 贺纸庭 `he/*` | H 回忆缠绵 | 纸潮、页边墨、刀口没敢动。时间来回。 |
| 分类/浦阴 `yellow/*` `nei/*` | E 短帖拼贴 | 黄页一行、卖家改价、邻县刹车。 |

## 声口对照（防同声）

- 翁苔：复述，改口，不敢发明手续。  
- 路值：短，甩九点，嫌烦。  
- 贺纸庭：慢，写纸边，不认闻山那年有过。  
- 石满：回单冷，旧有本工不修。  
- 纪柏舟：絮叨，改口，怕墙上出现他解释不了的字。  

## 结局动态

`desk/result-*.html` 的理由段读 `beiwen-tiaqie-v1` 的 `seen`：见过旧拓浅磨、见过匣、见过房头，各走不同句子。判定与交单三选对齐：recarve / same / approve。

## 未采用

不用开棺现场感官，不用磨碑口诀，不用全员「综上所述」。屏上不用机制标本词。
