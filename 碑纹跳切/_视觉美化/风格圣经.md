# 碑纹跳切　风格圣经　polish-20260823

相机锁死：正视 2D 网页平面。无透视、无一层视差、无 Canvas 粒子、无胶片条、无监视器框。中英同一相机。拓片是纸上的扫描件，不是可旋转谜盒。

比例：拓片图随栏宽缩放；热区百分比坐标锁死（本轮不改 inline 百分数）。命中盒 CSS `min-width/min-height: 44px`。卷宗栏宽沿用 `archive-simsun` 的 `min(800px, 92%)`。值班台 `#wrap` 960。红头 1000 table。石作 778 table。房头 677。博客 780 双栏。黄页 960。

线宽 1x：1px。首跳教学框 = 朱红虚线；quiet 可检物件 = 墨色点线 + 四角裁切短线。禁止 8px 圆角白卡、禁止任务宝石/感叹号 HUD。

主材质 `material_id=rubbing-paper-night-desk`：卷宗是仿古拓纸（米黄纤维底）；夜班台是 2010 浅青局域网值班桌（层压台面，不是 Bootstrap 卡）；引言是油印值班条（方角纸块）。所有者皮仍分家，不合成一张现代壳。

光：顶光、无动态光。强调色只绑功能（首跳教学、交单警告、焦点点框、回单形状），不绑情绪，不给正解三选上色。
