# 风格圣经 · 七晚驾驶座 · 2D VP1

相机：驾驶座正视挡风玻璃，锁死。无轨道、无视差、无 3D 旋转。手机框即驾驶舱视口。
比例：舱体 > 路单条 > 人像/静帧 > 压单钮。人像服从舱，不抢「压这一单」。
线宽：1px 仪表细线；2px 油印纸边；3px 后视镜框；选中来源 2px 内框 + 文字「已选」，不是准星。
主材质：雨夜挡风玻璃 + 仪表乙烯 + 油印米纸（客）。
三色锚：舱黑 `#07090c` / 米纸 `#efe4c8` / 强调 `#e0a24a`（只绑已选来源与份子，不绑情绪）。

不读字应先看见：方向盘/仪表、雨挡风、后视镜框、左上油印纸条、HUD 纸片「守则」、米纸「油钱」信封。

载 / 拒 / 送到门口 不得出现在标题层（由 JS 隐藏 panel，CSS 不补这些钮）。

所有者壳差（纸色 / 字号或字栈 / 页边或外形，至少三项）：

1. fleet 油印：米纸底、宋体、宽行距、右上红圆印「河西客运」。
2. visor 塑料板：黄褐梯形切角、等宽短句、深褐双边。
3. paper 折叠纸：横线练习本、楷体、虚线边、微倾。
4. radio 电文：黑底绿字、Courier、发光细边。
5. 铅笔注：楷体灰、虚线下划，不是红印。
6. 新墨：正文加黑、左粗条、「墨是新的」黑底纸字徽章。
7. 贴条：黄便签顶边加厚。

9. 窗口小卖：班后荧光绿柜台、双线标题、价签格；不是车内，不是货架墙。
