# 同窗在线

封闭世界仿网页调查。请先读上级目录 `怎么玩.txt`。必须用本地 http 打开本 `工程` 目录（例如 `python3 -m http.server`），不要用 `file://`，否则跨页搜索和存档会坏。

你是八十年代生人。多年未见的同学发来一个像当年校园实名站的网址。蓝条、新鲜事、最近来访都还在，站名却写成「同窗在线」。读页、抽出一个汉字词、用顶栏搜索，把跨越三代人的账核对清楚，最后决定应不应到。

## 人人网式玩法（结构记忆，不用商标）

本作用皮肤 `campus-sns-2010` 复原 2010 前后校园实名站的**构建方式**，不使用人人/校内的商标、吉祥物或官方切图。

| 原站功能 | 游戏里怎么用 |
|---|---|
| 蓝条顶栏 + 搜索 | 主循环：一次只搜一个汉字词 |
| 三栏布局（左导航 / 新鲜事 / 来访） | 公开壳，第一证据写在新鲜事里 |
| 个人主页 / 相册 / 留言板 | 隐藏页，换模块墙皮肤 |
| 日志 | 橙色个人博客，给出店名与学徒真名 |
| 礼物 | 附带页，印证进门口令 |
| 最近来访 | 把「谁来过」做成可搜栏目，死人仍在跳 |
| 班级公共主页 | 内嵌浅青后台，须知 + 登录 + 公约 |
| 应用中心（农场、车位、礼物商城） | **假入口**，暂停，不是主线 |
| 找人（按学校、入学年） | 接口已停，逼你改用顶栏搜词 |
| 站内信 | 登录后可读，不能外发 |

主循环只有一条：`读页 → 抽出一个汉字词 → 顶栏搜索 → 打开新来源`。没有物品栏、没有实时追逐。

## 局中局中局

- **表层**：老同学找你叙旧，镜像还活着。
- **中层**：站点是纸人祠堂。来访被写成香火。已故账号仍在发言。
- **里层**：你不是客人。1986 年阴册附录把江晚晴写成备用。点开链接等于被叫到场。

三代人：沈连山（1959 补数字）→ 沈秀兰 / 林昭弟（1987 应声与过继）→ 沈亦舟把班级页接上网，并把你写成备用。

两个结局都要先读完备用、香火、陈小北已死、第一代、过继的孩子，再在选择页提交：

1. **不应到**：注销备用，纸人停跳。
2. **接香**：你成为第四代管理员。

## 怎么玩

1. 打开 `index.html`，读说明，记住第一词 **纸马课**。
2. 进入首页新鲜事。顶栏一次只搜一个汉字词。
3. 应用中心是假入口。真入口在正文专名。
4. 卡关时去「帮助」向停运客服要提示（四档，第四档写推理，仍要你自己搜）。
5. 页脚 `N/36` 不是进度条，点不动。
6. 键盘 `/` 聚焦搜索。本机 `localStorage` 存档。

可解性自检：给任意页面加上 `?test=1`，例如 `index.html?test=1`。
