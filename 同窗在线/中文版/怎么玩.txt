《同窗在线》上线说明（网页解密，校园站多页壳）

【入口】
工程/index.html

务必先在「工程」目录开本地 http，不要用 file://。
macOS / Linux 示例（在「工程」目录里执行）：

  python3 -m http.server 8000

然后浏览器打开：http://127.0.0.1:8000/

Windows 可用同样命令，或 `py -m http.server 8000`。

file:// 下跨页搜索和 localStorage 存档会丢或串档。这不是可选提示。

也可以打开本目录「上线版/index.html」（仍要先对「工程」目录起服务器，再访问上线版对应的相对跳转，或直接开上面的 8000 端口）。

【主循环】
对齐《大学生登山失踪事件》的结构（借循环，不借皮、不借剧情）：
读页 → 抽出一个汉字词 → 顶栏搜索 → 打开隐藏页。
第一词：纸马课（写在说明页和首页新鲜事里）。
应用中心是假入口，暂停，不是关卡。必须对「工程」开 `python3 -m http.server`，不要用 file://。

【试玩】
UNTESTED。本轮只做代码/结构自检，未做完整浏览器盲测。

【要不要本地服务器】
要。多页 HTML + 本机存档，必须 http。

【卡了先搜】
卡在开局：纸马课。
再卡：回到已经打开的日志、作坊页、公约里抽专名，一次只搜一个词。
登录空串不会当万能钥匙。禁止页不是答案，回首页再搜。
帮助中心的停运客服有四档提示，第四档仍要你自己搜。

【刷新】
存档在本机 localStorage。用 http 打开时，刷新应回到已解锁进度。说明页可「继续上次」或「清除存档」。

【窗口】
约 390px 时顶栏搜索仍应可点。桌面更舒服。未宣称 Mobile Friendly。
