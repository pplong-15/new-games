## 0. 结论（先看这）

主链可以走通，双结局可以到达，搜索空串 / 英文 / 空格两词 / 禁止页均有句子反馈，刷新读档不崩。**本闸不是可玩性闸。**

## 2. 逐关破绽

每条格式：关卡 / 位置 / 性质 / 建议。优先级见第 3 节。

### 第一关　文案层

元语言泄漏、装腔腔调、机械重复、该口语的书面体。

**G1-01　「本页能证明 / 不能证明」模板刷屏（材料上屏）**  
位置：`js/pages-a.js` L352 来访、L378 陈小北主页、L479 公约（「你能证明」）、L539 地方志；`js/pages-b.js` L24 水库、L209 江晚晴、L288 口述（「本篇能证明这些」）、L338 族谱。  
性质：这是设计文档的证据能力边界，不是校园站、地方志、空间会写的话。同一句式连续出现，机械重复 + 书面体。  
建议：删掉。能证明的事实改成该皮会有的东西（户口变更一句、讣告一句、店招一行），让玩家自己对，不要代做阅读理解。

**G1-02　「不是 X，是 Y」对称骨架（假揭示）**  
位置（不完全统计）：`pages-a.js` L75–76、L96、L213、L215、L241、L274、L353、L405、L529；`pages-b.js` L18、L53、L56、L130、L208、L260–261、L286–287、L313、L361、L409、L430。原文例：「克制不是温柔，是把私刑写成手续」「送的不是船，是纸」「顶栏搜索不是找人，是找词」「这不是拯救，是拒绝到场」「暂停的是游戏，不是账」。  
性质：悬疑文案里最典型的 AI 揭示腔。全站共用一张嘴。  
建议：改成事实主干。店里送的是纸、搜索框只认一个词，直接说，不要先压后扬。

**G1-03　站内正文当说明书：主线 / 解锁 / 隐藏页 / 第一词**  
位置：
- 首页 `pages-a.js` L75：「你要找的第一个词在置顶日志的标题里……一次只搜那一个词。」
- 博客侧栏 L217：「回村那晚（若你是搜课名进来的，可能一并解锁）」
- 回村 L242：「这是附带页，不是锁。主线不靠它。」
- 礼物 L323–325：「一并解锁，不卡主线」「主线仍以空间那句为准」
- 陈小北相册 L404：「本页是……附带页。主线不靠它开门」
- 周棠相册 `pages-b.js` L83：「主线不靠留言开门」
- 周棠留言 L108：「本页附带，不卡主线」
- 关站稿 L310：「本篇是附带……主线不靠它」
- 帮助 `pages-a.js` L145：「那不是主线」
- 空搜 `engine.js` L151：「空串不会打开任何隐藏页。」
- 禁止页 `pages-b.js` L227–230：「隐藏页」「禁止页不是主线唯一解」「主线词」「主线不靠黑条」
性质：元语言泄漏。假官网不会说「主线 / 解锁 / 唯一解 / 隐藏页」。  
建议：公开壳只保留站点口吻（缓存、权限、接口停了）。规则放到说明页。禁止页用 2000 年代校园站真有的「没有权限查看该内容」，不要解释关卡设计。

**G1-04　作者站在玩家身后点词**  
位置：阴册 `pages-b.js` L55：「现在先把过继、替身、你的真名和备用这些词分别搜尽。」地方志 `pages-a.js` L531：「检索时请使用条目里的手续名或水利地名。」沈记 L270、L332：「请自己决定要不要把学徒的名字送进搜索框」「只搜沈记，都会落到这一页。」空间 L403：「搜栏目名才能看见谁来过。」  
性质：把谜底做成高亮作业。  
建议：词留在像真的字段里（店招、公约第三条、来访栏目标题），不要加「请搜这个」。

**G1-05　声口被同一张「讲解员」覆盖**  
位置：几乎每页在角色发言之后都跟一段 200–400 字的解释段（首页 L75–76，找人 L96–98，校园 L121–124，帮助 L147–148，企业页 L271–275，来访 L351–353，班级新鲜事 L506–508，论坛楼主把三笔账和「两边都成立」写进一帖）。  
性质：同声引语。陈小北的短句还像人；一转第三人称就变成同一支笔在做题解。论坛楼主尤其不像 2013 年茶馆灌水。  
建议：每页只留一种嘴。角色帖到角色为止。讲解员整段删。论坛楼主缩短到三五行，别替 2 楼 3 楼做摘要。

**G1-06　书面体、金句、三段排比**  
位置：结局 A `pages-b.js` L407–411「表层的叙旧结束。中层的祠堂停香。里层的备用没有启用。」结局 B L429「表层仍像叙旧。中层仍在收香。里层换成你。」名录 L259「局分三层。」地方志 L529「克制不是温柔」。  
性质：三大味里的三段式 + 金句收尾。结局尤其像海报。  
建议：结局只写玩家做了什么、站点变成什么样。删「表层中层里层」。

**G1-07　说明页自己堆元语言**  
位置：`pages-a.js` L29–38。原文含「游戏壳」「隐藏页」「假站点不再提醒你这是游戏」「本游戏不使用它的商标」「工程目录」「file://」。  
性质：引言允许教第一词和搜索规则；不需要同时把制作语境、商标免责、进度条否定句写进同一屏。  
建议：说明页压缩成身份、第一词、一次一词、帮助里有停运客服。商标和法律放页脚小字，不要讲「本游戏」。

### 第二关　视觉层

图内或字段英文代码、过精无噪点、合成痕迹、AI 生图文字、内容与设定冲突。七张 jpg 均在实玩页上打开过。

**G2-01　纸马课合影店招乱码（AI 生图文字）**  
位置：`assets/img-album-paperhorse2009.jpg`，实玩页 `album-zt.html`。竖匾、门楣「閿楼大」一类不可读汉字，左条「德坤炳祚」亦非店铺名。  
性质：图内文字不可靠，2009 年沈湾纸扎店不该挂乱码招牌。一眼 AI。  
建议：重画或改图：去掉可辨汉字，或改成无字金漆门 + 纸马实物。不要让模型写中文招牌。

**G2-02　卫衣英文是假品牌**  
位置：`img-album-grad2007.jpg`（DUNDEE / DUNDEBOYS 一类）、`img-album-spring2010.jpg`（DILEGOS、HOME EAST、DUDEBROS 风格乱拼）。  
性质：图内英文代码。2007–2010 职高合影可以有真品牌盗版，不该是无意义拉丁拼写。  
建议：改成纯色卫衣、校服、或可辨认的当时盗版商标，不要让模型自由生成胸前字母。

**G2-03　「灰衣服无面」三张图对不上文案**  
位置：文案 `pages-a.js` L72、L402，`pages-b.js` L79–81 写「灰衣服」「没脸的影子」「同一位置灰衣」。图：2007 合影是白布罩人；2009 是门口假人；2010 是米色卫衣 + 白椭圆贴脸。  
性质：内容与设定冲突，合成痕迹（白椭圆尤其像后期遮罩而不是照片里的人）。  
建议：三张统一成「同一块砖上、灰衣、无五官」，不要白布、不要椭圆贴纸、不要换服装。

**G2-04　讣告照片不是陈小北，年代也不对**  
位置：`assets/img-album-obituary.jpg` vs `img-avatar-cxb.jpg`。头像是偏胖、浅色衬衫、彩色证件风；讣告是瘦削、中分、黑白老照相馆、五官和年龄都不像同一人，更像 1960–70 年代肖像。文案说 2014 年车祸。  
性质：人物不一致 + 服装/年代冲突。  
建议：讣告必须能认出是头像同一人（可旧一点、可黑白），不能换一张完全不同的脸。

**G2-05　周棠头像幼龄，不像 04 计同学**  
位置：`assets/img-avatar-zt.jpg`，空间页实玩可见。儿童卫衣、幼齿五官；设定是 2004 级职高同学（2007 毕业约十七八岁）。  
性质：年龄/服装与班级设定冲突。三张头像还共用同一套「旧照片斑点滤镜」，过均、过精。  
建议：换成同龄女同学证件照或空间自拍，斑点不要三张一个模子。

**G2-06　陈小北相册文案说「格子是灰的、镜像没存原图」，页上却有两张大图**  
位置：`pages-a.js` L405–406 vs 实玩 `album-cxb.html`。  
性质：文案是占位图时代留下的，配图已经接上，互相拆台。玩家一眼知道这页改过。  
建议：删「灰格子 / 没有原图 / 占位图」整段。有图就写评论，别解释制作过程。

**G2-07　字段里的英文代码**  
位置：空间 `pages-a.js` L296「正在播放：本地文件 funeral.mp3（无法解码）」；校园 L119「实习 comms 已从校园网摘除。」  
性质：英文字段名/文件名留在可见正文。2009 空间可以坏掉音乐盒，不该把仓库文件名写上去；「comms」是制作残留。  
建议：音乐盒写成「本地文件无法解码」或不显示文件名。校园句删掉 comms，改「实习通讯稿已撤」。

**G2-08　合影脸型重复、曝光均匀**  
位置：三张集体照。多人五官接近、站姿一条线、地面和天空过干净，噪点是后贴的膜。  
性质：过精 + 合成感。  
建议：能换真拼贴或强压缩、偏色、闪光灯过曝，比「加一层斑点滤镜」有效。

Frontpage、ICP 涂黑、2005 表格站本身不像破绽，保留。

跳步：说明页 L34 出现「水库」（「不要拿里面的县名、水库、人名去查现实」）。引擎对词表不做「先读后搜」检查，进站后搜「水库」可直接打开水利页，绕过继。  
建议：说明页改成「县名和人名」，不要把有效词「水库」写进去。阴册用备注栏写「替身手续」而不是「请搜替身」。

**G3-02　搜索结果标题不含所搜词，容易漏点**  
位置：搜「林昭弟」→ 标题「沈氏族谱摘」；搜「过继」→「桐溪县情网 - 沈湾村」。`snippetOf` 在无 `excerpt` 时退回标题（`engine.js` L163–171），摘要里也看不到词。  
性质：出处逻辑上闭合，反馈层不像站内搜。实玩第一次因此没点进族谱，终局按钮不出。  
建议：给这两页补 excerpt，或 resultTitle 带人名/手续名。

**G3-03　吴启明「回复(12)」没有任何楼**  
位置：`pages-a.js` L70。首页只显示状态，没有 12 条回复。  
性质：计数无对应。镜像可以「评论丢失」，但应写成「回复(12)」点不开或「评论已关闭」，现在像忘了做。  
建议：改成「回复」无数字，或给两三条残楼。

**G3-04　1847 这个数字用了两次**  
位置：博客阅读 1847（`pages-a.js` L207）；陈小北来访 1847 次（L345）。  
性质：像复制粘贴。来访可以很多，不宜与一篇日志阅读数撞同一吉利数。  
建议：来访改成别的数（例如 36、108、2011 相关）。

**G3-05　论坛楼主提前总结 2 楼 3 楼**  
位置：`pages-b.js` L132–135 楼主正文写「三楼让人去看族谱」「三楼不让人肉孩子」；2 楼 3 楼在后面才出现。楼层数本身 楼主/2/3 与「已锁定 · 2013-09」一致。  
性质：发帖时间上，楼主不该像读完整帖的主持人。  
建议：楼主只问「还阴债」；把「去看族谱」留给 3 楼自己说。

**G3-06　微信「在看」与 2016 年稿**  
位置：`pages-b.js` L165「阅读 128　在看 0」，稿日期 2016-04-02。公众号「在看」约 2017 年后。  
性质：年代小冲突。  
建议：2016 稿改成「阅读 128　赞 0」或把日期改到 2018 以后。

**G3-07　班级登录后，同窗壳仍显示「游客 / 未登录」**  
位置：实玩相册、礼物、首页侧栏。顶栏在 `access_class` 后出现「站内信」，侧栏 still 游客。inbox / 结局 B 会改成江晚晴。  
性质：两套登录态。可以解释成「班级后台 ≠ 同窗账号」，但玩家会看成串档。  
建议：登录成功后公开壳也显示江晚晴，或顶栏明确「班级页已登录（游客浏览同窗）」。

### 第四关　第四墙

不自称游戏/网页制作、不暴露「网页材料 / 本关 / 通关」。

**G4-01　全站页脚自称「虚构调查游戏」（与引言承诺直接矛盾）**  
位置：`js/engine.js` L116–126，实玩每一页底部可见。引言 `pages-a.js` L36：「点「进入同窗」之后……假站点不再提醒你这是游戏。」  
性质：第四墙打穿。这是本闸最大的硬伤。  
建议：进站后页脚只留备案腔或「镜像缓存，勿对照现实」。法律声明放说明页。「调查游戏」四字从假站点拿掉。

**G4-02　禁止页用关卡词自报身份**  
位置：`pages-b.js` L227–230。隐藏页、源码、管理员密码、禁止页、主线唯一解、主线词。  
性质：这不是 2010 校园站 403，是作者对玩家说话。  
建议：只留「你没有权限查看该内容」+ 回首页。

**G4-03　企业页 / 祠堂 / 结局直接说「游戏」**  
位置：沈记 `pages-a.js` L271「不要把本页看成游戏关卡选择」；公约 L477「来访次数不得写成游戏分数」；祠堂 `pages-b.js` L364「老站点不会装成游戏」；结局 B L431「暂停的是游戏，不是账」；口述 L291「录音不在游戏里。」  
性质：第四墙 + 制作语境。公约若保留「不要把来访当积分」可以写成班规，不必出现「游戏」二字。  
建议：全部改成站内语言（关站、应用、积分、录音已佚）。

**G4-04　终局页眉「结局一 / 终局 / 不可用进度条代替」**  
位置：`pages-b.js` L387、L406；按钮文案 L249「进入终局选择」。  
性质：通关、本关、结局上屏。  
建议：选择页做成「附录：到场」或「账号处理」；结局页不要写「结局一」「35/36」。

**G4-05　每个 HTML 的 noscript**  
位置：`gen-pages.js` L29 及全部页面：「这是一款需要启用 JavaScript 的本地网页调查游戏。」JS 开启时不可见。  
性质：关 JS 时第四墙。  
建议：改成「本镜像需要脚本才能显示缓存。」

说明页作为说明书可以承认「这是一份说明」。进站以后不能再叫游戏。

### 第五关　UI 载荷

进度/字数元数据、按钮与 aria、窄屏、页脚引导语。

**G5-01　页脚进度元数据上屏**  
位置：`engine.js` L116–126。格式「08/36 · 已打开编号页 4/36」。选择页再写「不可用进度条代替」（`pages-b.js` L387）。结局 A 页眉「35/36」。  
性质：标本允许页脚 `N/总数`；本局额外加了「已打开编号页」、又用正文否认「这不是进度条」，等于把计数器讲解了一遍。  
建议：假站点页脚最多保留一个灰色 `12/36`。删「已打开编号页」「不是进度条」「不可用进度条代替」。

**G5-02　页脚引导语露馅**  
位置：同上 + 每页「说明」链回引言。实玩相册页脚还和侧栏广告句「不开放充值」挤在一起。  
性质：引导语 + 法律句 + 游戏自称叠在社交页底，2010 人人网不会这样。  
建议：说明链只留在帮助。社交页脚用当时的备案/版权小字。

**G5-03　按钮文案是关卡词**  
位置：名录「进入终局选择」（`pages-b.js` L249）；选择页「注销账号，不应到 / 我来值班，把香接下来」尚可；帮助「向客服发送一条」可用。搜索按钮可见字是「搜索」，`label.sr-only` 是「站内搜索」（`engine.js` L141–145），一致，这项过。陈小北主页 `aria-current="page"` 打在「主页」span 上（`pages-a.js` L372），合理。  
建议：终局入口改成「打开附录」或「账号处理」，不要「终局」。

**G5-04　窄屏 390**  
实测：搜索框可见可提交（输入条约 312×14–32，按钮可见）。接香结局 `ending-b.html` `scrollWidth - innerWidth ≈ 166`，蓝条 960 布局撑出横向滚动。「桐溪二职 · 04计」把「计」折到下一行。页脚在 390 下断成「勿对照现实机构或不开放充值 / 或个人」。  
性质：窄屏可用但脏。未宣称 Mobile Friendly，仍伤第一印象。  
建议：结局 B 在 800px 以下改单栏；页脚 `word-break`；侧栏「04计」不要断字。

**G5-05　搜索框常驻上次的词（含「源码」）**  
位置：引擎把 `state.query` 填回 `#q`。禁止页、终局页眉里还顶着「源码」「班级公约」。  
性质：像调试残留。  
建议：进禁止页或结局时清空输入框。
