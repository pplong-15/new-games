## How to play

1. Open `index.html`, read the note, remember the first word **PaperHorse**.
2. Enter the home feed. One token per search. No spaces.
3. App Center is a fake door. Real doors are proper names in the body.
4. If stuck, Help → retired support (four notes; the fourth writes reasoning; you still search).
5. Footer `N/36` is not a progress bar and does not click.
6. `/` focuses search. Saves are on-machine `localStorage` under `tongchuang-online-v1-en`.

Solvability self-test: add `?test=1` to any page, e.g. `index.html?test=1`.
