# 门坎试法 · 故事

对标机制：The Forgotten City（只借「一条世界法，可撞，知识留下」）。不是登山搜隐藏页，不是死档，不是 Password Game 外网叠规则，不是腊月巡站关站，不是香单分拣队列。民俗：门槛是内外分界，忌踏坐；丧事抬棺杠不得擦门槛；同一条门槛喜丧规则相反。玩家是桐石巷改造指挥部夜岗柴渡。

---

## 第1段　设定

门槛把巷子和堂屋分开。人从巷里进堂，脚要跨过去，不能踩，不能坐，钉死、顶柜、把摄像蹲在坎上都算没规矩。抬轿、抬棺都要把杠抬高，杠擦到坎，这一趟仪礼就算脏了。

同一条门槛，喜和丧的走法相反。喜事过门，人往里进，红的可以进堂待客。丧事出棺，人往外抬，杠更不能蹭坎；未净过的丧班，不该再当喜客放进堂。口头传说「踩门槛招鬼」只是巷口骂人，本台不当结案依据。

渠西县桐石镇桐石巷在做老宅修缮。指挥部夜岗不审风水，不做法事。夜岗只干一件：把过门记下来，再交一份放行建议——建议进堂，或不进堂。批准钥匙、改门槛、改值班板上的法，都不在夜岗权限里。权威恒为建议。

值班板上有一条法，白班阙禾写的，今夜开着，不许当没看见：今夜过门一律按丧记。丧事抬棺，杠不得擦门槛。自称喜队走错门，也按丧记。忌踏、忌坐。未核清仪礼，不得建议进堂。

本台允许试记一条过门。选踩踏或擦杠，系统会打回，并留下「法被撞过」。刷新、交班预览、重开页，已证实的这条不清。最终差事必须用撞过之后留下的知识，或用记录页上已经写着的踩踏栏，不能只靠初读口头传说。

网页上能打开的，是夜岗台、指挥部对外页、堂屋钥匙室抄件、夜岗机短信、贺连舟那张喜队黄页、巷口地方帖、指挥部公共邮箱、县里那几条门槛旧俗。它们能互相对，不能证明堂屋里躺着谁，也不能让一份建议变成钥匙。

## 第2段　故事（时间线）

表面：今晚二十二点前，柴渡要把贺宅堂屋这一趟过门的放行建议交上去。门口那队自称贺连舟喜队，红布、花车名、过门路线都写得像娶亲。指挥部对外页还挂着「本周堂屋窗口只接待喜事登记」。

真相：这队是给贺守石做丧。贺晚秧怕窗口卡丧班，让贺连舟借去年连秋穗婚队的名往里挤。穆三刀在丧班帮忙，短信写杠已经擦了。顾扃的钥匙簿写的是丧，不写喜。过门记录十九点四十分已经有一格踩踏。阙禾把法写死，是因为去年那张婚车返工单——摄像坐了门槛，连秋穗的喜片整卷作废。

### 起（傍晚到刚打开页）

柴渡是夜岗。白班阙禾四点走，板还亮着。工号柴-0821 写在值班室门框内侧，进台用这个。阙禾交接只留两句：法在板上，别改板；过门能试记，打回的留下。

台面第一屏就能看见三样：人是柴渡；板上那条法；第一件可撞的过门——贺连舟队十九点十分，状态「待记」，旁边一颗试记钮。柴渡不是侦探。他今晚要交差：这队放不放行进堂。

他第一眼会信喜。黄页是红的。对外窗口写喜事。贺连舟短信也只有四个字：我们喜队。喜可进堂，这是巷里老人都会说的。若他此刻就建议放行，故事停在第一层。

### 承（先信喜事可进，把件摊开）

对外页把窗口写得很土：修缮期堂屋不对外开放参观，本周只收喜事登记，丧事改走侧门备案。门槛改造说明写：旧坎保留，坡道另开，坡道不替代仪礼上的跨。邻里投诉栏有姜篾骂施工把快递柜顶在二门坎上，跟今夜这队不是一回事。

贺连舟的黄页写渠西贺宅过门喜队，路线从巷口到堂屋正门，花车名「秋穗号」。名单上有抬杠的人。许可证扫描件借用的是去年连秋穗婚期那张临时通行条，日期改过，章是旧的。

到这一步，柴渡仍可以停在第一层：窗口只收喜，这队自称喜，放行进堂。板上的法像白班多事。他甚至可以在建议里勾「改掉值班板上的法」——系统会收，那是错路。

### 转（两层反转）

第一层被推翻：这队是丧，借了喜队的名。

穆三刀的短信短，像怕被记名：杠擦了。别记我。贺守石那头还在等抬。顾扃钥匙室抄件写今夜领匙人贺连舟，用途丧班进堂布置，归还未打勾。顾扃自己的短讯更冷：条上写丧，嘴上说喜，钥匙不换发。地方帖里贺晚秧说漏了：窗口卡丧，先顶喜队名，进了堂再换白。卜巷跟帖看见有人脚踩在正门坎上，摄像还蹲着。

贺连舟名单对不上喜。抬杠、缠麻、缺新娘名。连秋穗的名字只出现在花车和旧通行条上。连秋穗去年已经嫁走，人不在今夜这队里。

第二层更深：过门记录不是干净的。十九点四十分那一行，记录员空着，动作栏写踩踏，备注「正门坎，贺连舟队前排」。法已经被撞过一次。不是传说，是本台自己的格子。即便柴渡今晚一次试记都没做过，这格也在。他若去试记踩踏或擦杠，系统会打回，并另留一条已证实：法被撞过。两条路都能撑起「不能放行」。

阙禾为什么把法写得这么死，是暗线。公共邮箱里有去年婚车返工单：连秋穗喜期，阮箔开车，摄像坐门槛，片子整卷不能用，指挥部被婚庆公司追责。阙禾当时在白班，他给自己写信：明年再有人用喜的名进这条巷，过门先按丧记，先看记录，再听嘴。不看这封，也能交对。看了，只解释板为什么是这个口气。

### 合（放行建议，两处抉择）

建议表开了。仪礼性质、过门栏、处置、权限。柴渡要交。交了由白班决定开不开匙。窗一过二十二点，贺连舟队仍会在门口等——除非建议写的是不放行进堂。

抉择一：当喜还是当丧。当喜，就是信黄页和窗口。当丧，才对得上钥匙簿、穆三刀、晚秧那句换白。

抉择二：守法还是改法。改值班板上的法，等于夜岗去动白班立的规矩。系统收，回单作废意义上的那种收——路是错的。权限若勾批准，同样退回。只能建议。

过门栏若仍勾「干净可进」，即使仪礼勾了丧，也过不了：记录页或试记留下的那条，已经证明坎被踩过。丧班踩了门槛，还要进堂，等于把脏的一趟送进内。

暗线不挡路。去年返工单只解释阙禾。不看也能交对。

抽掉「自称喜队」这个钩子，故事还在：一条门槛，喜丧相反，修缮窗口偏爱红的，丧班要借名，记录里已经有一脚。恐怖是格子对不上嘴，不是门槛里爬出鬼。

## 第3段　人物小传

**柴渡**  
功能位：夜岗，今晚唯一能交放行建议的手。  
声线：只在引言里用他的嘴，碎，改口，怕记错又怕交晚。  
动机：把过门记明白，好交班。  
弧光：从「喜可进」→看清是丧班借名→记录里已有踩踏→若去改板会被退；能做的只是建议不放行。

**阙禾**  
功能位：白班，值班板作者。  
声线：短，板上不解释怕什么。交接两句就走。  
动机：别再让去年那种婚车返工落到自己班。  
弧光：从把法写死→留下试记口→自己不当夜岗的笔。不看邮箱也能理解他为何写得硬。

**贺连舟**  
功能位：自称喜队的头，门口那队的嘴。  
声线：急，会圆谎，黄页上像接活的。  
动机：先把人送进堂，再谈红白。  
弧光：从喜队广告→借去年秋穗的花车名→钥匙簿揭穿他→他仍可能赢，只要柴渡当喜放行。

**穆三刀**  
功能位：丧班帮忙的人，短信把杠擦了说出来。  
声线：省字，怕被记名，不像贺连舟会写广告。  
动机：别把自己写进擦杠那一行。  
弧光：从帮忙抬→杠蹭了坎→只敢发短讯→他不能交建议，只能把脏的一趟扔给夜岗。

**顾扃**  
功能位：堂屋钥匙管理员。  
声线：只认条，不认嘴。抄件冷。  
动机：匙按用途发，丧不改喜，喜不补第二把。  
弧光：从发匙给贺连舟（用途写丧）→贺连舟改口要喜→顾扃不换发。钥匙在谁手里，不能单独证明仪礼，但用途栏能顶嘴。

**贺守石**  
功能位：真正的亡者。人不到场。  
声线：无对白。留下丧班布置、穆三刀那句「那头还在等抬」。  
动机：无。他已经故了。堂屋若按喜打开，丧班会把白的抬进红的窗口。

**贺晚秧**  
功能位：让连舟借喜名的家里人。  
声线：地方帖上漏句，事后想删。  
动机：窗口卡丧，先顶红的。  
弧光：从求便利→帖上说漏→成为丧不是喜的人证。她自己开不了堂门。

**连秋穗**  
功能位：去年喜期的新娘名，今夜被借走。人不到场。  
声线：无今夜对白。留下花车名、旧通行条、返工单。  
动机：无。她去年已经走完自己的过门。名字留下，是因为片子作废，档案没销。

**阮箔**  
功能位：去年婚车司机，返工单上的名字。  
声线：邮箱附件里一行。  
动机：当时他只开车，摄像坐了门槛。  
弧光：暗线人物。不看他，主线也能收。

**卜巷 / 姜篾**  
功能位：目击踩踏的邻里；把快递柜顶在二门坎上的施工噪。不是换名充数：卜巷证明「踩踏长什么样」；姜篾证明邻里骂没规矩是另一条坎，不得并案。

## 第4段　每人抽出的单独故事

**柴渡的今晚**  
他六点接班，阙禾已经走了。门框内侧有工号。他先以为是记一趟红的过门，写放行，二十二点就能走。黄页太红，对外窗口又只收喜，他差点就按喜交。穆三刀那条短信是后来才翻到的，字难看。顾扃的簿子更难看。他可以按贺连舟的嘴交，明天吵的不是他——夜岗名不印在钥匙上。他也可以写不放行。写了，白班会问他是不是死板。他若勾改板或批准，窗直接退。他的弧是：夜岗想少惹事，最后只能在建议的格子里把丧和踩踏写明白。

**阙禾的板**  
去年连秋穗喜期，摄像坐门槛，片子废了，婚庆公司找指挥部。阙禾在白班挨了那一下。后来他专写硬法。他不是要咒贺家。他要一张自己班没再被追责的记录。他把试记口留给夜岗，等于把「法能不能撞」交给别人试，自己不当夜岗。不看返工单，也能读板上的字。

**贺连舟的名**  
他接活。贺晚秧说窗口卡丧。他手里有去年秋穗那张通行条复印件。花车名不用换，红布一罩，黄页就能挂。他不是礼生。他要进堂。进了再换白，他觉得是家里的事。钥匙簿写丧的时候，他还在发「我们喜队」。他的弧是：借名的人把窗口的偏好当成法。

**穆三刀的短讯**  
他来帮忙抬。杠沉，正门坎高，有人喊快。杠皮蹭到木头，他听见了。他怕把自己写进擦杠。贺连舟不让他在门口说丧。他只能给夜岗机发四个字加一句：杠擦了。别记我。他的弧是：帮忙的人把脏的一趟扔给记格子的人。

**顾扃的匙**  
堂屋匙不归夜岗。他下午把匙发给贺连舟，用途写丧班进堂布置。夜里贺连舟改口，说是喜，要再补一把红穗的。顾扃不补。条上写什么，匙就是什么。他不审红白对不对，他审条。他的弧是：管钥匙的人把嘴挡在条外面。

**贺晚秧的帖**  
她先以为删得掉。窗口的人下午说丧事改侧门，侧门堆着灰。她让连舟顶喜名。夜里卜巷问门口怎么又是红的，她回了一句：先进去再换白。回完才怕。她不能领匙，也不能交建议。她的弧是：求便利的人把一句实话留在楼层里。

**贺守石的缺席**  
他故了。堂屋还在修。丧班要进去布置。窗口爱红。他的名字不在黄页标题上。穆三刀提他，顾扃的用途栏不写他的讳，只写丧。三份网页同时成立，人已经不在巷口。

**连秋穗的旧名**  
她去年过门。摄像坐了她家那条坎。片子不能用，返工单进了指挥部邮箱。她人走了，花车名和通行条还在。今夜有人拿她的名去抬别人的丧。她不知道。

## 线索与伏笔

| 掉落 | 指向 | 回收 |
|---|---|---|
| 值班板「今夜按丧记，杠不得擦」 | 世界法 | 试记打回；建议不得改板 |
| 待记过门（贺连舟队） | 第一件可撞 | 试记三选 |
| 试记踩踏/擦杠被打回 | 法被撞过 | verified.broke，刷新仍在 |
| 记录 19:40 踩踏 | 页上已有违规 | 无试记也能撑「已有踩踏」 |
| 黄页喜队、对外喜事窗口 | 第一层：喜可进 | 被钥匙簿/短信/帖推翻 |
| 穆三刀「杠擦了」 | 丧、且脏 | 仪礼=丧；不得放行 |
| 顾扃用途「丧班」 | 匙按丧发 | 嘴上的喜对不上条 |
| 贺晚秧「先进去再换白」 | 借名 | 第二层真相 |
| 名单抬杠、无新娘 | 不像喜 | 近答案「真喜走错门」的排除 |
| 旧通行条日期改过 | 借去年秋穗 | 暗线入口 |
| 返工单摄像坐门槛 | 阙禾为何写死法 | 暗线，非必走 |
| 姜篾快递柜顶二门坎 | 有用噪声 | 不得与正门并案 |
| 民俗页忌踏坐、喜丧相反 | 法的出处 | limits：旧俗不能单独定今夜这队 |

被砍的支线：不写驱鬼、不写真门槛做法事、不阻碍坡道权益（坡道争议只作人物偏见）、不批准开匙、不改原板。

## 多结局

| 键 | 触发 | 逻辑根 |
|---|---|---|
| hold-funeral | 仪礼=丧；过门=已有踩踏；处置=不放行进堂；权限=建议；且已持 verified.broke 或已打开记录页 | 丧不是喜，坎已被踩，只能建议不进堂 |
| let-in | 处置=放行进堂（无论红白怎么勾），且未勾改板 | 当喜事或当能进，送进堂 |
| rewrite | 处置=改掉值班板上的法，或仪礼栏选改法 | 夜岗去动白班的法 |

正确收口是 hold-funeral。let-in / rewrite 各有根。缺已证实踩踏或未见记录页时，不放行也只退回，不另开键。

## 单案种子（备查）

- 标题：门坎试法
- 钩子：自称喜队要进堂，板上的法按丧记，记录里已有一脚
- 主角：柴渡
- 欲望：交差下班，别把脏的丧班当喜放进去
- 冲突：窗口爱红，板上写丧，门口那队两张嘴
