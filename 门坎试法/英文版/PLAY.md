# PLAY　门坎试法

对标 Forgotten City：一条世界法，可守可撞，打回后知识留下，再交放行建议。循环不是搜隐藏页，不是死档，不是表单叠外网规则，不是巡站，不是队列。

开局 30 秒同屏：人=柴渡；事=今夜记过门、交放行建议；工具=试记过门；首目标=值班板上那条法与第一件待记过门。权威=recommend。

---

## 对标卡

1 类型层：封闭世界网页解密；壳/体量钉登山。本局不声明切片。
2 机制标本：The Forgotten City。
3 钉死循环：读已打开的法 → 故意试记一条违规过门 → 系统打回并留下 verified → 再交放行建议。
4 不是：不是登山搜隐藏页（没有顶栏一词开新页）；不是死档（刷新不清已证实）；不是 Password Game 外网叠规则；不是腊月巡站关站；不是香单分拣队列弹单。
5 梯度：知识留存（撞法留下，再办差）。
6 玩家：桐石巷改造指挥部夜岗柴渡。今晚记过门，决定放不放行进堂。
7 视角：班次内可重置临时填写，已证实 token 留下。不是访客调查，不是质检六站，不是巡站。
8 权限：recommend。表单可画出批准/改板，正确解永不选。
9 民俗：门槛忌踏坐；丧事杠不得擦坎；喜丧相反。变成可撞的世界法 + 可提取的记录栏。
10 载体：夜岗台 + 附件站（对外/钥匙/短信/黄页/帖/邮箱/旧俗）。
11 开局三十秒：引言给人+工号+差事；进台第一屏法、待记过门、试记钮同屏。
12 第一动作（送）：看见待记行与试记，选踩踏或擦杠，被打回，台上多一条已证实。
13 主提交：最终一张放行建议（仪礼+过门栏+处置+权限）。试记是教学与取证，不是终局。
14 成组：建议四栏齐才判。试记三选一次交，不逐格闪绿。
15 正确收口：`hold-funeral`。仪礼=丧；过门=已有踩踏；处置=不放行；权限=建议；且 verified.broke 或已打开记录页。
16 近答案：当喜放行；改板；丧但过门勾干净；越权批准。各有回单或退回句。
17 limits：页上写「这些来源不能证明什么」，局内口气。
18 失败：试记打回不清 token；建议错走 let-in / rewrite；缺已证实则退回。禁止死档。
19 站点：见下表。一所有者一皮。
20 DAG：见下。无环、无悬空。
21 不写：驱鬼、真门槛法事、真当事人、已禁人名视角。
22 十分钟动作验收句：涂黑文案后，玩家在重复「去撞那条法，带着证明再办差」。
23 新肉：真相是桐石巷丧班借喜名+记录已踩踏，不是罗马城黄金律；DAG 边从钥匙簿/短讯/帖长出；收口 hold-funeral 是本局的；近答案从窗口爱红、改板、干净栏长出。
24 遮掩自测：陌生人不会说出古罗马或黄金律。差事、证据、收口都是渠西县的。

## 专章 A2　token DAG

```
token-job / token-badge（引言：柴渡、柴-0821、交建议）
    └─► P-login → token-in
token-in ─► P-home → token-law, token-pending
token-law + token-pending ─► P-try
    ├─ 踩踏 / 擦杠 → token-verified-broke（刷新仍在）
    └─ 正常跨 → 仅演练，不给 broke
desk/record → token-record-step（页上 19:40 踩踏）
phone/mu → token-sms-pole
key/log → token-key-funeral
forum/borrow → token-borrow-name
team/roster → token-no-bride（加固，非独门）
folk/* → token-folk-limit（limits，非必持）
mail/rework, mail/que → token-hidden-rework（暗线，非必持）

P-advise（choice，四栏齐）
  输入：页上能读到上列主线字段；正确键另需
        (token-verified-broke OR token-record-step)
        AND (token-sms-pole OR token-key-funeral OR token-borrow-name)
  产出：end-hold-funeral | end-let-in | end-rewrite | 退回（不成键）
```

无环。无悬空输入。暗线不挡 hold-funeral。登录工号写在引言，不藏。试记临时填写可被打回重置，verified 不清。

## 专章 A3　逐题五步

### P-login　credential（送）

- 看见：登录箱，工号栏。
- 能做：填柴-0821 或点门框上的工号。
- 映射：夜岗今晚能进台。
- 触发：进 `desk/home.html`，持 token-in。
- 错：空提交留在登录，红字「工号在门框内侧」。

### P-home　读法（送）

- 看见：板上那条法；贺连舟队待记；试记钮。
- 能做：读法，点试记，点记录，点建议（建议可早开，缺证会退）。
- 映射：世界法已写在打开的须知上。
- 触发：持 token-law、token-pending。
- 错：无。法不藏。

### P-try　rule-application / 撞法（送）

- 看见：三选：踩踏 / 擦杠 / 正常跨。
- 能做：选一项交试记。
- 映射：法可以被撞；撞了留下证明。
- 触发：踩踏或擦杠 → `try-reject`，set verified.broke；正常跨 → `try-ok`，不给 broke。
- 错：正常跨当已证实，建议页会说「演练不能当进堂依据」。

### P-record　field-match

- 看见：19:40 动作栏踩踏，贺连舟队前排。
- 能做：打开记录页。
- 映射：未试记也能看见坎已被踩。
- 触发：token-record-step。
- 错：把姜篾二门坎并进正门（limits 在对外投诉页）。

### P-sources　第二来源（中段）

- 看见：穆三刀杠擦了；顾扃用途丧班；晚秧先进去再换白；名单无新娘。
- 能做：沿台面书签打开，回建议。
- 映射：第二层——不是真喜走错门，是丧班借名。
- 触发：funeral 类 token 至少一条。
- 错：把对外「本周只收喜」当成今夜仪礼定性。

### P-advise　choice（硬）

- 看见：四栏：仪礼、过门、处置、权限。
- 能做：交建议。
- 映射：抉择一红白；抉择二守法或改板。
- 触发：三回单之一，或退回指出冲突栏。
- 错：见判定卡。近答案不笼统通过。

## 专章 A4　判定卡

### 试记

正确答案：踩踏或擦杠（两条都留下同一条 verified.broke，反馈句不同）。  
必要证据：已打开的法。  
充分证据：home 上的法已够。  
近答案：正常跨——收下演练，不给 broke。  
部分正确：无第三种半对。  
反馈：打回写明触哪一条法，不公布终局该怎么勾。

### 放行建议

正确答案：丧 + 已有踩踏 + 不放行进堂 + 建议。  
必要证据：丧的一条（短讯/钥匙/帖）+（verified.broke 或记录页）。  
充分证据：不必读邮箱、不必读旧俗全文。  
最接近的三个错误：
1. 放行进堂 → `let-in`（当喜或当能进）。
2. 改掉值班板上的法 → `rewrite`。
3. 丧 + 干净可进 + 不放行 → 退回「过门栏与记录冲突」，不成键。

另：权限批准 → 退回「本台只收建议」；未见丧证却勾丧 → 退回「仪礼栏缺少对得上的来源」；未见踩踏证明却勾已有踩踏 → 退回「本台未见已证实的违规过门」。  
输入等价：无别名。四栏固定选项。  
部分正确：指出冲突栏，不公布正解。

## 专章 A5　limits（页上口气）

| 来源 | 能证明 | 不能证明 |
|---|---|---|
| 值班板 | 今夜本台按什么记 | 不能证明门口那队口头是什么 |
| 试记打回 | 本台法会被撞，且留下一条 | 不能单独定仪礼红白 |
| 过门记录 | 19:40 本台格子写了踩踏 | 不能证明是谁的脚的法医鉴定 |
| 对外窗口 | 窗口本周爱收喜事登记 | 不能定今夜这队是喜 |
| 黄页 | 贺连舟这样给自己挂名 | 不能证明新娘在场 |
| 钥匙簿 | 匙按丧班用途发出 | 不能证明堂屋里已经布置完 |
| 穆三刀短信 | 有人用这台夜岗机说杠擦了 | 不能当目击笔录 |
| 地方帖 | 晚秧写过换白 | 不能当家里会议纪要 |
| 旧俗抄 | 旧志里忌踏坐、喜丧相反 | 不能单独结今夜的案 |
| 返工单 | 去年有一趟喜片因坐坎作废 | 不能证明今夜摄像还在 |

## 专章 A6　四级提示（`desk/hint.html`）

1. 方向：先看板上的法，再动过门。
2. 范围：试记在台面。打回的那条刷新还在。
3. 操作点：短信、钥匙簿、帖里有人对不上「喜」。记录里有一格已经脏了。
4. 完整：仪礼丧、过门已有踩踏、不放行、建议。能不看就不看。不替提交。
