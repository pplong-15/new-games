# 门坎试法　风格圣经　polish-20260823

相机锁死：正视 2D 网页平面。无透视、无一层视差、无 Canvas 粒子、无插画房间冒充公文。中英同一相机；八张静帧中英同字节，不另出英文图。

比例：夜岗台是限色后台桌，不是关卡条、不是边检亭。桌面宽栏 960；320 / 390 把值班板、试记三选、四栏建议纵向叠满，禁止横滑藏栏。其余八个所有者栏宽按皮（说明书 820、对外 960、卷宗 min(800,92%)、功能机 240、黄页 960、楼层帖 980、邮箱 960、百科 960），窄屏只把栏拉满，不把九套皮收成同一张卡。

线宽 1x：1px 实线为主。值班板 2px 实线 + 左 8px 木色条。已证实条 2px 虚线 + 左 6px 实条 + 「■」。打回 2px 双线 + 「×」。演练 2px 点线 + 「○」。选中试记 2px 实线 + 左内条 + 加粗。空下拉虚线，已选实线。焦点 3px 点线。引言说明书可留圆角白卡；假官网与夜岗台禁止 8px 全站圆角白卡。

主材质 `material_id=county-night-duty-2010`：2010 年前后县级指挥部夜岗 HTML 表 / float / 雅黑或宋体栈，略糊 JPEG 静物（巷、坎、门、杠、布、麻、匣、车尾）。年代用控件形态写（1px 线、斜边钮、楼层 float、功能机 240），不写「复古」。

光：顶光，无动态光。强调色只绑功能（进台/交试记/交建议、打回、焦点），不绑四栏对错、不把 hold 正解镀金。
