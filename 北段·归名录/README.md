# 北段·归名录 V2.1.2

本目录是当前唯一主版本，源自桌面「北段·归名录V2」完整项目（2026-09-22/23）。游戏源文件、原始美术、设计文档和验证材料均在本目录。

## 开始试玩

打开 `游戏/index.html`，或在本目录执行 `python3 -m http.server 8000` 后访问 `http://127.0.0.1:8000/游戏/`。完整玩法、手机操作、存档和当前试玩链接见 `阅读说明.md`。

## 当前边界

这是 V2.1.2 六案完整版。修正判断按钮的未就绪提示，并为幕间与结案剧情标清推进状态，避免新剧情弹窗被误认为旧弹窗未关闭。更早的 V4、V5 第一案和实体牌桌首案包属于历史/局部版本，没有与完整战役源码混拼；整理记录见 `整理记录.md`。旧版本移入本机 Codex 项目的归档目录，不随本版公开提交。
