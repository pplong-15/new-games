## 封面处理

- 源：既有 `img/cover-paper.png` 1536×1024 ~3MB

- 禁止在图上加可读新字、日期台标、商标、拉丁文、汉字。
- 裁完仍能指认：纸、红格谱线、中央墨污。

## 无障碍钉死

- 主操作触控 ≥44 CSS px（三门、查找、摊开、写入、开簿、交建议）
- `:focus-visible` 金/青描边，不靠 hover 才能点
- 状态不唯色：未打开/已打开/还没有；已挂 / 整条作废 / 未改库 是不同标题句
- `prefers-reduced-motion: reduce` 时特藏章不倾斜
- 320 / 390 三门仍在首屏可点
