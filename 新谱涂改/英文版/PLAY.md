## 逐题五步

### P1 看见涂行（送）

- 看到：委托台待传「西房卷二」，点进电子页，第十四行墨污，旁注出嗣。  
- 能做：记下附件号、上传口。  
- 映射：不是空白页，是有人写了理由。  
- 触发：`v-new`。  
- 错：在引言空转。页上已写「对照台在委托台里」。

### P2 旧页有名（送）

- 看到：阅览须知先立凡例，扫描表里伯岑仍在。  
- 能做：把馆藏抄件当左栏。  
- 映射：一九九八年没把他写成出嗣。  
- 触发：`v-old`。  
- 错：把墨污当扫描脏。对照后会打回。

### P3 对照旧∥新（中）

- 看到：对照台左右下拉。  
- 能做：摊开，勾对不上的字段。  
- 映射：主动涂，不是漏排。  
- 触发：`cmp-erase`。葛汀留言刷新一句。  
- 错：只勾年份不勾行/注，条不写。近答案有回馈。

### P4 迁出事由（中）

- 看到：户政镜像查户主，命中进迁出页。  
- 能做：读事由、回迁空、厂函。  
- 映射：走的是务工，不是过嗣。厂函不能定死。  
- 触发：`v-hk`；对照新∥迁出得 `cmp-reason`。  
- 错：查别人得「不在本卷」。

### P5 旧帖补件年（中，可与 P4 二选一）

- 看到：房头楼从二〇一四问到二〇一九回。  
- 能做：对照旧帖∥新谱。  
- 映射：字据是后来补的。  
- 触发：`v-bbs` + `cmp-year`。  
- 错：把楼下玩笑当原件。

### P6 挂条（硬）

- 看到：对照条有差之后，挂条口可交。  
- 能做：四栏单选，权限写明建议。  
- 映射：世系建议 vs 产业越权。  
- 触发：三终点之一。  
- 错：对照不够则退回「差还没写出来」；越权走退回终点。

### 暗线 P7

打开一九八三稿、借阅条、东房另卷、厂函全文：加深「谁先看见旧行 / 出嗣在谱上长什么样 / 厂函不能定死」。无新强制 token。挂对后回单多一句仍只看 `v-draft`，不改变终点键。对照台可加选东房扫描 / 厂函 / 借阅条摊开，写入仍只认原四对。

## 四级提示（抽屉，不替勾选）

1. 方向：先把馆里的旧行和台上的新行摊开。  
2. 范围：旁注那两个字，去迁出簿里找事由。  
3. 操作：对照台左续修右电子页，再换迁出或房头楼。  
4. 完整：脏因选按附件涂，世系选外迁，主件选底册，末栏选只核世系。

1–3 不写应勾项。4 在抽屉最底，不自动弹。

## Source limits（屏幕用站内说法，不出现「不得推出」）

- 电子页：只能说明此刻库里的字，不能说明六二年原件存在过。  
- 续修扫描：馆藏抄件，不能证明人现在还活着。  
- 迁出底册：能对事由和年份，不能当死亡证明。  
- 镇事楼：楼层是发言，不是公证书。  
- 未定稿：未刊行，只能说明更早写法。

## 新手五原则

1. 引言同屏给人、事、门、对照台位置。  
2. 每站末尾指下一处（须知→扫描，新页→对照台，底册→对照，楼→对照）。  
3. 对照对了写一条冷反馈；错了指哪一栏还虚。  
4. 委托台用「已打开的卷」清单，不用进度条字样。  
5. P1–P2 送，P3 起要勾字段，P6 才要四栏同时对。

匹配度：民俗「对世系、发现涂/双挂」=对照+挂条；离线闭环；DAG 无环。
