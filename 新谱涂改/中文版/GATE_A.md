# GATE_A　故事层七维

验收对象：`STORY.md`。本闸不碰 HTML。

## 1 人物立住　PASS

芮秋（出钱被涂）、怀川（送补件、自认理顺）、葛汀（两头钱、只收建议）功能位分开。三人若开口：芮秋碎而改口，怀川在楼下像邻里抬杠，葛汀短句不解释。延木、尤霜、怀山不是工具贴纸：延木留下问句，尤霜把门，怀山以缺席施压。

## 2 台词像真人　PASS（文本层）

故事层已规定各站书写习惯，不在此阶段写屏幕对白。预定：引言絮叨改口；委托台冷断；馆规先立后抄；底册半文；镇事楼群嘴。无「综上所述」式说明腔设计。开发期按 `COPY_NOTES.md` 落盘，本维先过框架。

## 3 剧情顺　PASS

冬至逼钱 → 付钱修谱 → 电子页涂行 → 旧页仍有名 → 迁出是务工 → 补件出在二〇一九 → 挂条只有建议权。怀川与芮秋不是突然翻脸，是同一笔岁修话语权结了几年。葛汀不站队，符合外包夜班。无阴婚、无突然恋爱。

## 4 恐怖类型成立　PASS

中式谱牒恐怖：入祠前一行被墨涂，依据是年份对不上的补件。反派不是单纯恶人——怀川有一九八六年未还的八百，葛汀是夹心。情绪落点是「谱上有名不等于能分岁修」，不是鬼爬出来。limits 挡住把厂方来函当成死亡铁证。

## 5 线索可闭环　PASS

伏笔均有掉落页与对照回收。三结局触发条件写在挂条四栏与对照 token，不靠作者宣布。暗线（一九八三稿、借阅条）可挖、非必走。

## 6 设定可单列、故事够厚　PASS

第1段设定，第2段时间线有起承转合。人物弧光：芮秋从讨说法到守权限。抉择点≥2：出嗣/外迁；只核世系/写产业。结局≥3。  
厚度：芮秋—怀川—葛汀互锁（钱、附件、上传窗）；反转两层（先信脏点/漏排 → 故意涂 → 补件年份与迁出事由推翻出嗣）；暗线未定稿。抽掉涂改钩子，两房抢话语权仍成立。

## 7 可英文化　PASS

解谜靠迁出事由、附件年份、凡例、权限，不靠拆字谐音。术语表已随故事交付。无功能谐音梗。

## 结论　PASS

可进玩法。开发红线：

- 玩家只 `recommend`，不准批准祠产、不准教做假序。
- 九六年厂方来函必须带 limits，不得写成死亡铁证。
- 四站并行对照，不做灰栏目搜隐藏页，不做片库，不做文旅游记。
- 禁用人名：陈迈、裴晚、沈南、周引娣、招招、闵科、程石、狄厚。
- 屏幕不出现：主线、搜词、汉字词、进度条、关卡、通关、解锁、线索、结局、源码、本游戏。
