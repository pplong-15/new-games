# 风格圣经　香单分拣　VP1　2D

本局锁死：正交网页正视。不借边检亭、不借真搜索引擎壳、不借游戏 HUD。

## 相机 / 比例 / 线 / 光 / 材质

- camera_angle: 网页正视。无 2.5D、无透视桌面。
- character_prop_ratio: 无角色精灵。可读比是「可写单行 : 附件链 : 裁决栏」。
- line_weight_at_1x: 值班台功能描边 2px 青石色；红头皮顶栏底边 4px 金线保持其皮。
- light_dir: 顶光平铺。禁止压暗、雾、全屏 vignette 当难度。
- material_id: 2015 市政内网浅青塑料台面 + 各所有者自己的纸/屏（红头铜版、协会 778 表、纸黄博客、黄页顶栏、公众号 677 白栏、宋体卷宗）。

## 值班台信息层级（D1）

1. 顶栏：机构名 + 系统钟。检索是已关死壳，灰虚线，视觉权低于队列。
2. 首屏主操作：待写队列（带链=可写）| 本班推送附件。
3. 便笺次级。
4. 班前说明与头图沉到底，不当搜词门户。

死搜框 action 仍为 `search-closed.html`。不得做成 Google。不得做成进度条。

## 控件

- 主操作（进后台、队列链、裁决提交、便笺、回执）≥ 44 CSS px。
- 值班台检索不是主操作，保持小于主链，避免再抢眼。
- `:focus-visible` 3px 实线，颜色跟皮走。
- 320 / 390：栏宽改 100%，双栏改上下叠，不丢主动词。
- 成功/失败/禁用/空/错误：字或形或线，不唯色。选项下拉不给绿放行/红暂扣。

## 减动

`prefers-reduced-motion: reduce`：无位移动画；摘抄章取消倾斜。Toast 仍瞬时出现（本就 0ms）。
