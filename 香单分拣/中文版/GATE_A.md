# GATE_A　故事层

## 七维

### 1. 人物立住　PASS
裘石怕晨班追问，屈南只写白板，米穗收银口吻半句就走，霍麦写自己委屈，晚秋书面客气，开平电话里重复忌日，尚灯寺庙套话，司徒秋会务腔，蓝秋荻算钱。换掉署名仍能听出谁在说话。

### 2. 台词像真人　PASS
预留改口、半句、套话、通告句。禁止说明性旁白上场。开发期按 COPY_NOTES 各站习惯写，不写「综上所述」「不是 X 而是 Y」。

### 3. 剧情顺　PASS
接班 → 何家放行教学 → 烧衣对照禁烧 → 供灯对照芳名 → 纪单推送多源 → 开平摘记与底账冲突 → 剩余三封收尾。没有突然相爱式关系跳跃。每场把下一封或下一组附件交到手上。

### 4. 恐怖类型成立　PASS
不是开鬼门，不是跳脸。压迫来自：你写的桌签早上会摆出去；无嗣的人可能被写进别人的龛；在世的孙子只能留下一通电话。反派不是单纯恶人——晚秋要给舅舅一个位置，开平要守祖父的字，屈南要店里别打起来。

### 5. 线索可闭环　PASS
孤魂席芳名、客死无嗣、伯元六月十九、霍麦去年改桌、开平摘记，各有掉落页。纸扎取消是暗线，不挡主线。地方号七月文不产出桌次。多结局各有触发。

### 6. 设定可单列、故事够厚　PASS
第 1 段只放中元分桌与代办权限。第 2 段按时间线走。关系网：晚秋–开平–守成/伯元互锁，屈南–霍麦–裘石压在同一条改桌规矩上，同乡会–寺庙–福泽三套账（≥3 节点）。两层反转：填错名字 → 守成是孤魂 → 晚秋故意抢格。暗线：纸扎孤衣取消。抉择点：纪单放行/暂扣/改桌 + 建议写什么；其余六封仍要处置。

### 7. 可英文化　PASS
不靠拆字谐音。术语表已随 STORY 交付。正祀／孤魂席作桌次字段，不作字形谜。

## 结论
**PASS**。可进玩法与开发。

## 开发期红线
- 玩家只有 recommend：按钮禁止出现批准、核定、准予入龛、同意超度。
- 不写法事口诀实操；不写七月开鬼门；不把俗信写成法律。
- 队列不许跳号。纪单附件必须在打开该单后推送，禁止做成站内搜隐藏页。
- 不做邮局分拣员换皮（不出现邮路、邮戳、分拣码当作主循环）。
- 开局同屏：队列、第一封已在、推送栏、钟。
- 屏幕禁止：主线、搜词、关卡、通关、解锁、线索、结局、源码、本游戏。
- 禁用人名见 LOCK.md。本局不用卫棠、岑禾、蒲生、韩洲。
