# 乡村邮政登记调度员 — 开发施工单

## 项目概述

一款**网页解密游戏**（ARG式网页解谜的接收端变体）。玩家是乡镇邮政所夜班分拣员，在六站系统界面中处理邮件，发现退回信件来自二十年前被水库淹没的村子。核心机制：信息流向玩家（非玩家搜索），玩家做处置决策。恐怖完全来自数据异常。

## 技术规格

- **交付形式**：单文件 HTML（所有CSS/JS内嵌）
- **无外部依赖**：无CDN、无外部图片、无字体文件
- **纯静态**：双击浏览器打开即玩
- **总大小**：目标 ≤ 2MB
- **所有图片用CSS生成或极简SVG**：证件照用灰度渐变占位，X光图像用CSS filter

## 核心交互循环

1. 玩家看到邮件列表（自动刷新，按游戏时钟推进）
2. 点击邮件 → 查看详情 → 系统自动检测地址/人员状态
3. 如果有异常 → 弹出处置选项（确认注销 / 标记待核验 / 标记异常）
4. 处理完成 → 待核验计数更新 → 下一封邮件流入
5. 游戏时钟推进 → 触发下一批事件

## 游戏流程

三夜，每夜1小时游戏时间（20:00-01:00），可加速（×2/×5/×10倍速）。

### 第一夜
- 培训关（5分钟）：赵德明教基本操作，处理10封正常邮件
- 异常浮现（40分钟）：沈秀兰退信→三封连锁→周海签收→吴桂芳包裹
- 收束（15分钟）：系统提示陈国栋

### 第二夜
- 首字拼句（30分钟）：6封退信首字拼成"水库下面有人"
- 陈国栋日志（20分钟）：翻阅值班日志
- 查询操作记录（10分钟）：1998数据合并

### 第三夜
- 自身记录发现（20分钟）：林远退信→三人绑定
- 赵德明对话（20分钟）：系统即时消息对话
- 最终抉择（20分钟）：四结局分支

## 四个结局

A. 干净的记录（批量注销79条→系统干净→林远升职→忘记一切）
B. 模糊的边界（逐条处理但不处理自己→被系统注销→成为系统"硬块"）
C. 继承者（逐条+拆分+后门归档→接任所长→失去记忆但保护了数据）
D. 隐藏：第三个孩子（暗线A解码+重定向→三人数据封存→林远保留记忆）

## 视觉风格

- 整体：2000年代中国基层政务系统
- 站4（地址簿）：绿底绿字 CRT终端风格 — 最重要

## 实现优先级

1. **Phase 1**：六站UI框架 + 游戏时钟 + 邮件系统（第一夜可玩）
2. **Phase 2**：异常事件链 + 操作记录 + 第一夜完整流程
3. **Phase 3**：第二夜 + 第三夜 + 首字拼句逻辑
4. **Phase 4**：四个结局 + 暗线 + 倍速 + 回档

## 铁律

1. 单文件 HTML — 所有CSS/JS内嵌
2. 游戏时钟驱动 — 异常按预设时间表触发
3. 所有数据在代码内声明 — 不依赖外部文件
4. 纯信息层恐怖 — 不出现任何恐怖画面/jump scare音效
5. 手机适配 — 响应式布局，至少桌面端完美运行
6. 语法零错误 — 完成后跑 `node --check`
