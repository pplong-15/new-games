# 风格圣经 · 乡镇邮政 MIS 六站夜班 · 2D VP1

相机：正对桌面，无透视、无视差。
比例：窗框 > 站壳 > 证据 > 人像。证件照小，不抢裁决钮。
线宽：1–2px Win2K 斜角；站4 用 1px 绿栅。
主材质：2000 年代基层邮政终端（扫描灯床 / 仓格 / 纸质花名册 / 绿 CRT / 米色 OA 表 / 运单时间线）。
三色锚：窗框蓝 #1a365d / 系统灰 #d4d0c8 / CRT 绿 #33ff33（强调色只绑站4终端与功能，不绑情绪）。

六站壳差（至少三项：底色 / 标题栏 / 控件形态 / 字体栈）：
1. 扫描台：冷蓝灰、工业标题栏字距、ridge 扫描床、Tahoma。
2. 分拣：仓绿、small-caps 标题、outset 格。
3. 调度：牛皮纸底、宋体、双线标题、纸卡片阴影。
4. 地址簿：黑底绿字 Courier，标题全大写，扫描线可停但状态在。
5. 退件 OA：#ece9d8、#003c74 标题、inset 表。
6. 回执：运单蓝、左黄条标题、时间线左轨。

禁止：新 AI 脸、重绘内嵌照、边检护照、现代白卡、游戏 HUD、搜词顶栏。
减动：扫描线静止可见，不靠闪完成反馈。
