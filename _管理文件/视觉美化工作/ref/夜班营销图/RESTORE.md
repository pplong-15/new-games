# 恢复夜班营销图到玩家语言目录

这两套是美化前从玩家包完整移出的原目录 + 封面，不是删除。

## 核对

中英文件名与 SHA256 见 `SHA256.txt`。本局中英字节相同，仍分语种保存。

## 恢复（可逆）

在 `/Users/jianglong/Desktop/游戏美化` 执行：

```bash
REF="_视觉美化工作/ref/夜班营销图"
GAME="夜班"
mkdir -p "$GAME/中文版" "$GAME/英文版"
mv "$REF/中文版/夜班-小红书" "$GAME/中文版/夜班-小红书"
mv "$REF/中文版/夜班-小红书封面.jpg" "$GAME/中文版/夜班-小红书封面.jpg"
mv "$REF/英文版/夜班-小红书" "$GAME/英文版/夜班-小红书"
mv "$REF/英文版/夜班-小红书封面.jpg" "$GAME/英文版/夜班-小红书封面.jpg"
```

恢复后用 `SHA256.txt` 对玩家目录再哈希一次。不要把本 `ref/` 目录算进玩家发布包。

单文件 `夜班.html` 从未引用这些图。
