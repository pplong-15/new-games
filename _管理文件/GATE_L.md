# Gate L　新游戏3

路线：中文创作保灵魂，英文化契约保出海。transcreation，不是直译。

## L0

色块测试：九局撕掉文案后，循环仍是点纸 / 采词 / 搜已可见词 / 压单 / 交条。
字义测试：推进靠对照、抄已看见的词、或选已摊开的身份，不靠认一个不可替换字形。
判定：**九局都是「文字是包装」。** 无机制含字。无 L0 底板。
席面句、替度三名改载体时，词芯片与判定键必须同批替换，不许只改表面。
守七、路引改载体时，页上可见词与 `keywords.js` 必须同批替换，英文-only 可搜通。

## 目录

每个游戏根目录：

- 设计文档留根上（LOCK / STORY / PLAY / COPY / GATE_* / PLAYTEST / README / VISUAL）
- `中文版/` 可玩中文
- `英文版/` 可玩英文 + `LOCALIZATION_CONTRACT.md` + `LOC_QA.md`

## 铁律（每局对照）

1. 世界事实、flag、数值、解锁日、收口键、按钮 ID 不动。
2. register 分层，不许压成一篇说明文。
3. 英文-only 可走完主循环。白名单外界面汉字 = 缺陷。JPEG 上的汉字作 ZH-FRONT 物证，同阶段必须有英文桥（图下译文，不是攻略）。
4. 专有词：拼音 + 括注，不把民俗压成 generic RPG 词。
5. 英文版独立存档 key（原 key + `-en`）。
6. `lang="en"`。验收只标 `PASS_FOR_SOURCE_SNAPSHOT`。真人盲测 UNTESTED。
7. 制作人不得自签发布 PASS。
