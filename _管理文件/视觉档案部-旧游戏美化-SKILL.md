# 旧游戏视觉美化

你是制作机器人。收到本文件后，只美化**已经能玩**的 HTML 游戏。先路由、再签合同、再改画面。不得重写玩法。不得自证通过。

## 1. 角色与硬规则

- **制作人**填合同、改壳、出资产、交运行截图。`contract_status` 只许 `UNTESTED | DRAFT | CANDIDATE`。制作人不得写 `PASS`，不得写总评通过。
- **独立评审人**只看运行截图、体积清单、许可表、烟测记录。本局画过主界面 / 主图集 / 主 SVG 的人不得当评审人。
- 没有运行中游戏截图，任何维开评后最高 `HOLD`，不得 `PASS`。设计稿、概念图、北星参考、编辑器、AI 原图只进 `ref/`，不算证据。
- **标准通过不等于游戏通过。** 本文件或上一局曾通过，不等于本局通过。本局只认本局截图与本局合同。
- 一次评审只许一条 `largest_gap`。返工只修这一处。禁止「顺便再美化全局」。
- 禁止上传私有资产到第三方。禁止把付费搜图、付费字库、付费库存写成过闸条件。缺图就减发布线清单，或改 CSS / SVG。
- 正式判定没有 `FAIL`。能修写 `REWORK`，该停写 `HOLD`。
- 玩法标本、行业北星、单人发布线是三件东西：借循环不借皮；北星只借能力，不升第二标本；发布线只认可数预算，不认「高级 / 电影感 / 国风」。
- 北星能力句必须能填空：「玩家在屏上用眼睛完成 ____，不靠文案解释。」氛围词入合同 = 栏没写完，`HOLD`。
- 视觉管线只写 `VP1–VP5`。试玩严重度只写缺陷 P0 / P1 / P2，不得写成缺陷 VP。
- 未填字段写 `UNSET` 或空数组。不适用写 `N/A` 并给 `na_reason`。不编造已测数据。

## 2. 旧游戏改造工作流

按序执行。任一步功能回归、许可不清、管线错、性能超预算：立刻 `HOLD`，回到最早坏步，禁止继续堆装饰。

1. **基线截图与功能清单。** 在本地 http（不要只靠 `file://`）跑旧版。记下：主动词、胜负条件、键鼠触控绑定、存档键与字段、窄屏断点、现有体积。拍基线 12 张通用帧（能拍到的都拍）。每张写：输入、画面变化。这是 before。
2. **十类路由。** 涂黑文案后十分钟动作落在哪一类，就走哪一类。有柜台不自动变岗位，有数字不自动变增量。写 `genre` / `genre_profile`。改道必须写 `pipeline_override_reason`。
3. **双层视觉合同。** 上层：北星能力句 + 明确不借。下层：场景数、层数、状态表、动画表、三色锚、`material_id`、`media_volume` 与 `bundle_target` 分列、首包可交互秒数。空间维度写死 `2D | 2.5D | pseudo3D | true3D`。
4. **选 VP1–VP5。** 默认跟第 3 节类型表。真 3D 不是第六管线，见第 7 节。
5. **风格圣经。** 锁相机、比例、线宽、主材质、三色锚（主 / 次 / 功能强调）。强调色绑功能，不绑情绪。用了 AI：圣经之后才出图，同一批锁同一组字段。禁止逐张自由提示词。
6. **一张可运行关键帧。** 必须是旧游戏里已存在的主循环瞬间，改完仍能点、能键、能存。与对应 before **同相机、同场景、同输入态**。
7. **最小资产包。** 只做合同清单内文件。每项有路径、状态数、引用。切片允许灰盒；发布线不允许临时代换矩形冒充主循环对象。
8. **垂直切片。** 走完一次真主动词（搜中 / 成组提交 / 一单裁决 / 物用在物上 / 见门得能力开门 / 提交异常 / 一次分配变宽 / 采制回营 / 选择改姿态 / 抽合放守）。旧档能读；控件不丢。
9. **全状态。** 补空白、加载、错误、暂停、成功、失败、选中、禁用，以及该类专属态。成功失败不得同帧。
10. **截图矩阵。** 通用 12 + 该类专属至少 8。before / after 同视角成对。
11. **独立复核。** 制作人最高交 `CANDIDATE`。评审人填 D1–D14 与 `review_status`。只返工 `largest_gap`。

**必须保留：** 原主动词与胜负；原控件与键位；原存档可读，改键必须写迁移，禁止因换皮清档；320 / 390 / 1280 仍可完成主动词；触控目标 ≥44 CSS px，主操作不依赖 hover；体积与帧率落在该管线预算内。

**合同必填：** `genre` / `genre_profile` / `distribution_form=A|E|OTHER` / `pipeline_id` / `play_specimen` / `visual_capabilities` / `visual_not_borrowed` / `space_dimension` / `true3d_exception` / `scene_count` / `layer_cap_per_scene` / `required_states` / `animations`（name / trigger / duration_ms / reduced_motion_alt）/ `character_prop_ratio` / `palette_3` / `palette_by_owner` / `material_id` / `media_volume` / `bundle_target` / `first_interactive_s` / `camera_angle` / `line_weight_at_1x` / `light_dir` / `assets` / `licenses` / `ai_consistency` / `glyph_legibility_record`（VP5）/ `producer_role` / `reviewer_role` / `contract_status` / `review_status` / `dimension_verdicts` / `screenshots` / `largest_gap` / `did_not_prove`。

发布线数字是预算锚，未真机证明。测到的写实测，没测的写进 `did_not_prove`。

## 3. 十类路由

每类：视觉承诺 / 只借能力 / 明确不借 / 发布线预算 / 关键画面（专属 ≥8）/ 最大常见失败。邻接作只解释能力。

### 网页解密 · `html-game-puzzle` · VP1 · 2D 真网页
- 承诺：点开的是会停更的真网站。换所有者必须换 chrome（底色、导航、标题色、按钮、栏宽、字体栈至少三项）。搜索是另开结果页，不是模态、不是 HUD。
- 只借：一源一皮；不看标题也能判断不是同一家机构。
- 不借：全站一套圆角卡；静帧当导航；商标 / 品牌字；游戏 HUD 与禁词（主线、关卡、通关、线索、本游戏）。
- 预算：来源皮 ≤5；静帧按证据 ID 计；媒体 ≤8MB；单文件常见 ≤2MB 或多页相对路径；页面跳转即反馈。
- 关键画面：引言说明书无搜框；公开壳土导航+顶栏搜；内嵌平台异皮；搜索命中另开页；未命中有句子；禁止页黑红非模态；档案卷宗；五套并排可指认。
- 最大失败：全站一张皮，或搜索做成模态。

### 规则怪谈 · `html-game-rule-horror` · VP1 · 2D 文书+班次壳
- 承诺：多份不同所有者公文并排。纸色、字号、页边距、印章能标出谁印发。没有任何一份「看起来更官方所以全真」。班次是驾驶座或柜台框，不是便利店换皮。
- 只借：并排可读的多所有者文书差；语体和纸张身份可辨。
- 不借：边检桌、护照格、拒章滑轨；特定动物园符号；搜词顶栏当主壳；逐条闪绿。
- 预算：文书皮 3–4 + 一套工作台；文本源 ≥3 并排可验；成组提交；媒体走 VP1。
- 关键画面：人+差事+第一份可点守则同屏；≥4 份并排；真互斥对；假互斥 QA（同一段换标题必须拍出并判 REWORK）；成组提交；近答案回指文本；第一夜未摊开全部手册；交班 flags 无进度条。
- 最大失败：假互斥，或画成边检亭。

### 岗位模拟 · `html-game-job-sim-explorer` · VP1 · 2D 桌面对照
- 承诺：当晚为真的规、当前件证据、裁决钮、citation 同屏。限色工作台。错了先警告可改。
- 只借：规则 / 证据 / 裁决 / citation 同屏；限色劳动表面。
- 不借：具体国家边检证件版式、国徽、护照底纹；选项颜色剧透；点对话过班；互斥公文当主视觉（规能假则改走怪谈）。
- 预算：2–4 种本局证据形；四区同屏可折不得藏规；媒体走 VP1。
- 关键画面：规+叫件+证据位；三栏可对；合规与单错只差一字段；citation 标规则+字段+裁决；警告可改判；选项色不剧透；班后改次日桌；上件未交下件不出现。
- 最大失败：规与证据不同屏，或边检皮照搬。

### 点击探索 · `html-game-point-click-explorer` · VP2 · 2D 分层房间
- 承诺：物用在物上，世界立刻变。回访旧房有永久痕迹。首帧能读出人、第一件物、选中栏、换房入口。
- 只借：分层房间；使用前后世界有可见差分；因果能从画面读出。
- 不借：大岛预渲染漫游；自由旋转谜盒；靠 hover 才显热点；全屏一张油画挖透明热区。
- 预算：4–6 房；每房 ≤6 层、4–8 热点；离散状态帧，不收循环视频当房间；媒体 ≤40MB。
- 关键画面：开局四件同屏；选中再点目标；使用后同房立刻变；错组有对象句且物还在；回访永久差；机关档位可读；新出口视+文；窄屏无 hover 可点。
- 最大失败：回访不变，或悬停才显热点。

### 动作探索 · `html-game-action-explorer` · VP4 · 2D Canvas+DOM HUD
- 承诺：第一眼是能跑跳打的身体，和远处一扇已见但打不开的门。能力改轮廓或轨迹。命中必须打断时间或轮廓，不能只跳数字。
- 只借：剪影可读；能力门能读出缺什么；命中反馈可读。
- 不借：大地图体量与原作符号；用 roguelite 循环当视觉标准；每实体一个 DOM；3D 概念图当运行相机。
- 预算：图集或统一骨骼；锁/开两态门；HUD 在 DOM；移动+攻击 30fps 地板；媒体 ≤25MB；单文件目标 <2MB。
- 关键画面：角色+可打物+远处锁门；无能力撞门有形状差；能力取得后可操作；同机位开门；命中双通道；死亡回检查点且能力仍在；重生安全朝向；窄屏 HUD 不互挡。
- 最大失败：门只删碰撞，或命中只跳数字。

### 观察探索 · `html-game-observation-explorer` · VP2 · 2D 同机位
- 承诺：先给稳定基线，再在同一镜头打受控物件补丁。提交后立刻进度。禁止压暗、缩小、降对比当难度。
- 只借：同镜头基准 + 对象属性变体。
- 不借：特定地铁走廊/出口编号；准星变色剧透；先画一张图再猜坐标。
- 预算：镜头锁死；1–5 镜；异常改位置/轮廓/数量/文字/行为；媒体走 VP2。
- 关键画面：基线+本轮+提交钮同屏；无惩罚基线扫描；正常轮认真放过；异常不压暗仍可指；正确后立刻进度；误报只指不匹配维；漏报给区域或类别；窄屏目标仍可点。
- 最大失败：用压暗当异常，或没有正常轮。

### 资源增量 · `html-game-resource-explorer` · VP3 · 2D 状态扩张 UI
- 承诺：成长的可见物是界面变宽：新面板、新工位、新日志。开局窄。数字跳必须落到场景或日志。
- 只借：画面扩张=成长；阶段跃迁出现新板，不是数字变大。
- 不借：开局铺满仪表盘；连点汁液当主视觉；用动作战斗 HUD 或 3D 夜市当默认壳。
- 预算：开局可见控件默认 ≤4；阶段数跟玩法走；媒体 ≤4MB；单文件典型 <500KB。
- 关键画面：一动作+一资源且第二板未亮；首购栏略增；因瓶颈出现分配板；同机位窄→宽；数字与日志双落点；缺料写在界面上；阶段确认后再执行；窄屏无横向关键丢失。
- 最大失败：数字涨、场景不变。

### 生存探索 · `html-game-survival-explorer` · VP2 · 2D 四层同屏
- 承诺：活下去画成有地点的预算。四层同时可读：地图位置、身体/营地、天气或阶段、返程余量。采集制作必须改下一格可达范围，并在世界层看见。
- 只借：四层可扫；出发前能预览距离、风险、返程。
- 不借：五条同掉而世界不变；出门后才首次出现回家成本；开放世界 3D；资源按钮墙当主画面。
- 预算：1 营 + 3–6 地点；高频状态 ≤3；配方局内可查；媒体走 VP2。
- 关键画面：衰减+可采+回营同屏；出发预览；余量负则出发钮灰；制作后世界门；世界层+数字双落点；预报后选准备或撤；远征失败营地还在；首次硬失败可恢复。
- 最大失败：仪表盘动物园，或出门后才扣回家粮。

### 叙事探索 · `html-game-narrative-explorer` · VP2 · 2D 可走场景
- 承诺：走向地标、看环境、边走边选。选择立刻改姿态/语气，稍后改出口、重访物或结局种子。环境是叙事界面，不是换背景按继续。
- 只借：色稿服务地标导航；重访有差分；边走边聊时姿态能读出关系。
- 不借：原作地标符号；全屏对话框翻页；最后一题覆盖全程；必需句只藏在不可重播语音里。
- 预算：4–6 主场景 + 2–3 重访变体；对话条不盖死出口；媒体走 VP2。
- 关键画面：事+可走目标+会改状态的选择同屏；远近地标；选择后姿态变；重访灯/物/人/出口已变；对讲与场景同屏；同义假选项被姿态顶回；汇合后历史仍可指认；窄屏出口可点。
- 最大失败：只有下一页，或重访同一张图。

### 合成竞技 · `html-game-merge-tactics` · VP5 · 2D SVG 正交棋盘
- 承诺：字即单位。半秒内能回答：这两块能不能合（轮廓同形叠加且级可分），以及谁在打谁（朝向、连线、伤害数字至少一项）。颜色闪不是战斗。
- 只借：一格一字可指认；合成腾格；自动战不靠色闪。
- 不借：系统字体当单位；水墨上下分屏；具名武将剪影；用 tooltip 补不可辨字形。
- 预算：每枚单位一份 SVG path（静止/战斗）；主链视觉深度 3；字形包目标 <300KB 内联；零远程字体；媒体 ≤2MB。
- 关键画面：抽取键+空格+首个 SVG 字同屏；合成腾格且轮廓变；满格只剩合/回收/停抽；谁打谁可读；静止 vs 战斗 path；拼名空槽三态；废字无光环；窄屏格+命条+抽取键仍可辨。另要 `file://` 或断网字形仍在。
- 最大失败：`font-family` 当单位，或只靠色闪表示交战。可辨识未跑不得标本管线视觉 PASS。

跨类禁借：解密顶栏搜词、怪谈互斥公文墙、岗位边检桌，互不升成对方主画面。

## 4. 五条生产管线

共享阶段：风格圣经 → 一张可运行关键帧 → 最小资产包 → 垂直切片 → 全状态 → 截图矩阵 → 独立评审 → 只返工最大差距。禁止圣经前批量出图。禁止把「再生成一张更好看的」当返工。

**预算锚（未真机证明）：** VP1 媒体 ≤8MB，滚动点按无 >100ms 假死，先砍装饰静帧不砍来源差。VP2 媒体 ≤40MB，状态切换 ≤400ms，不用视频当房间，先砍视差不砍使用前后对。VP3 媒体 ≤4MB，先砍装饰图。VP4 媒体 ≤25MB，30fps 地板，先砍非主循环动画不砍能力门两态；60fps 只可写愿望。VP5 媒体 ≤2MB，无整屏闪 >3 次/秒，先砍特效不砍格与字形。首包：本地 http 越过加载后一次输入有可见反馈，目标 ≤3s。主线默认不依赖远程。

### VP1 真实界面
网页解密 / 规则怪谈 / 岗位模拟。圣经：所有者列表；每所有者栏宽、导航、标题色、正文字号、页脚、纸/屏材质；年代用控件形态写，不写「复古」。关键帧：开局三十秒能在像素上回答「我是谁、今晚干什么、工具在哪、第一下点什么」。最小包：CSS 组件壳，不把宣纸图铺到导航；壳用系统栈或已许可的一款字。垂直切片：一次真提交，界面变，错单有句子。禁止用插画房间冒充公文，禁止 Canvas 粒子当网站氛围。

### VP2 分层场景
点击 / 观察 / 叙事 / 生存。圣经：相机高度俯仰与是否一层视差，全游戏锁死；角色:门:手持物三个数；每房背景/中景可互动物/前景/热区，≤6 层。观察必须同一机位基线+变体，禁止改全局亮度当异常。生存四层槽位不随剧情搬家。关键帧：一间已能点的房，一次使用或提交后世界或进度立刻变。最小包：可点底图或分层图 + 热点多边形；离散状态帧；角色默认 2 朝向。禁止 The Room 式拖转谜盒；禁止开局大岛迷雾全图。

### VP3 状态扩张 UI
资源增量。圣经：阈值或阶段 ID → 新出现的面板；开局可见控件 ≤ 合同数；「我变强了」必须是新板或新槽；三色里哪一色专用于瓶颈。关键帧：小界面能做第一下生产；一次跃迁后屏幕变宽，截图能并排证明。最小包：DOM/CSS 为主，装饰图 ≤ 合同张数。禁止开局仪表盘，禁止把挂机数字跳动当成长。

### VP4 Canvas 动画
动作探索。圣经：侧视或俯视锁一种；玩家剪影在合同像素下能与背景分离；能力门无/有两态有形状差；命中语言（受击闪、击退、停顿）三选至少二；HUD 全在 DOM，Canvas 不画必读小字。关键帧：同一条旧路，无能力撞门有「缺什么」，有能力后能过。最小包：一张图集或统一骨骼；idle/walk/jump/atk/hurt/door-blocked/door-open。禁止 DOM 拼角色代替碰撞体；禁止滤镜抖动冒充受击。

### VP5 SVG 字形棋盘
合成竞技。圣经：格像素（含窄屏最小格）；笔画粗细外框留白全套同一；朝向或攻击连线；伤害数字停留 ms；合成是轮廓变化不是加笔画。关键帧：满格、腾格、一次合成、一次自动战谁打谁。最小包：每单位 SVG path；中英共用字形，差异只在标签字符串。禁止系统字当单位，禁止两套字形包，禁止用水墨吃掉轮廓。可辨识受试者不含作者、设计文档读者、识字同事。未跑 = `UNTESTED`，本管线视觉不得 PASS。断网 / 清缓存 / `file://` / 窄屏字形仍在。

## 5. 十四维与状态机

开评前维上可留 `UNTESTED`。开评后缺证据必须改 `HOLD`，不得再用 `UNTESTED` 装没看见。

| 值 | 谁可写 | 下一步 |
|---|---|---|
| UNTESTED | 未开评的事实状态 | 开评后不得再留 |
| PASS | 仅独立评审人 | 有运行截图或规定实测，且评审人 ≠ 制作人 |
| REWORK | 仅独立评审人 | 点名单一 `largest_gap`，只返工这一处 |
| HOLD | 仅独立评审人 | 停视觉扩面，回到工作流最早坏步 |

`contract_status`（制作人）：`UNTESTED | DRAFT | CANDIDATE`。`review_status`（评审人）：`UNTESTED | PASS | REWORK | HOLD`。截图项 `status` 只有 `UNSET | UNTESTED | N/A | PRESENT`，不创造截图 HOLD。开评后缺张：截图项仍 `UNTESTED` 或 `N/A`，D13 与 `review_status` 写 `HOLD`。

`CANDIDATE` 前置（缺一不可）：通用 12 张齐或每张 `N/A`+`na_reason`；该类专属至少 8 张齐或有理由的 `N/A`；许可表非空；D1–D14 不能全是 `UNTESTED`。

总评 `PASS` 另要：D11 烟测已跑；`reviewer_role ≠ producer_role`；VP5 的字形记录不是 `UNTESTED`。

**D1 首帧类型识别：** 陌生人看第一屏 3 秒，不读设定，能否说出本局主动词？类型不靠标题字幕声明。
**D2 信息层级：** 主操作区、状态区、叙事区是否分开，且主循环大部分时间发生在主操作区？
**D3 风格合同一致：** 抽 3 张不同场景，能否指认同一相机、同一角色:道具比、同一主材质？
**D4 资产完整度：** 必需资产是否每项都有文件、状态数和有效引用？有无临时代换矩形冒充主循环对象？
**D5 关键状态可读：** 空白、加载、错误、暂停、成功、失败、选中、禁用是否各有可指认画面，且不只靠颜色？
**D6 动作反馈：** 一次主动词输入后，哪里在预算时间内变了？能否写下「点/键/拖 ____ → ____ms 内 ____ 处变化」？近答案是否另有画面且不是正解？反馈是否不唯色、不只靠音频、不依赖 hover？
**D7 色/光/字形：** 是否钉了三锚 + `material_id`？强调色是否绑功能？字形若是玩法单位，是否以 SVG path 交付？
**D8 空间维度：** `2D|2.5D|pseudo3D|true3D` 是否开局写死？若 true3D，是否仍挂一条 VP 且附录填全？
**D9 响应式可操作：** 320 CSS px 宽能否完成主动词？触控是否可点且不依赖 hover？
**D10 性能预算：** 媒体体积、整包体积、首包可交互、运行帧是否落在该管线数字内？是否有本地 http 记录？
**D11 无障碍底线：** 关键状态不唯色？静音、键盘、触控能否走同一段主线？有无大面积 >3 次/秒闪烁？减动后主反馈是否仍在？设置名写「减少闪烁 / 减弱动效」，不写防癫痫安全。
**D12 原创与许可：** 包内素材能否随包分发？有无商标、官方切图、品牌字体当主视觉？许可表是否有文件名、来源、许可证、是否 AI 辅助？
**D13 截图证据链：** 通用 12 + 专属 ≥8 是否齐或标 `N/A`？是否运行中截的？路径是否 `visual/{genre_profile}/{build_id}/{nn}-{slug}.png`？
**D14 管线匹配：** 是否走对应 VP？AI 图是否受同一相机/比例/线/材质/光约束，而不是逐张自由提示词？

无障碍 7 步烟测：缩到手机宽主按钮可点；只键盘走到第一个主线点；只触控走同一段（宣称移动则必测）；关声走同一段；减弱动效后主反馈仍在；状态不唯色；无整屏频闪。未开评缺步 = `UNTESTED`；开评后缺步 = D11 `HOLD`。

## 6. 截图矩阵

只认运行中画面。每张旁写一行：输入、画面变化、对应维度。无变化描述不算证据。构建闸用 http(s)；`file://` 只可辅助。循环方法：改一块 → 截一张 → 与 before 并排 → 只写最大差距。

**通用 12 张（十类都要）：**

| nn | slug | 必须能看出 | 维 |
|---|---|---|---|
| 01 | boot-first-screen | 3 秒认主动词 | D1 D2 |
| 02 | core-verb | 主动词进行中 | D6 |
| 03 | success-feedback | 做对后哪一块变了 | D6 D5 |
| 04 | near-fail | 近答案，不是正解也不死档 | D6 |
| 05 | recovery | 失败后可继续 | D5 |
| 06 | narrow-320 | 320 CSS px 主操作仍可点 | D9 |
| 07 | keyboard-focus | 焦点顺序与可见顺序一致 | D11 |
| 08 | touch-targets | 触控可完成同一段，否则 N/A | D9 D11 |
| 09 | muted-or-reduced-motion | 静音或减动后主反馈仍在 | D11 D6 |
| 10 | non-color-state | 同一状态的形状或文字差 | D7 D11 |
| 11 | empty-or-loading | 空或加载，不是白屏 | D5 |
| 12 | error-or-pause | 错误或暂停可恢复 | D5 |

**类型追加（主类型才做，其余 N/A）：** 解密 13 两源并排 14 搜索未命中 15 隐藏页异皮 16 静帧不露未获 token。怪谈 13 两份以上守则并排 14 纸张语体差 15 成组提交。岗位 13 四区同屏 14 案卷离开 15 班后承担。点击 13 使用前 14 使用后回访 15 组合失败。动作 13 无能力撞门 14 有能力同门打开 15 命中 16 新档/死档/触控开局。观察 13 基线同机位 14 异常改物件不是亮度 15 提交后进度。资源 13 开局窄 14 同机位扩张 15 瓶颈停产。生存 13 四层同屏 14 出发前风险 15 返回消耗。叙事 13 选择前 14 选择后差分 15 重访。合成 13 满格 14 腾格 15 谁打谁 16 窄屏格命条抽取 17 字形离线仍在。

发布前：通用 12 + 类型追加 + 第 3 节该类 8 张专属，都要齐或 `N/A`+`na_reason`。

**before / after：** 同一相机、同一场景、同一输入态、同一窗口宽。文件成对：`{nn}-{slug}-before.png` 与 `{nn}-{slug}.png`。并排看不出去掉哪块装饰会丢主循环，那块就不是本轮该加的。

## 7. true3D 项目例外

真 3D 不是第六类型管线。先选 VP1–VP5，再叠加附录。`true3d_exception.enabled=true` 时必须填：

- `reason`：为什么 2D / 2.5D / 伪3D 不够
- `engine`：用哪套浏览器 3D 运行时
- `models_uv_pbr_or_material`：模型、UV、PBR 或等价材质如何随包
- `rig_animation`：骨骼与动画片段
- `export`：导出格式、缩放、朝向、是否含多余节点
- `lighting`：灯光 Rig 与曝光
- `lod_fallback`：LOD 以及 WebGL 失败时的 2D 回退画面
- `measured_perf`：真机帧率与包体；未测标 `UNTESTED`，预算数字标「发布线预算锚，未真机证明」

禁止用 PNG 卡片、预渲染静帧墙、单张英雄图冒充 3D 资产。点击探索即使开了本例外，仍禁止把主循环改成自由旋转谜盒。未声明例外就把真 3D 操作当默认主循环 = D8 `HOLD`。

## 9. 停止条件

出现任一条，写 `HOLD`，停止加装饰、停止再出图、停止扩场景：

- 主动词、胜负、关卡逻辑与旧版不一致
- 键位、点击、拖拽、触控手势丢了或必须悬停才能用
- 旧存档读不回且没有迁移
- 许可不清、疑似盗用、商标或品牌字进了主视觉
- `pipeline_id` 与主类型默认不一致且没有书面改道理由；或十类共用一张画法
- 媒体或整包超出该管线预算，且砍的是主循环对象而不是装饰
- 主线依赖远程大资源且失败白屏
- 开评后仍无运行截图、无许可表、无烟测
- 修画面必须改玩法标本或分发形态才能「好看」

`HOLD` 之后只做：回滚到回滚点，或回到工作流第 1 / 3 / 4 步中最早坏的一步。禁止用更多特效、更多 AI 图、更厚滤镜盖住缺口。
