## 任务：加「真相拼图」——分层真相，玩家亲手连线索

### 现状
线索是碎片化过场，玩家「看过就忘」。两个未填的坑：第二条店规为何是陷阱（悖论缺铺垫）、现任老板是谁（工具人废案）。

### 目标
每晚收集的线索进「线索板」，玩家自己把线索连成结论，分层揭开真相：
- **表层真相**：老板 = 上一班没敢数钱的人（首通可见）
- **深层真相**：纸扎铺来历 / 恒老板为何变孤魂 / 猫是什么（需多周目拼图）

### 实现要求
1. **线索板**：
   - `newState()` 加 `clues: []`（已收集线索 id 数组）。
   - 线索在剧情里自动收集（关键 then 文本触发 `st.clues.push('xxx')`）。
   - 线索板界面：点「线索」按钮打开，显示已收集线索卡片。
2. **比对机制**：
   - 玩家可选两条线索「比对」，两条能互证 → 连线+高亮，揭示一条真相结论。
   - 用 `CLUE_LINKS` 数据定义哪些线索对能互证、比对出什么结论。
3. **分层真相**：
   - 表层真相（老板=上一班）：线索对「老板短信/老板消失/钥匙」互证即可拼出，首通可见。
   - 深层真相（纸扎铺/恒老板/猫）：需要特定线索对 + 二周目猫视角解锁的信息才能拼出。
4. **线索内容**（克制文风，无 jump scare）：
   - 陈师傅「店以前是纸扎铺」→ 线索 id `paperShop`
   - 店规第二条「墨色深是后添的」→ `rule2Added`
   - 账本「历代夜班记录，有我的名字」→ `ledger`
   - 老板短信「接不接得看运气」→ `bossPhone`
   - 猫视角「老人先对猫点头，像认识很久」→ `catKnowsOld`
   - 中山装老人「夜班要有人接」→ `needRelief`
   - 等等，具体按剧情延展。
5. **真相结论**：
   - 表层：`老板是上一班`（拼出后，结局 dawn 的文案补完这句，让「钥匙扔三次」更完整）
   - 深层：`纸扎铺→恒灯便利的历史`（拼出后解锁一段隐藏文本）
6. **核心红线**：五条店规原文、商品道具、pickEnding 现有判定（含新增分支）不动。真相拼图是新增信息层，不改变结局判定（只补充 dawn 结局的文案，不改判定）。
