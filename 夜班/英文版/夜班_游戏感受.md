# 《夜班 · 恒灯便利》游戏感受（诚实版）

通关时间：完整五晚 × 1 轮，达成「灯还亮着 / 正常下班」结局。
主观评分参考：氛围 9/10，叙事 8/10，玩法 6/10，打磨 6.5/10。

## 优点

1. **氛围极佳**。便利店、雨夜、灯管频闪、收音机电流声，几个元素就把"夜班便利店不该有人却一直有人来"的恐怖立住了。没有廉价 jump scare，靠文字和细节（湿发男人"地板却一直是干的"、白裙女人"灯下没有影子"）制造不安，非常高级。

2. **五条店规是真正的游戏机制**，不是摆设。每条都在特定场景被验证：收纸钱会变成"编制"、后间不给进、猫的决定最大、天亮前别数钱。玩家在"老板催你收钱"和"规则警告你"之间拉扯，体验到了规则类怪谈的核心张力。

3. **选择题有后果且有伏笔**。小雅那句"收下不该收的就会留下来"后来真的对应了纸钱陷阱；猫粮投入在拦门/拦后间时获得了回报。这让每一次选择都有分量。

4. **人物是有名字的熟客**。林阿姨、王师傅、周晓晚、保安吴师傅、司机陈师傅——他们不只是提需求的NPC，各自带一条生活线，让这家店"有人情味"，也让最后"正常下班"的结局特别暖。

5. **结局有回甘**。"现任老板是上一班没敢数钱的人""钥匙扔了三次终于扔了出去"，一句话把整家店的历史闭环，立意完整。

6. **有存档**。中途卡住时刷新页面，能通过"继续值班"回到进度，对多结局游戏是基本盘。

## 问题与意见

1. **打字机动画没有"进行中"提示，非常容易卡住**。第3晚周晓晚的对话很长，文字打完前页面上没有任何"点击继续"或"…"指示，也没有快进引导。我以为卡死，来回点击、等待，还一度误判为 BUG，最终是靠"多等两秒"才出选项。建议：打字过程中显示"▌"闪烁光标或"…"；对话结束后明确出现"点击继续"；给对话框加一个"单击快进/跳整段"的轻交互。

2. **经济系统对普通玩家偏苛刻**。一夜营业额撑死 ¥30~60，而好道具（监控 ¥80、桃木 ¥60）贵得离谱，等价于不吃不喝两晚。为了活命必买灯管 ¥50 后，几乎整局没现金进货，第4、5晚只能"零进货"裸奔。建议：提高白天/经营收入、降低大件价格，或让"不买大件也能靠策略活命"真正成立。

3. **部分情节缺一个"结果呈现"**。比如"多看一眼"几乎每次都是安全的，缺少真正的风险收益（掉san/惹怒鬼）；"请他天亮再来""送她到门口"这类选择，事后没有明确反馈这次选择影响了什么，玩家会怀疑选项是装饰。建议给关键选择加一个结算时的"你做的某件事产生了影响"提示。

4. **菜单和布局的滚动体验一般**。进货页很长，道具按钮和"开始值班"在窄视口下会互相遮挡、需要手动滚动才找得到；进货后页面重新渲染，按钮编号/位置会变，自动化操作时尤其明显。建议做成固定侧栏或分段页签，避免长列表+遮挡。

5. **文本偶尔被截断**。个别长句在对话框里被硬截断（如第3晚小雅的台词只显示到一半），需要等打字动画才能看全，第一次读会漏信息。建议优先保证长句不被视觉裁切。

6. **多结局探索成本高**。每个分支都要重走完整五晚，缺少"章节跳转/选择回看"功能，"再值一轮"完全清空重来。建议加入已读剧情快进 + 结局收集列表，降低重复游玩负担。

## 总结

《夜班》是一款氛围和叙事都很出色的规则类怪谈小品，五条店规把"经营"和"恐怖"咬合得很好，结局有温度。它的问题集中在操作流畅度（打字机卡顿、布局遮挡）和数值平衡上。如果做一版交互打磨和收支重平衡，它完全配得上"完成度很高"的评价。

—— 来自一次诚实的一周目玩家体验
