# 闸门调用模板（codex 只读验收）

本文件是给 codex CLI 做质量闸门时用的 prompt 模板，确保「别撞车」约束落地。

---

## 一、codex review（轻量只读审 diff）

调用方式：
```
/Applications/ChatGPT.app/Contents/Resources/codex review \
  --base <base-ref> 2>&1
```

## 二、codex 完整验收（独立闸门，只读）

调用方式（用 exec，prompt 内必须显式声明只读）：

```
/Applications/ChatGPT.app/Contents/Resources/codex exec \
  "你是独立质量验收闸门。对你当前工作目录里的单文件 HTML 游戏做只读验收。硬约束：1) 禁止调用 cursor CLI 或任何其他 agent；2) 禁止写任何文件、禁止修改任何代码；3) 你只读代码、只运行只读检查命令、只输出验收报告。验收维度：语法完整性、单文件自包含、无遮挡无崩、状态机闭环、结局可达性、核心设定未被破坏（五条店规原文/真相回环/猫当裁判/关键人物/无jump scare风格）。最终输出 PASS / REWORK / HOLD 三选一 + 逐条证据路径。" \
  2>&1
```

## 三、撞车检测（每次闸门前必查）

```bash
# 确认没有 cursor 进程在跑
pgrep -fl cursor-agent
# 确认没有其他 codex 进程在跑
pgrep -fl codex
```

规则：cursor 开发期间不跑 codex；codex 验收期间不跑 cursor。串行执行。

## 四、cursor 开发调用模板

```bash
cd "/Users/Zhuanz/Desktop/项目/01_民俗恐怖游戏/夜班"
```
