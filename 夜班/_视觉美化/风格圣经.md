# 夜班 · 规则怪谈工作台圣经

路由：html-game-rule-horror / VP1 / 2D。工作台是**恒灯便利夜班柜台**，不是边检亭。

## 北星能力

玩家不读说明书也能看见：

1. 自己在柜台后值班（店景层次：店内照片 → 雨幕 → 暗角 → 人物立绘 → 柜台叠层）。
2. 手上不止一张纸，且纸有不同主人。
3. 选项、库存、猫眼是柜台工具，不是任务 HUD。

## 明确不借

边检护照格、拒章滑轨、海关玻璃窗、荧光检票台、全站一张皮肤、远程 Noto、新立绘。

## 纸张所有者

| 所有者 | 载体 | 可指认差（至少三项） |
|---|---|---|
| 店（油印店规） | `.rules` | 黄油纸底、衬线、暗红编号底线 |
| 后来的手（后添第二条） | `.ink-fresh` | 暖黄条、左侧焦糖竖标、加粗 |
| 某人铅笔 | `.pencil` | 冷灰等宽、✎ 前缀、字距松 |
| 临时贴条 | `.rules-sticky` | 黄便利贴、无衬线、左边胶带 |
| 纸条背面 | `.rules-verso` | 更浅纸、虚线框、微旋 |
| 角色纸（非店规） | 角色规页同一抽屉不同衬线/边 | 不跟油印店规同色同边 |

没有任何一张「看起来更官方所以全真」。互斥只存在于文案逻辑，不靠某一张纸更烫金。

## 店景层次（每场景 ≤4 层可读）

1. 照片店景（外/内）
2. 雨幕 + 灯管晕（伪元素，减动后雨幕仍在）
3. 人物立绘
4. 柜台叠层 + UI 纸/选项

## 控件

- 主按钮/选项/图标/步进器/留下·不留：**≥44px**
- `:focus-visible` 3px，所有者色不同（选项用纸色、主按钮用墨色、幽灵钮用霓虹）
- 320 / 390：选项仍可点，标题字缩小，猫眼不挡主钮
- 静音：钮上「音/静」字形，不只靠颜色
- 减动：停雨动画与闪灯；雨幕透明度保留
- 非唯色：warn 虚线+叹号；神智低条纹；污名规则「墨污」戳

## 禁改玩法

五条店规原文、`buildNight` 七晚、`pickEnding` / `ROLE_ENDINGS` / 14 结局 ID、全部 `hengdeng-*` storage keys、空格/长按、进货/猫眼逻辑。
