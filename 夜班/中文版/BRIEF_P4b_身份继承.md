## 任务：加「身份继承」——roguelite 内容倍增

### 目标
每通关一个结局，解锁一个「下一任身份」（当猫/当恒老板/当小雅/当保安），同一家店换身份 = 换规则 = 换视角，内容量几何倍增。

### 实现要求
1. **解锁机制**：
   - `localStorage` 存 `unlockedRoles`（数组），通关某结局时 push 对应身份。
   - 主界面加「身份选择」页：已解锁身份可点选，未解锁灰显+提示「通关 XX 结局解锁」。
2. **身份 → 结局映射**：
   | 通关结局 | 解锁身份 |
   |---|---|
   | dawn 正常下班 | （默认夜班员，已有）|
   | cat 交给猫 | 猫 |
   | joss 接了班 | 恒老板（孤魂）|
   | ferry 送她离开 | 小雅 |
   | void 变成客人 | 保安吴师傅 |
   | fired 关灯走人 | （无新身份，或解锁隐藏）|
3. **换身份 = 换规则**（核心）：
   - **猫身份**：无现金系统，有「猫的规则」（拦人/观察），主循环变成「判断谁不该进」。
   - **恒老板（孤魂）身份**：不能碰真钱、只能收纸钱，「孤魂的规则」。
   - **小雅身份**：只能买不能卖，「顾客的规则」。
   - **保安身份**：巡逻、核对花名册，「保安的规则」。
   - 每个身份有专属的规则提示 + 专属结局。
4. **实现策略**（避免大改引擎）：
   - 身份继承是「同引擎换规则集」，不是重写。
   - 加 `roleRules(role)` 返回该身份的规则列表；加 `roleState(role)` 返回该身份的初始状态（猫无 cash、恒老板无真钱等）。
   - 每个身份一个「专属开场 + 规则 + 专属结局文案」，复用现有引擎循环。
5. **核心红线**：五条店规原文、商品道具、pickEnding 现有判定不动。身份继承是「新增身份维度」，一周目（夜班员）流程完全不变。
