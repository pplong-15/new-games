# 《夜班·恒灯便利》升级版 · 5 玩法方向机制设计

> 阶段：P1 玩法设计（只设计，不写代码）
> 依据：P0 审计结论 + 现有代码结构（数据驱动，5晚→7晚扩容）
> 核心红线：五条店规原文、规则怪谈×经营、真相回环、猫当裁判、四维数值、关键人物、无jump scare风格、多结局骨架 —— 全部不动

---

## 总设计原则（来自四标本研究，全方向共用）

1. 核心动作 3 秒能懂，复杂度全在后面解锁的系统里。
2. 系统逐关解锁（玩家刚好需要时出现），禁止开局全摆出。
3. 难度爬坡 = 每晚加一个新变量，禁止同操作换皮。
4. 反馈双落点：即时数字 + 落到剧情一句话。
5. 故事靠「做」不靠「听」。
6. 第二循环才有厚度（转生/暗线/换身份）。
7. 引导是设计期硬交付：开局 30 秒玩家能答出「我是谁/要干嘛/做了有啥用」。

# 方向一：规则演化引擎（第一批）

## 核心循环一句话
每晚值班前，先看清「店规今天长什么样」，再用当晚客人的行为**验证哪条还是真的、哪条被改了**，按真规则守活到天亮。

## 玩法↔故事匹配表

| 机制 | 对应故事元素 | 为什么匹配 |
|---|---|---|
| 店规每晚「变」 | 现有埋点：第二条「墨色深是后添的」+铅笔字「纸钱不算」+第五条「描了好几遍」 | 现有最聪明的设计，但只用一次就停；升级成贯穿全游戏的主循环 |
| 玩家「验证真伪」 | 林阿姨/王师傅/陈师傅透露的店史传闻 | 让「背规则」升级成「比对+推理」 |
| 规则被「历代夜班改」 | 真相回环（老板=上一班没敢数钱的人） | 规则也在被一代代夜班员改，和「顶班」设定自洽 |

## 细致玩家操作流程（第 3 晚为例）

- **看到**：值班前抽屉里店规纸，第一条墨色正常，第二条旁边多了半行没擦干净的铅笔字「纸钱不算」，第五条被人重新描过，字迹比昨天深。
- **能做什么操作**：点「规」按钮 → 打开店规查看页 → 看到 5 条店规 + 异常标记（第二条有铅笔痕、第五条描深）。
- **操作映射到故事**：铅笔痕=上一班夜班留下的警告；描深=有人反复提醒「没天亮别数钱」。
- **触发**：当晚中山装老人递红纸钱 → 玩家要判断「第二条『钱都收』这条今晚还成不成立」→ 选择「收」或「不收」。
- **失败分支**：收 → 发现是纸钱 → 若玩家昨晚没发现「纸钱不算」的铅笔痕 → sanity -14（原设定）→ 若发现了 → 仍收但 sanity -4（玩家明知是纸钱还收，代价轻但仍有）；不收 → 触发「拒收」正确路径，sanity 不降，但老人留下一句「夜班要有人接」。

**关键差异（vs 现在）**：现在玩家「见绿就点」或「背下答案」；升级后玩家必须**每晚重新读店规、比对变化、再做判断**，规则本身成了博弈对象。

## 交互映射
- PC：点「规」按钮（HUD 上的「规」字）→ 鼠标滚轮翻看店规 → 点选项。
- 手机：点「规」按钮 → 上下滑动看店规 → 点选项。店规页顶部固定「今晚异常」高亮条。

## 系统解锁表（课程式）
| 晚 | 新解锁的规则演化元素 | 玩家卡在哪（为什么此刻需要） |
|---|---|---|
| 1 | 五条店规原文（教学，无变化） | 学会读店规 |
| 2 | 「铅笔字」机制：店规出现被擦写的痕迹 | 白裙女人无影子，怀疑规则真假 |
| 3 | 「墨色差异」机制：能看出哪条是后添的 | 纸钱陷阱，必须分辨第二条真假 |
| 4 | 「规则冲突」机制：两条店规互相矛盾（如「钱都收」vs「别数纸钱」） | 湿发男人借后间 + 纸钱同时出现 |
| 5 | 「规则被污染」机制：某条店规被改写得看似正常实则陷阱 | 中山装老人查岗 |
| 6 | 「规则溯源」机制：能追查店规是哪一任夜班改的 | 账本出现，发现自己的名字 |
| 7 | 「规则裁决」机制：玩家自己决定留下哪条店规给下一班 | 交班，把灯交给愿意开着的人 |

## 难度爬坡设计
- N1：规则是死的，背就行（教学关）
- N2-N3：规则会「变」，但要玩家自己发现（铅笔字、墨色）
- N4-N5：规则「冲突」「污染」，玩家要判断哪条优先
- N6-N7：规则「溯源」「裁决」，玩家从「遵守者」变成「制定者」

每晚安插一个新变量，玩家认知负荷从「记忆」→「比对」→「推理」→「裁决」递增。

## 单关验证计划
先做第 3 晚（纸钱陷阱是核心）：验证玩家在「没发现铅笔字」和「发现铅笔字」两种情况下，收纸钱的代价是否不同；验证「不收」路径的 sanity 和 flag 是否正确。过关标准：玩家不看攻略，能靠「读店规+比对变化」判断出第二条当晚不成立。

# 方向二：生存资源管理（第一批）

## 核心循环一句话
每晚有营业额底线（付得起电费灯才不灭），你要在「卖货赚钱」和「守规保命」之间做权衡，钱和命第一次真正打架。

## 玩法↔故事匹配表

| 机制 | 对应故事元素 | 为什么匹配 |
|---|---|---|
| 营业额底线 | 「灯不能关」（店规①）+ 电费 | 灯是生存核心，灯灭=坏结局，经营压力直接接到恐怖核心 |
| 卖给非人客人 vs 拒卖 | 湿发男人/白裙女人/中山装老人 | 卖=赚钱掉神智，拒=保神智损失钱声望 |
| 声望 rep 兑现 | 吴保安/王师傅的援助 | rep 高→第4晚保安留手电、最后晚王师傅提供逃离载具 |
| 断货真实惩罚 | 熟客（林阿姨/王师傅） | 断货→客人失望→rep降→影响援助→恶性循环 |

## 细致玩家操作流程（第 4 晚为例）

- **看到**：白天进货界面，现金只剩 ¥14（昨晚听剧情没卖货），今晚电费底线 ¥30。货架空了大半。
- **能做什么操作**：进货（花现金补货）→ 或选择不进货（赌今晚现金够）。
- **操作映射到故事**：电费底线 = 「灯不能关」的机制化；不进货 = 赌注，赌客人需求少。
- **触发**：值班时白裙女人要买「咸的」→ 玩家选择卖（+¥ 但 sanity 微降）还是不卖（保 sanity 但凑不够电费）。
- **失败分支**：凌晨营业额不足 ¥30 → 灯开始频闪 → sanity 加速下降 → 若凑不够 → 灯灭 → 触发「关灯走人」类坏结局。

**关键差异（vs 现在）**：现在「现金流过宽裕、断货惩罚过轻」；升级后每晚有明确的电费底线，玩家必须真实地经营，且 rep 终于有用了（影响 NPC 援助）。

## 交互映射
- PC/手机：进货页显示「今晚电费底线 ¥X」「当前现金 ¥Y」，差额红色高亮；结算页显示「营业额 vs 底线」对比条。

## 系统解锁表
| 晚 | 新解锁的生存元素 |
|---|---|
| 1 | 电费底线（教学，底线很低几乎必过） |
| 2 | 非人客人的「卖/不卖」权衡（卖=钱+掉san） |
| 3 | rep 首次兑现（吴保安提醒危险） |
| 4 | 断货恶性循环（断货→rep降→援助消失） |
| 5 | 天气/随机客流（暴雨夜方便面雨伞翻倍） |
| 6 | 债务压力峰值（电费底线突然翻倍） |
| 7 | 最终财务抉择（把钱留给下一班 vs 带走） |

## 难度爬坡设计
N1 底线几乎必过（教学）→ N2 出现权衡 → N3 rep 兑现 → N4 断货连锁 → N5 随机变量 → N6 债务峰值 → N7 财务抉择。每晚新增一个生存变量，玩家从「随便进点货」到「精打细算」。

## 单关验证计划
先做第 4 晚（原报告说「剧情党第4晚破产」）：验证「零进货裸奔」和「合理进货」两条路径的结局差异；验证电费底线未达标时灯灭的惩罚是否合理；验证 rep 兑现（保安留手电）是否真实发生。

# 方向三：猫视角二周目（第一批）

## 核心循环一句话
首通任意结局后，解锁「猫视角」：用猫的眼睛重看这 7 晚，发现第一周目看不到的真相（谁在说谎、第二条为何是陷阱、恒老板和纸扎铺的关系）。

## 玩法↔故事匹配表

| 机制 | 对应故事元素 | 为什么匹配 |
|---|---|---|
| 猫视角 | 猫是裁判（不说话，用动作表态） | 猫天然是「上帝视角但不说破」，适合承载二周目的真相揭示 |
| 猫能看到「非人特征」 | 猫拦着不让进的人（店规④） | 玩家一周目靠文字猜，二周目用猫的眼睛直接「看到」谁是鬼 |
| 猫的「记忆」 | 纸扎铺历史、恒老板消失 | 猫是店里最老的「住户」，见证过一切 |

## 细致玩家操作流程（二周目第 3 晚为例）

- **看到**：切到猫视角后，同一个第 3 晚场景，但界面多了「猫的视野」——非人客人身上有淡淡的轮廓提示（中山装老人身后有纸扎铺的残影）。
- **能做什么操作**：正常玩 7 晚，但猫视角下多一个「猫的观察」面板，显示猫对当前客人的真实判断（一周目玩家看不到）。
- **操作映射到故事**：猫的观察=猫当裁判的机制化；一周目玩家只能靠文字细节，二周目猫直接告诉真相。
- **触发**：二周目通关后，解锁「猫的记忆」碎片，拼出纸扎铺→便利店的历史、恒老板为何变孤魂。
- **失败分支**：猫视角下玩家如果「干预」（比如替猫拦人），会破坏猫的裁判中立，触发猫的疏远，猫好感反而降。

**关键差异（vs 现在）**：现在多周目是「重看五遍动画」；升级后二周目是「换视角重读」，重玩价值翻倍。

## 交互映射
- PC/手机：二周目主界面多一个「猫视角」开关；猫视角下 HUD 显示「猫的观察」面板。

## 系统解锁表
| 二周目进度 | 解锁 |
|---|---|
| 首通任意结局 | 解锁「猫视角」开关 |
| 二周目 N1-N3 | 猫能看到非人客人的轮廓 |
| 二周目 N4-N5 | 猫的「观察」面板（对每个客人的真实判断） |
| 二周目 N6-N7 | 猫的记忆碎片（纸扎铺历史） |
| 二周目通关 | 深层真相（恒老板为何变孤魂、猫是什么） |

## 难度爬坡设计
二周目本身不是「更难」，而是「信息更多」——玩家从一周目的「猜」变成二周目的「看」，从「蒙」变成「懂」。难度体现在「猫视角下的新抉择」：知道了真相后，玩家要重新做一周目的选择，但这次是「知情选择」，道德重量不同。

## 单关验证计划
先做「猫视角开关」+ 第 3 晚的猫观察面板：验证切到猫视角后，中山装老人身上出现纸扎铺残影；验证猫观察面板对每个客人的判断文案正确。过关标准：二周目玩家能说出「一周目我没发现的真相」。

# 方向四：真相拼图（第二批）

## 核心循环一句话
每晚收集的线索进「线索板」，玩家自己把线索连成结论，分层揭开真相：表层（老板=上一班）首通可见，深层（纸扎铺来历/恒老板为何变孤魂/猫是什么）要亲手拼出。

## 玩法↔故事匹配表

| 机制 | 对应故事元素 | 为什么匹配 |
|---|---|---|
| 线索板 | 每晚对话里散落的线索（纸扎铺、店规第二条、老板消失） | 把现有「碎片化过场」升级成「主动连结论」 |
| 分层真相 | 表层=老板是上一班；深层=纸扎铺/恒老板/猫 | 解决报告两个缺陷：第二条悖论缺铺垫 + 老板废案 |
| 成组确认 | 两条线索能互相印证才算结论成立 | Obra Dinn 式，防止玩家瞎猜 |

## 细致玩家操作流程（第 6 晚为例）

- **看到**：账本之夜，店里出现一本账本，上面有历代夜班的进货记录，玩家发现自己的名字已经列在账本上。
- **能做什么操作**：点开「线索板」→ 看到已收集的线索碎片（如「陈师傅说店以前是纸扎铺」「店规第二条是老恒走后添的」「账本上有我的名字」）→ 拖拽两条线索放到一起「比对」。
- **操作映射到故事**：线索比对=玩家亲手推理「老板=上一班」；账本=真相的实体化。
- **触发**：玩家把「老板=上一班没敢数钱的人」拼出 → 解锁表层真相 → 结局文案里这句话得到补完。
- **失败分支**：玩家只找齐线索但没主动「比对」→ 结局仍能通（表层真相在结局自动揭示），但深层真相（纸扎铺/恒老板/猫）需要二周目继续拼。

**关键差异（vs 现在）**：现在线索是「看过就忘」的过场；升级后线索进「线索板」，玩家主动连，且真相分层，深层真相需要多周目拼图。

## 交互映射
- PC/手机：线索板界面，线索卡片可点选、可两两「比对」，比对成功会连线+高亮。

## 系统解锁表
| 晚 | 解锁的拼图元素 |
|---|---|
| 1 | 线索板（空，教学：收集第一条线索） |
| 2 | 线索「比对」机制（两条线索能比对） |
| 3 | 表层真相碎片（老板消失、纸扎铺） |
| 4 | 深层真相碎片（恒老板、纸钱） |
| 5 | 线索「成组确认」（需 N 条互证） |
| 6 | 账本（真相实体化，我的名字出现） |
| 7 | 真相「裁决」（玩家决定揭不揭开深层真相） |

## 难度爬坡设计
从「收集」→「比对」→「成组确认」→「裁决」，认知负荷递增。真相分层保证：表层首通可见（不卡进度），深层需要多周目（增加重玩价值）。

## 单关验证计划
先做线索板 + 第 6 晚账本：验证玩家能收集线索、能比对、能拼出「老板=上一班」；验证深层真相（纸扎铺/恒老板/猫）确实需要二周目才能拼全。过关标准：一周目玩家能拼出表层真相，二周目玩家能拼出深层真相。

# 方向五：身份继承（第二批）

## 核心循环一句话
每通关一个结局，解锁一个「下一任身份」（当猫/当恒老板/当小雅/当保安），用不同身份重开，体验同一家店的不同侧面——同一家店、同一 7 晚，换身份=换规则=换视角。

## 玩法↔故事匹配表

| 机制 | 对应故事元素 | 为什么匹配 |
|---|---|---|
| 身份继承 | 真相回环（老板=上一班，链条上每个身份都是一环） | 「顶班」设定天然支持换身份 |
| 换身份=换规则 | 不同身份面对不同的店规/约束 | 同一家店，猫看到的是「裁判视角」，恒老板是「孤魂视角」，小雅是「顾客视角」 |
| roguelite 内容倍增 | 同一 7 晚，换身份=内容几何增长 | 付费游戏的时长+重玩价值 |

## 细致玩家操作流程（通关后为例）

- **看到**：通关「正常下班」结局后，主界面解锁「身份选择」：默认身份（夜班员）+ 新解锁的「猫」「恒老板」等。
- **能做什么操作**：选择「猫」身份 → 重开游戏 → 用猫的视角和规则玩 7 晚（猫的规则=「别让不该进的人进来」等）。
- **操作映射到故事**：猫身份=店规④「猫拦着不让进的人别硬留」的执行者视角；恒老板身份=「夜班要有人接」的孤魂视角。
- **触发**：不同身份有不同的专属结局和真相碎片，拼出完整的「纸扎铺→便利店」历史。
- **失败分支**：某个身份下做出与身份冲突的选择（如恒老板身份下「把灯交给猫」），触发该身份的专属坏结局。

**关键差异（vs 现在）**：现在单身份单线；升级后多身份多线，同一家店从多个视角讲完整，内容量几何倍增。

## 交互映射
- PC/手机：主界面「身份选择」页，已解锁身份可点选，未解锁身份灰显+提示「通关 XX 结局解锁」。

## 系统解锁表
| 解锁条件 | 身份 | 规则变化 |
|---|---|---|
| 通关 dawn 正常下班 | 夜班员（默认，已有） | 五条店规（现有） |

| 通关 void 变成客人 | 保安吴师傅 | 「保安的规则」（巡逻、核对花名册） |

## 难度爬坡设计
不同身份不是「难度递增」，而是「规则换一套」——猫身份无现金系统、恒老板身份不能碰真钱、小雅身份只能买。每个身份都是新的约束组合，玩家要重新学一套规则。

## 单关验证计划
先做「猫身份」：验证通关 cat 结局后解锁猫身份；验证猫身份下无现金系统、有「猫的规则」；验证猫身份的专属结局。过关标准：猫身份能完整玩 7 晚并解锁猫的专属真相碎片。

# 开发分批总结
