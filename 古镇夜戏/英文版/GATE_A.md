# 闸 A　古镇夜戏

## 七维

1. 人物立住　PASS。程石要齐人，沈南要退，狄厚只是告假，豆皮絮叨，吴窗念稿。
2. 台词像真人　PASS（开发按站点书写习惯：文旅套话、剧团立规、论坛漏白、档案冷陈述）。
3. 剧情顺　PASS。告假→空行→套票→手机号入簿→已开锣不退。
4. 恐怖成立　PASS。名分错位，不跳脸，不中邪。
5. 线索闭环　PASS。购票页 vs 须知 → 龙套帖 → 票号登录 → 三本账 → 交割。
6. 厚度　PASS。关系网≥3；两层反转（规则不退→写成角→齐人靠游客）；白戏暗线。
7. 可英文化　PASS。谜题靠合同与班规冲突，不靠拆字。
