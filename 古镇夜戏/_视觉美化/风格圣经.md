# 古镇夜戏　风格圣经　VP1 / 2D　网页解密

全游戏锁死下列字段。本局不出新图；既有 `assets/stills` 只许 CSS 框，不许换提示词。零引用 `assets/base` 整目录移出玩家包，不进主循环。

## 相机

- 正交网页平面。无透视、无视差、无 Canvas 粒子。
- 比例跟所有者走：文旅小店 960；剧团表 778；茶馆 960；博客 780；文献红头 1000；地方号 677；票务后台 960；问答 960；卷宗 min(800,92%)；检索 720。禁止收成全站同一套圆角卡。

## 线宽（1x）

- 文旅导航：实心 Tab，上圆下不圆（小店身份，不是全站圆角卡）。
- 剧团：1px 灰表框 + 蓝横幅斜边搜钮。
- 茶馆：蓝头 1px 版块表。
- 检索命中：1px 底边虚线列表，0 圆角。
- 未命中：2px 虚线井。
- 禁页：4px 双线。
- 卷宗：1px 实线外框 + 1px 点线 meta；终局钮左侧 6px 实边。

## 主材质 `css-dom-town-ticket-archive`

- 文旅公开壳：褪色米黄纸 + 静帧细灰边。
- 剧团：2005 灰底 778 表，宋体 12px，链 #00e。
- 茶馆：2008 蓝头论坛，Tahoma/SimSun。
- 票务后台：浅青塑料咨询台，蓝钮，不是小店橙 Tab。
- 检索/禁页：CRT 浅青磷光底 vs 黑红斜纹。
- 档案交割：发黄卷宗宋体缩进。
- 文献：红头金线，不是小店。
- 地方号：677 白文栏。
- 问答：蓝头 + 最佳答案绿条。
- 说明书：短信回执灰卡，禁止用在假官网。

## 三色锚

| 角色 | 色 | 绑什么 |
|---|---|---|
| 主 | `#f9ebde` | 文旅小店纸底 |
| 次 | `#e0f7fa` | 票务后台 / 检索索引底 |
| 功能强调 | `#c8161d` | 文献红头、禁页关闭、交割报缺 |

强调色不绑「恐怖」「怀旧」。橙 `#d15c20` 只留给文旅搜钮与现行 Tab。后台搜钮用 `#007bff`。

## 焦点

`:focus-visible` 3px。小店深色描边；禁页黄虚线；检索青绿；后台蓝；其余近黑。

## 触控

搜框、搜钮、打开购票页、查询提交、终局四钮、主链 Tab：min-height 与可点边 ≥44 CSS px。320 / 390 顶栏折行，搜框不得盖住正文第一句。

## 状态不唯色

- 未命中：虚线井 + 「0 项 / 0 hits」等宽字。
- 命中：编号 + 下划线链。
- 禁页：斜纹 + 双线 + 禁止/DENIED 戳。
- 报缺：终局 `.err` 虚线井 + 句子。
- 登录错：红虚线匣 + 前缀标记，不只红字。
- 假入口 `javascript:void(0)`：删除线 + 虚线框。
