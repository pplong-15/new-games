# 金鹊录像厅　风格圣经　VP1 / 2D　停更录像厅搜词调查

全游戏锁死下列字段。本局不出新图；既有照片只许 CSS 滤镜/框，不许换提示词。

## 相机

- 正交网页平面。无透视、无视差、无 Canvas 粒子。
- 比例：所有者自带栏宽（小店/博客/论坛约 900–960；县情 1000；地方号 677；卷宗 min(800,92%)；搜索结果 720）。禁止改成全站同一套 12 栏圆角卡。

## 线宽（1x）

- 小店导航：实心 Tab，上圆下不圆（这是小店身份，不是全站圆角卡）。
- 卷宗：1px 实线外框 + 1px 点线 meta + 2px 红戳。
- 搜索命中：1px 底边虚线列表，0 圆角。
- 未命中：2px 虚线井。
- 禁页：4px 双线。
- CRT 扫描：1px 横纹，opacity ≤ 0.06，减动后仍在（这是材质不是动画）。

## 主材质 `css-dom-ticket-crt-archive`

- 公开小店：褪色米黄纸 + 旧照片细边，像厅里电脑生成的免费模板。
- 搜索/禁页：CRT 浅青磷光底 vs 黑红斜纹，像停更镜像的索引机。
- 档案：发黄票根/卷宗，宋体缩进，红戳旋转。
- 后台：浅青咨询台塑料壳，蓝钮，不是小店橙 Tab。
- 论坛：蓝头表格楼层。
- 地方号：白文栏长文，不是红头公文。

禁止把上述六种收成同一张白卡。

## 三色锚

| 角色 | 色 | 绑什么 |
|---|---|---|
| 主 | `#f9ebde` | 小店纸底 |
| 次 | `#e0f7fa` | 后台页 / 搜索索引底 |
| 功能强调 | `#c8161d` | 县情红头、禁页关闭 |

强调色不绑「恐怖」「怀旧情绪」。橙 `#d15c20` 只留给小店搜钮与现行 Tab，不当成全站 CTA。

## 焦点

`:focus-visible` 3px。小店深色描边（避免橙上橙）；禁页黄虚线；搜索青绿；其余用功能强调或近黑。

## 触控

搜框、搜钮、进厅、登录提交、提示、终局两钮、主链 Tab：min-height 与可点边 ≥44 CSS px。320 / 390 顶栏折行，搜框不得盖住正文第一句到看不见。

## 状态不唯色

- 未命中：虚线井 + 「0 项 / 0 hits」等宽字，不只灰字。
- 命中：编号 + 下划线链。
- 禁页：斜纹 + 双线 + DENIED/禁止戳。
- 锁：登录盒左侧 8px 实心门闩；已登录手册是青左边条 + 须知块。
- 假入口 `.dead`：删除线 + 虚线框。
