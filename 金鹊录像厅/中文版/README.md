## 怎么玩

1. 打开 `introduction.html`，点「进入录像厅」。
2. 读首页公告，搜 **加映场**。
3. 一次一个汉字词。空串、空格两词、英文不会打开隐藏页。
4. 卡关用站内帮助的停运客服（四档提示）。
5. 票根、老侯、陆小棠、空座、田麦读齐后，搜 **末班票** 进入选择。

存档键：`jinque-hall-v1`（本机 localStorage）。
