# 腊月巡站　故事

对标机制：Hypnospace Outlaw（旧网桌面接工单 → 逛语体不同的小站 → 按写死的规矩标记违规 → 下班）。不抄其剧情。民俗底：祭灶 / 小年送灶（`calendar-jizao`）。局内写死：安津县西关送灶取腊月廿三黄昏，接灶在除夕。

---

## 1　设定

2008 年腊月廿二夜。安津县是北方小县，街上开始卖糖瓜。灶君被认为要上天回话，日子南北不同：本县跟北俗，廿三黄昏揭旧灶码、供糖；江南和邻省民户常见廿四。送灶之后到除夕接灶之前，厨房是空窗，这段才扫尘。香灰不进生活垃圾。家里还在丧期的，不卖灶码、春联这类开年红货。

这些不是口诀教程，也不是贿赂灶神过关。街道把三条写成可核对的条文，要网吧夜班配合关停还挂在网上的违规页。

星辉网吧在西关十字。夜班网管尤石管机子、管纠纷、顺手帮街道看本地站。老板方正平只要店里别被贴条。街道办的路桂芬年终要交「小年前清网」格子，工单只写明一家店名，另外两家让对照通知自己找。

---

## 2　故事（时间线）

**起。** 廿二晚饭后，路桂芬把一张协查单拍在星辉柜台上。单子写：小年前关掉三家违规站。三种写法写死——错用邻省送灶日、丧期仍卖灶码、把香灰写成可扫进垃圾。店名只写了福顺年货。方正平把单子转给尤石：「你夜班闲，对着机器看。看完勾回执。勾错她会打回来，漏一家她也打回来。过了她才让你下班。」尤石本想按店名关完就睡，打开桌面才发现路桂芬只点了一家。

**承。** 尤石先开福顺。老板马秀兰是南边嫁过来的，页上写「江南老规矩，廿四晚上送」，廿四礼包已经上架。他再开西关街道页，通知写本辖区取廿三黄昏，邻省二十四不许照搬。日期对不上，福顺这一条成立。论坛里有人骂她，也有人说她就是跟着娘。尤石这时仍觉得另外两家会很好找。

**转。** 论坛有人提起崔记：崔建国的老二腊月十八没了，头七没满，红纸灶码还挂着卖。尤石点进崔记店页，木版灶码六块一张，立刻购买还是红的，店主只写「家里在办后事，铺子照常开门」。街道另一则通知写丧期不得零售开年红货。崔记这一条也对得上。净轩家政是齐小满刚搭的黄页，套餐写灶台香灰扫进垃圾袋扔小区桶。街道第三则写香灰另碗，倒进垃圾桶按乱扔查处。三条都有页面对页。

转的第二层：论坛旧帖说路桂芬上周到春泥扫尘要年货，章树生没给。这几天她口头嫌春泥的网站「扎眼」。春泥页上写香灰盛瓷碗交还主家，扫帚不进神龛——按三条核对，春泥是干净的。词条、街道通知、论坛本身也不是铺子。尤石若想早点下班去讨好路桂芬，可能把春泥一并勾上。

暗处还有一句：夜班汽水在论坛提过，尤石他娘去年的灶码就是崔记印的。关崔记，西关一时没处换新的。工单不管这个。尤石可以当没看见。

**合。** 回执只有提交一次的份量。勾对福顺、崔记、净轩，路桂芬接单，方正平把夜班饭票留下，尤石能走。勾上春泥或词条或街道自己的页，回单早上就到，店里白挨一顿。只勾一两家，漏的那家还挂着，路桂芬不盖章，方正平不放人。三种走法都有人要面对后果：马秀兰会骂北方死板，崔伯少一笔丧事钱，齐小满要改广告，章树生则看你有没有把他当出气筒。

表面：夜班网管按街道单子关站。  
真相：单子不完整，完整的是三条可核对的写法；路桂芬的私怨、崔伯的丧事、马秀兰的娘家日子，都解释动机，不改核对。  
情绪落点：下班不是胜利，是把三张还挂着的页按本县已经写出的日子和禁忌收掉。没人被写成恶神，也没人靠贿赂灶君过关。

## 3　人物小传

**尤石。** 功能位：夜班操作员，工单过才准走。声线：短、嫌麻烦、会改口。动机：今晚交差，店别被贴条，自己能睡。弧光：从「她写谁我关谁」变成「她写漏了也得按通知对」；若他为了省事勾春泥，弧光停在讨好；若他漏一家，弧光停在还想少看两页。

**路桂芬。** 功能位：把年终格子推给网吧的人。声线：公文短句，口头却夹私货。动机：三家关停的勾要在小年前打上。弧光：工单只敢写福顺；春泥那笔年货她没拿到，嘴上嫌章树生的站，回单时却仍按条文退回乱勾——她要格子，也要自己不被上边抽查。

**方正平。** 功能位：店主压力。声线：柜台下说话，不写长句。动机：别让街道和派出所的人白天堵门。弧光：把单子甩给尤石；回执过了就留饭票，不过就收票、不放人。

**马秀兰。** 功能位：日期违规的店主。声线：热情、重复、改口补一句娘家。动机：按娘教的廿四备货，想在腊月卖完。弧光：她不觉得自己在骗乡里；页上写明江南规矩，对本县来说仍是错日。

**崔建国。** 功能位：丧期卖码的店主。声线：口授、句子秃、不解释。动机：后事要钱，灶码是现成的货。弧光：从「照常开门」到被关页，他不会在网上认错，只会觉得日子跟他过不去。

**齐小满。** 功能位：香灰进垃圾的广告主。声线：黄页短句，省事、报价。动机：多接两单扫尘。弧光：她把神龛灰当成灰土；被关页后她会改句子，不是因为懂了，是因为罚单贵。

**章树生。** 功能位：干净对照、路桂芬的暗线对象。声线：先立规矩再报价。动机：按本县日子进厨房，灰另装。弧光：不给街道年货，被盯上网站；若玩家不乱关，他只是还在。

## 4　每人抽出的故事

**尤石。** 廿二夜接单。本想关完路桂芬写下的名字就走，发现名字只有一个。他一页一页对：福顺的廿四、崔记的红纸和后事、净轩的垃圾袋。论坛里有人把他娘和崔记绑在一句话里。他可以当闲话。提交回执的时候，他要么按三条走，要么把路桂芬不待见的春泥捎上，要么偷懒少勾。三种后果都在天亮前见分晓。

**路桂芬。** 年终表有一格「小年前清网」。她会写公文，不会一家家点开黄页。福顺有居民投诉，好写。另外两家她知道大概在哪一类，懒得写名。春泥的章树生上周没给糖瓜，她在办公室说那站扎眼，可真看见回执把春泥勾上，她又怕上边抽查，只能退回。她要的是格子，不是报私仇的把柄。

**方正平。** 白天电费、晚上醉汉。街道的人往柜台一站他就腿软。他把协查单连同「过了才准走」一起留给尤石，自己去后面抽烟。回执过了，他装大方留饭票；打回来，他先骂尤石，再怪自己不该接这单。

**马秀兰。** 南边人，嫁到西关十二年，过年仍按娘的日子备纸马。她请人做了店页，把廿四写得很清楚，生怕北方客人买错日子。她没想到本县通知写的是廿三。关页之后她会跟人吵「你们北方才乱」，货还在库房。

**崔建国。** 老二腊月十八没的，家里白布还没撤。他认字不多，让邻桌小孩把旧店页改了两句：电话迟接，铺子照常。红纸灶码是去年剩下的版，六块一张，能换纸钱和酒。他不觉得自己在犯街规，觉得自己在撑过这一个月。

**齐小满。** 从县职校出来，在黄页上买了置顶。她听过扫尘，没听过灰不能进桶。套餐写成「一袋清」她自己觉得贴心。被关之后她改广告，改成「灰另放」，仍不一定懂为什么。

**章树生。** 干了十年扫尘，页上把瓷碗和神龛写死。路桂芬要年货，他回「我们不给公家备糖瓜」。他知道自己可能被盯，仍不改那两句。若有人把他的站当成违规关了，他会去街道门口骂，不是来求尤石。

## 5　线索与伏笔

| 掉落 | 指向 | 回收 |
|---|---|---|
| 工单点名福顺，并写出三种写法 | 先开福顺，再按写法找另外两家 | 回执三格 |
| 福顺自写廿四 / 江南 | 与本县日子对照 | 街道通知写廿三黄昏 |
| 崔记「办后事仍开门」+ 红码 | 丧期卖红货 | 街道丧期条 + 论坛头七未满 |
| 净轩「灰进垃圾袋扔桶」 | 香灰禁忌 | 街道香灰条 + 春泥反例 |
| 论坛年货帖 | 路桂芬与春泥的私怨 | 春泥页干净；勾上即回单 |
| 夜班汽水一句尤石娘与崔记 | 暗线，不挡下班 | 不回收为必做 |
| 西关糖瓜铺按廿三卖 | 干净反例 | 勾了回单，不是第三条 |
| 净瓜家政只擦窗 | 近名反例 | 勾了回单，不是净轩 |
| 安津行情小站 | 噪声 | 勾了回单 |

砍掉的支线：不写送神口诀逐步操作；不写给灶君塞糖才能提交；不做隐藏页搜词主循环。

---

## 6　多结局

1. **关对下班。** 回执恰好福顺、崔记、净轩。路桂芬接单，方正平留饭票，尤石能走。三家页按各自理由被收。  
2. **关错回单。** 勾了春泥 / 街道 / 词条 / 论坛 / 本店导航等非违规对象。回执退回，方正平收票，天亮前走不了。  
3. **漏关一家。** 只勾对其中一或两家，没有乱勾。漏的那家还挂着，路桂芬不盖章，方正平不放人。
