Empty window, then the broom

Between Kitchen God send-off and New Year’s Eve welcome-back, the kitchen is spoken of as an empty window. Older talk puts year-end sweeping in that span, so a still-on-post Kitchen God is not swept away. This entry covers timing talk only. It does not rewrite shop ads. It does not write subdistrict fines.

An empty window is not a stall. It cannot take goods down. It cannot go on a return slip as a shop. Copy that writes sweeping as dump-with-the-dirt is ad wording. The fine is in that subdistrict notice, not in this entry.

Intern note: someone asked me to name which housekeeping is clean and which wrote ash as trash. I did not. An encyclopedia that writes a shop name becomes an ad. To see a shopfront, go to the shop page.
