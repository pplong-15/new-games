# 腊月巡站　风格圣经　polish-20260823

相机锁死：正视 2D 页面，无透视、无一层视差、无 Canvas 粒子。桌面是 XP 监视器平面；假官网是 2005–2010 表格式站点平面。中英同一相机，英文开局不加中文首图。

比例：桌面图标约 32px 色块 + 字；XP 窗框 3px；假官网栏宽按所有者（见下），不得全站 960。

线宽 1x：1px 实线为主，XP 斜边用 1px 高光/阴影对；禁止 8px 圆角白卡。

主材质 `material_id=crt-lcd-2008-table`：LCD 亮底 + HTML table/float 壳。引言唯一纸面：油印协查单。噪声站仍是网页，不是插画房间。

光：顶光、无动态光。强调色只绑功能（提交、焦点、退件），不绑情绪。
