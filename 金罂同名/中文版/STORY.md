# 金罂同名　故事

对标机制：The Roottrees are Dead（多源检索 + 同名按出生年 / 住址 / 迁出年排除）。
民俗基底：捡金二次葬在当代法规下收成骨灰堂格位；游戏动词是认格、对册、出建议，不写开棺洗骨。

---

## 第1段　设定

桐溪县金罂堂是县城骨灰安放处。西河乡下原来流行捡金：初葬若干年后把骸骨装进金罂，再进祖塔或另葬。条例收紧以后，乡里把金罂和后来的火化骨灰一起收进堂，按格位出租。堂里仍把柜子叫金罂格，合同上写的是安放格位。

夜班权限只有三件事：开册、查档、写出认领建议。不能改原格，不能挪金罂，不能替家属签字。同名核验写在班前纸上：只看姓名不够，必须对上出生年、户籍住址、迁出年份，对不上就不得写死格号。

认错格位，当夜按租赁合同违约：扣押金，出事故单，主任追责到值班工号。家属认领当晚不交建议，按弃权，格位次日进入待清理。

金罂堂的册会落后于现场。迁出回执缺附件时，格位仍挂原名。迁坟那年标签淋过雨，重贴过。谱牒数字化还把同名两房合成过一条。这些都不能当「册上有名就是还在」。

本局所有县名、人名、乡组、堂号均为虚构，勿去现实对照。

## 第2段　故事（时间线）

表面：今夜有个外地赶回的女儿要认「林阿盛」的格。册上恰好两行同一个名字。  
真相：两行是两个人。女儿记混了祖屋和户口。西厅那行已经迁出，只是册没销干净。

### 起（二〇二六年八月二十一日　十七点到接班）

褚慈上金罂堂夜班不满一个月。白天主任裘晚秋把一条短讯甩进值班机：林秋禾今晚要认格，册上两个林阿盛，写错格按违约，你自己担。方永石上周退了，交接本还摊在抽屉里。

秋禾坐在值班室塑料椅上。她妈吴晚香住院，十年租期预审今夜截止，格位证复印件被茶渍盖住厅号。她开口先说柿树坪，又说九六年厂里招工搬走，再补一句承租人是她妈。三句话分别指向两个人。

褚慈打开格位册。西厅〇七：林阿盛，二〇一一年迁坟转入，备注仍写在册。南厅二二：林阿盛，二〇一六年火化直入，状态在租。同名两行并排，夜班灯管嗡嗡响。

玩家此刻能做的：读册、听口述、按班前纸去公告/谱页/旧报对字段。认领单随时能交，交早了容易写错。

### 承（对源，先信口述）

秋禾的柿树坪和九六年，对得上西厅那行。西河乡二〇一一年迁坟名单里，柿树坪十二号有个林阿盛，一九三八年生，金罂转入西厅。县报二〇〇三年讣告里，水泥厂退休的林阿盛享年六十五，妻邱秀兰，子林柏年。谱牒德房页也是这个人：一九九六年迁县，住过工人路筒子楼。

先信解释成立：秋禾要认的就是西厅〇七，九六年搬走的那房。

### 转（第一层推翻）

旧报另一份讣告把这层掀开。二〇一六年桐溪晚报：东巷居民林阿盛，一九五一年生，同年十一月病逝，也是享年六十五，妻吴晚香，女林秋禾。南厅格位证正本扫描上，承租人栏写的是吴晚香，原址城关东巷三号，未迁出。

秋禾自己报的承租人名字，只出现在南厅这一边。西厅那边的儿子叫林柏年，不叫秋禾。

二〇一八年乡栏还有一则迁出备案：西厅〇七申请人林柏年，金罂转祖山寄放点，回执缺火化存根复印件，暂不销册。方永石交接本里用圆珠笔点过同一件事：西厅那个，柏年来电说迁出后勿再接待认领。

西厅挂名不是人还在，是手续缺一张纸。

### 合（第二层，以及今夜抉择）

谱牒勘误条把口述为什么会串说清楚。东巷这房清光绪年间从柿树坪析出。秋禾小时候走亲戚，把祖屋和父亲户口说成一处。二〇一九年数字化还曾把「德房阿盛（一九三八）」和「东巷阿盛（一九五一）」合成一条，后来按出生年拆开。迁坟那年西厅标签淋湿重贴，更不能只看柜面字。

褚慈要在今夜交出认领建议。四种写法会走向不同后果：

1. 听柿树坪，认西厅〇七。  
2. 对上吴晚香和东巷，认南厅二二。  
3. 不敢写格号，暂缓。  
4. 把同名冲突报给主任，今夜不认。

秋禾等在椅子上。裘晚秋要的是一纸建议，不是原物批准。灯管还在响。

## 第3段　人物小传

**褚慈**  
功能位：夜班新人，工号落在建议单上，违约也落到这张工号。  
声线：短、复述、改口，敢把字段再读一遍，不敢发明结论。  
动机：想把这班安稳交出去，不想明天被柏年和秋禾两头堵。  
弧光：接班时只看见两个相同的名字 → 对完出生年和迁出后，能说出「挂名不等于还在」。

**林秋禾**  
功能位：到场家属，口述会把两房故事焊在一起。  
声线：急、补句子、自己打断自己，外地口音夹着乡下称呼。  
动机：给住院的母亲办续租授权，今夜过了预审就轮到待清理。  
弧光：开口认柿树坪 → 若被问到母亲名字，才回到东巷那条线上。

**林柏年**  
功能位：西厅那房的儿子，已经办过迁出，人不必到场。  
声线：只出现在讣告、备案和交接本的来电摘记，句子硬。  
动机：金罂转走后不想再有人认那一格，免得两家抢寄放点。  
弧光：二〇〇三年丧事从简 → 二〇一八年把格退掉 → 留下「勿再接待」的电话。

**方永石**  
功能位：退班师傅，把排除法写在本子上，也把当年的失手写在本子上。  
声线：絮叨、重复、爱用「先」和「别」，像怕后班只看一行。  
动机：自己贴错过标签，怕新人再写错格。  
弧光：迁坟夜图快重贴 → 退班前把「对年、对址、对迁出」写成死规矩。

**裘晚秋**  
功能位：主任，施压，不替夜班对字段。  
声线：短讯体，不解释，只甩后果。  
动机：预审今夜必须有字，事故单不能落到科室。  
弧光：白天丢下一句「你自己担」 → 若夜班上报同名，她得白天接手，会不痛快但接。

**吴晚香 / 邱秀兰**  
功能位：两位妻子，用来把同名拆开。吴晚香是南厅承租人，今夜住院。邱秀兰只出现在零三年讣告和德房谱。  
声线：本人不出场，名字当字段。  
弧光：不需要完整弧，她们是排除的尺子。

## 第4段　每人抽出的单独故事

**褚慈的一夜**  
傍晚接班，短讯已经在机子上。秋禾比他早到，塑料椅还是热的。他先把册翻到林姓，看见两行阿盛，手心出汗。方叔的本子夹着一张旧标签边，字被水洇过。他按本子去对讣告和乡栏，发现享年都是六十五，出生年却差十三年。交建议的时候，他要么把格号写死，要么把冲突推给白天。无论哪一种，工号都在单上。

**林秋禾的一天**  
省城的医院走廊里，母亲让她回县里「把格认下来」。她记得小时候回柿树坪吃席，也听大人对过九六年招工。格位证在包里泡过茶。进堂以后看见册上两个一样的名字，她先指西厅，又把母亲的名字说出来。她不是来骗格的。她把两房的记忆叠在一张嘴里。

**林柏年的十八年**  
父亲二〇〇三年走，丧事按厂里习惯从简。二〇一一年乡里迁坟，金罂进西厅。二〇一八年他请有资质的改葬服务把金罂转去祖山寄放，堂里说回执还缺一张火化存根复印件，册先挂着。他打过电话：迁出以后别再让人认。今夜他不在桐溪。若有人把西厅重新认走，他明天才会知道。

**方永石的尾班**  
二〇一一年迁坟夜，金罂标签淋湿，西厅〇七他重贴过一次，事后在本子上记了「别只看柜面」。后来同名越来越多，他把对年、对址、对迁出写成三行。退班那天本子没带走，他知道后班会懒得问人。

**裘晚秋的白班压力**  
续租预审卡在夜班，是科室排班的结果，不是她要刁难新人。她清楚册会脏，也清楚夜班若上报同名，白天她得自己对。所以短讯只写违约。她要的是纸上有字，好应付明天的电话。

## 线索与伏笔

| 掉落 | 指向 | 回收 |
|---|---|---|
| 格位册两行同名 | 不能按姓名认 | 认领单若只填姓名会撞车 |
| 秋禾说柿树坪、九六年 | 西厅 / 德房 | 乡栏名单、德房谱、零三年讣 |
| 秋禾说吴晚香 | 南厅承租人 | 南厅证、一六年讣 |
| 两份讣告都写享年六十五 | 年龄不能当唯一项 | 必须回到出生年 |
| 二〇一八迁出备案 + 柏年来电 | 西厅挂名已空 | 认西厅即违约 |
| 谱牒勘误（非必走） | 口述为何串房 | 解释秋禾不是撒谎 |
| 湿标签（非必走） | 柜面字不可靠 | 加强「只出建议」 |

被砍的支线：不写捡骨师傅上门、不写两家祠产官司、不写柏年本人到场对质。

## 多结局

1. **认甲（西厅〇七）**  
   触发：建议格位选西厅。  
   逻辑根：按口述里的柿树坪和九六年认人，没把吴晚香和迁出备案压上去。次日柏年问责，合同按违约走。

2. **认乙（南厅二二）**  
   触发：建议格位选南厅。  
   逻辑根：承租人、住址、出生年对上秋禾之父；西厅已迁出。秋禾能给吴晚香办预审。

3. **暂缓**  
   触发：今夜不出格号。  
   逻辑根：怕写错。秋禾过了预审点，南厅进入待清理，裘晚秋记一份迟交。格没写错，租期却险。

4. **上报同名冲突**  
   触发：把冲突报给主任，今夜不认。  
   逻辑根：夜班承认两行无法只按姓名闭合。白天裘晚秋接手，秋禾须补母亲证件。不违约，也不当场给格。

## 单案种子（备查）

- 标题：金罂同名  
- 钩子：册上两个林阿盛，女儿只带来一张泡过茶的复印件  
- 主角：褚慈  
- 欲望：把认领建议写对，好下班  
- 冲突：口述把两房焊在一起，册又没销干净  
- 反转：先信西厅迁出户，再被妻子名和迁出回执推翻  
- 结尾钩子：挂名不等于还在  
- 所需素材：格位册、两张证、两份讣、两房谱、两则乡栏、交接本

## 与已有题的差异

不是阴间媒婆访客，不是质检员六站批准原物，不是登山灰栏目搜隐藏页，不是录像库，不是文旅官网加游记。玩家是骨灰堂夜班，循环是多源检索后按出生年 / 住址 / 迁出年排除同名，只交认领建议。
