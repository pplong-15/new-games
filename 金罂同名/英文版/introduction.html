Trouble in the book

Jinying Hall keeps village jinying (bone urns) and later cremation ashes in one lease book. Flip the Lin pages and you will see it: one printed name occupies two rows. One row is WestHall. One row is SouthHall. A wrong niche is a same-night contract breach. Deposit and accident sheet land on the duty badge.

Night shift may only write a claim recommendation. You cannot change the original niche, move what is in a cabinet, or sign for anyone. The township used to talk about jianjin, second-burial bone collection into a pagoda. The hall now only does placement and MoveOut filings. Procedure notes stay off this machine.

How to match

Same name: first birth year, then registered address, then MoveOut year. A name match alone is not enough to lock a hall number. The lookup box takes one continuous token. No spaces. Names print as LinAsheng. Places print as PersimmonFlat. Years are four digits, like 1996. Township notices, register scans, and old obituaries are separate sites. A field matches only when the field matches.

The WestHall row note already says GraveMove in. When a MoveOut receipt is missing an attachment, the book can still post the old name. Do not treat a posted name as still present.
