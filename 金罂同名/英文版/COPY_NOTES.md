# 金罂同名　文案习惯（humanize 0.9）

书写习惯是站点的，不是人物标签。改口、漏字段、重复嘱咐都留着。不灌水，不加金句。

| 站点 | 习惯 | 怎么写 |
|---|---|---|
| 班前纸 `introduction.html` | B 冷陈述体 | 短句交代工号、权限、对年对址。不抒情。 |
| 格位册 `desk/hall.html` | B + 口述夹 A | 册是表格。秋禾那段拖、改口、补母亲名字。裘晚秋短讯不解释。 |
| 西厅 / 南厅抄件 | B 冷陈述体 | 证核栏像夜班打印机。水渍、茶渍当事实，不写阴森。 |
| 交接本 | A 絮叨漏白体 | 方永石重复「先看」「别写」，把湿标签和来电漏出来。 |
| 抽屉便条 | A 短嘱咐 | 一张一句。第四张才把厅号说死。 |
| 认领单 | B 冷陈述体 | 权限写建议。回执按已读档换理由，不写海报句。 |
| 乡栏三页 | D 史笔半文体 | 乡镇油印口气，略土。名单、备案各说各的缺件。 |
| 谱牒四页 | C 讲古立规体 | 先立「乳名跟生年一起录」，半文半白。勘误承认合条是录文偷懒。 |
| 旧报三页 | B 报馆体 | 厂宣传科与邻里供稿口气不同。两则都写享年六十五，生年分开。 |
| 联查中转 | B 机内回执 | 「找到 N 份」「查不到」「未对夜班开放」。不出现搜词、汉字词。 |

## 声口对照（防同声）

- 褚慈：复述字段，改口，不敢发明。  
- 秋禾：急，先报柿树坪，再补吴晚香。  
- 方永石：啰嗦，怕后班只看一行。  
- 裘晚秋：短讯，甩后果。  
- 柏年：只在摘记里留一句「勿再接待」。

## 结局动态

`desk/claim.html` 的理由段读 `localStorage.jy_seen`：看过南厅/一六年讣、看过迁出备案、看过勘误，各走不同句子。判定优先级与按钮一致，不把认西厅说成认南厅。

## 未采用

不用 E 群嘴论坛、不用 G 感官轰炸、不用 F 结巴预演。本局没有贴吧楼，也不写开棺现场。
