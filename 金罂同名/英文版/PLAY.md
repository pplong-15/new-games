## Token DAG

```
[开局：册上两行、口述柿树坪/九六年/吴晚香、查档框]
        │
        ├─ 检索「林阿盛」→ 多源命中（讣、谱、证、名单、口述、预审、合条、邻乡附卷、窑讣）
        ├─ 检索「柿树坪」或读十一年名单 → T-甲址年
        ├─ 检索「吴晚香」或读南厅抄件 / 一六年讣 → T-乙妻女
        ├─ 读零三年讣 / 德房页 / 配氏页 → T-甲妻儿（邱秀兰、柏年）
        ├─ 检索「林柏年」或读十八年备案 / 柏年摘记 → T-甲已迁出
        ├─ 读东巷谱 / 析出纪事 → T-乙未迁、串祖屋
        ├─ 检索「石灰窑」或「一九四四」（词已写在格位册）→ T-丙排除
        └─ 读勘误条 / 合条工作页（可选）→ T-合条已拆
                │
                └─ 交认领建议 → 认西厅 / 认南厅 / 暂缓 / 上报
```

无环。认领单无前置锁，避免死锁；交早了走错结局。勘误条与石灰窑附卷不是必经。丙不能认进今夜两格。

## 逐题五步

### 题0　接班看见两行

- 看到：班前纸说明夜班、同名、只出建议；进厅后格位册两行林阿盛与秋禾口述同屏。  
- 能做：点西厅/南厅抄件，或把册上的字送进查档框。  
- 映射：任务成立，先信解释（柿树坪那房）被摆在嘴边。  
- 触发：持有开局 token。  
- 错：直接交西厅。系统照收，走违约结局。

### 题1　同名检索

- 看到：查档框。册上已有「林阿盛」。  
- 能做：检索该名，中转页列出多份档，不是一份。  
- 映射：Roottrees 同名膨胀，必须再对字段。  
- 触发：命中讣告、谱页、抄件、乡栏，以及邻乡附卷、窑上讣。  
- 错：空格、数字、字母 → 查不到。把石灰窑一九四四当成今夜两行之一。

### 题2　用住址和出生年拆甲

- 看到：口述「柿树坪」「九六年」。  
- 能做：检索柿树坪，或打开十一年名单、德房页、零三年讣。  
- 映射：甲 = 一九三八、柿树坪十二号、一九九六迁县、子柏年。  
- 触发：T-甲址年、T-甲妻儿。  
- 错：把享年六十五当成同一人。两份讣都写六十五。

### 题3　用妻子名拆乙

- 看到：口述里的吴晚香。  
- 能做：检索吴晚香，读南厅抄件、一六年讣、东巷谱。  
- 映射：乙 = 一九五一、东巷三号、从未迁出、女秋禾。  
- 触发：T-乙妻女。  
- 错：继续用柿树坪压过妻子名。

### 题4　用迁出年排除西厅

- 看到：西厅备注「迁坟转入」、交接本「柏年来电」。  
- 能做：检索林柏年或迁出，读十八年备案、西厅抄件状态栏。  
- 映射：西厅金罂已转走，册未销。  
- 触发：T-甲已迁出。  
- 错：认仍挂名的西厅。

### 题5　交建议（伦理点）

- 看到：认领单，权限写「建议」，四路可点。  
- 能做：认西厅 / 认南厅 / 暂缓 / 上报。  
- 映射：夜班不批准原物；写错格违约。  
- 触发：对应四结局。文案按已读档生成理由。  
- 错：四路都合法提交，没有「必须选对才能点」。

## 每步解锁

不靠刷新楼层。新档靠检索命中或站内链。交接本、乡栏、谱馆、旧刊在格位册页脚和短讯里已经点名，前几步是送的。

抽屉便条按点击展开，不替勾选。

## 四级提示（游戏内便条，不写死格号在前三档）

1. 方向：同名先对年、对住址，别急着填厅号。  
2. 范围：乡栏和旧报各有一份名单/讣闻，别合成一个人。  
3. 操作：秋禾嘴里的母亲名，只印在其中一份安放抄件上。  
4. 完整：南厅对吴晚香；西厅已迁出未销。可认南厅，或上报同名。不要认西厅。

## 烟雾弹 / 死路

| 项 | 作用 |
|---|---|
| 两份讣告同写享年六十五 | 年龄误认 |
| 秋禾先说柿树坪、九六年 | 先信西厅 |
| 西厅仍挂名 | 以为人还在 |
| 检索开棺、洗骨、发财 | 档未对夜班开放 |
| 积水短讯、筒子楼拆迁预告 | 补工人路门牌，不作认领 |
| 石灰窑林阿盛（一九四四） | 第三条同名。生年/址/葬地都对不上今夜两行，只供排除 |

## 新手不迷路

1. 三十秒同屏：褚慈、今夜认格、查档框、册上两行。  
2. 链：林阿盛 → 多命中；柿树坪 → 甲；吴晚香 → 乙；林柏年 → 迁出；石灰窑／一九四四 → 丙排除。  
3. 检索有中转页；交建议有回执。  
4. 进度用「建议未交 / 已交」和册上待核两行，不上游戏条。  
5. 前步送词（林阿盛、柿树坪、吴晚香、一九九六、石灰窑、一九四四写在格位册），中段才要主动对迁出。

## limits（设计层）

- 网页抄件只能互相对字段，不能证明金罂此刻仍在柜里。  
- 迁出备案缺附件，只能证明柏年申请过转出，不能证明祖山现场。  
- 谱牒是扫描室录文，不能当户籍原件。  
- 秋禾口述会串房，不能当唯一出处。
- 湿标签与柜面字不能当租赁册。茶渍件不能当厅号。
- 石灰窑附卷与邻县讣只能排除丙，不能认进南厅或西厅。
- 积水稿、拆迁预告只锁工人路门牌，不开格。

## 匹配度自检

- 捡金/金罂当代入口（迁坟、格位证、谱页）都变成可提取字段。  
- 每步对年、对址、对迁出，都对应故事里「两个人、一笔未销」。  
- DAG 无环，认领无悬空前置。  
- 离线闭环。  
- 开局能答：我是褚慈 / 今夜给秋禾出建议 / 写对才能避免违约。
