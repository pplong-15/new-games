That year the De branch was crowded. One line rented rooms in Chengguan. The register set up an East Lane branch. Offering tables still went back to the flat. Children knew the banquet. They did not know the later lane doorplate.

PersimmonFlat first out of Qiuhe's mouth is mostly a memory of the table. The East Lane residence column still writes Chengguan EastLane 3. A banquet does not write it back to No. 12. This room has heard that mix. The residence column does not move the pen.

This page only explains why visiting relatives can call two houses one household. It cannot be used to claim the WestHall niche for an East Lane daughter, and it cannot write a De-branch jinying as SouthHall cremation.
