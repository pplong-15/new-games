# 改名对质　文案习惯

书写习惯是站点的，不是人物标签。改口、漏字段、重复嘱咐都留着。不灌水，不加金句。屏幕不英文化。

| 站点 | 习惯 | 怎么写 |
|---|---|---|
| 班前纸 `introduction.html` | B 冷陈述体 | 工号、口头、未解除、对质入口同屏。不抒情。 |
| 夜窗 `chuang/*` | B + 窗口短句 | 覃书复述栏。屈晚禾急、重复已经跳过了。对质顶回不公布正解。 |
| 附属柜 `shu/*` | B 卷宗体 | 缪守匣只报在不在、解没解。朱笔是状态，不是故事。 |
| 谱局 `pu/*` | D 半文土口 | 纪蒲舟一口，重复承字辈、要收费单、夜不改。 |
| 须知 `zhi/*` | B 公文短句 | 名齐三栏、回执边界、夜窗只建议。不要国徽腔。 |
| 邮箱 `you/*` | B 邮件体 | 席芦冷、抄送、号写全。蓝槐骂科室短。 |
| 旧页 `kou/*` | A 絮叨漏白 | 屈晚禾记墙、记顺眼。江棠枝只催七点。屈秋蝉记香停。 |
| 问答 `wen/*` | C 讲古立规 | 先拆四套名，不给跳墙步骤。 |
| 关闭 / 禁止 | B 机内回执 | 夜窗打不开；代办不对夜窗开放。不上搜词、汉字词。 |

## 声口对照（防同声）

- 覃书：复述字段，改口，不敢发明解除。  
- 屈晚禾：急，重复已经跳过了，被指栏会顶，被指态度更顶。  
- 缪守匣：干，柜不教。  
- 纪蒲舟：半文，带单来，夜不改。  
- 蓝槐：条子短，别许原件。  
- 江棠枝：催七点，不管墙。  
- 席芦：号写全，不要并案。

## 结局动态

`chuang/result-*.html` 的理由段读已指破绽与已打开页。判定与 `js/state.js` 对齐：overreach → release → hold。

## 未采用
