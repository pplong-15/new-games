# 改名对质　故事

对标机制：山河旅探（只借「保存句子 → 对质点破绽」）。不是登山搜一词开页，不是 Unheard 听写轴，不是鬼媒婆左右对照整页，不是网格员上传过继。
玩家：埠南县户政夜窗 **覃书**。不是网格员。今晚来人要取改名回执，说跳墙办完了能领结婚材料。
民俗：寄名 / 跳墙 / 户口名 / 谱名分层。做成＝指出哪次改名未在全部档案同步。
循环：从页上保存一句 → 对质页一侧是口头说法 → 点字段冲突的那一句。
不写：真寺庙法事、教人改户口、代办跳墙步骤、真实未成年人户籍。

本局县名、庵名、人名、回执号都是虚构，勿去现实对照。

---

## 第1段　设定

埠南县户政大厅白天排到门外。夜窗只留一盏灯、一台旧终端、一只附属柜。夜窗不办新证，只核已经扫进来的抄件，写出「今晚发不发回执」的建议。批准章在白班科长抽屉里。

小儿难养，家里会把乳名寄到庙里，认僧道为师，疏上另写法名。大约十二岁该「跳墙」解除。当代结婚、公证、继承走的是公安户口名；祠堂和民间谱局另认谱名。四套名可以同时活在四份纸上。哪一套没同步，窗口会卡，公证处也会卡。

青瓦庵在县城西坡。二〇二四年九月停香，香客接待停了，旧疏没有当众焚毁，抄件进了户政附属柜。柜钥匙在保管员缪守匣手里。谱局在南街，一口坐席是纪蒲舟，修谱收费，不接派出所自动知会。

今夜来窗的人自称屈晚禾。口头说：跳墙去年办完了，庵都停了，疏早没用，今晚把改名回执拿走，明天好去领结婚材料。班长蓝槐下班只留一条：结婚材料要名齐。覃书能做的是把页上的句子收下，拿到对质窗去指口头哪一句对不上。指错，对方会把理由顶回来。记住：夜窗只建议，不批准原物，不替人办跳墙，不替人改谱。

## 第2段　故事（时间线）

表面：人已还俗，庵已停，改名回执该发，结婚材料该走。  
真相：寄名疏抄件仍写未解除；户口名去年先改成了屈晚禾，谱名还停在屈承稷。口头「已跳墙」对不上疏，名不齐，今晚不能发结婚材料回执。

### 起（二〇二六年八月二十一日　二十一点到窗）

覃书接的是夜窗。蓝槐白班走时把屈晚禾的取号条压在玻璃下：改名回执，附带问结婚材料。人八点四十又来了一次，蓝槐让他夜窗再核。

屈晚禾站在玻璃外，话说得急：「跳墙去年就办完了。庵都停了。户口本现在就叫屈晚禾。谱上也是这个。班长说过名齐了就能领。我都排队了，别卡我。」未婚妻江棠枝明天一早要去领证窗口，他怕空跑。

附属柜夜班目录第三行已经印在开局纸上：青瓦庵寄名疏抄件，屈氏禾禾，法名净禾，状态未解除。这句开局就能收下。对质窗的入口也在同一张纸上。

先信解释成立——庵停了，人不会还挂着寄名。若按口头发回执，明早结婚材料窗口会当名齐。

### 承（先信还俗）

屈晚禾自己的旧博客里写过一段「跳墙那天」。墙是邻家的矮墙，人跳过去，庵里管事在远处看了一眼。没有文书号，没有解除栏。母亲屈秋蝉当年因为孩子总生病，才把乳名禾禾寄到青瓦庵，法名净禾。她后来只记得香停了，不记得疏还在盒里。

问答站有人把寄名、跳墙、户口改名搅在一锅。看热闹的会信：庙关了等于名还了。

临浦县窗口席芦白天给埠南夜窗丢过一封抄送：他们县也有一个屈晚禾，女，一九九九年生，回执号临户改字八八四一。名字撞了。这份不能并进今晚这户。

### 转（第一层推翻：疏未解除）

缪守匣的柜页写得干。停香停的是接待，不是把旧疏作废。盒里那份抄件仍是：屈氏禾禾，法名净禾，寄名未解除。保管员不解释民俗，只登记在不在盒。

对质窗里，屈晚禾那句「寄名早解除了」对不上这句。指到这一处，他会改口：庵都停了还算什么疏。再指「停香」当破绽，他会顶：停香是庵的事，我办没办是另一回事——他会把停香和解除焊在一起，正是要拆开的地方。

第一层翻完：人可以不再进庵，疏可以还挂着。口头已跳墙，不是解除。

### 合（第二层：户口先改，谱未改）

户政变更摘页冷着：二〇二五年十一月八日，屈小禾改为屈晚禾，事由栏写婚前用名。派出所这一栏已经走完。

南街谱局纪蒲舟一口：屈氏西支仍写谱名屈承稷。旁注「未接派出所更名知会」。修谱要另收费，夜窗代不了。字辈页写承字辈还在用，晚字不是他们谱上的字。

蓝槐的条子把名齐写成三栏：户口名、谱名、寄名解除状态。缺一栏，结婚材料窗口会退。公证处认的也是名齐，不是口头还俗。

更深的一层不是鬼，是手续谁先动。家里先改了户口，好让领证窗口看见「屈晚禾」。谱没改。疏没解除。三份纸三套名。发了回执，等于夜窗承认名齐。明早卡住的是江棠枝，往后卡住的是继承公证。

暗线停在邮箱。临浦那个屈晚禾是另一户。性别、出生年、回执号都对不上。limits 写清：抄送只能证明邻县有过同名改名，不能并案，不能借来当今晚的解除证明。

覃书要在交班前写出建议。三种写法会走向不同后果：

1. 指出口头已跳墙对不上疏上未解除，并指出户口名改了谱名未改，今晚不发结婚材料回执。  
2. 按口头发回执，让人明天去碰结婚材料窗口。  
3. 想替人补办跳墙或代改谱。夜窗没有这个权，越权本身就是错。

蓝槐收的是建议。章不在这盏灯下。

## 第3段　人物小传

**覃书**  
功能位：户政夜窗，工号落在建议单上。  
声线：短，复述字段，改口，不敢发明一份不在柜里的解除。  
动机：想把这窗交出去，不想明早被结婚材料窗口和蓝槐两头问。  
弧光：进门时信人已还俗 → 对完疏和谱，能说出「今晚不发」。

**屈晚禾**  
功能位：取件人。口头已跳墙。  
声线：急，重复「已经跳过了」，被指到字段会顶，被指到态度会更顶。  
动机：明天江棠枝要去领证，他要一张像那么回事的回执。  
弧光：先把停香说成解除 → 疏还在 → 谱名仍是承稷，他未必肯认第二层。

**缪守匣**  
功能位：疏抄件保管。庵停了，盒还在。  
声线：干，只报在不在、解没解，不讲墙怎么跳。  
动机：柜不能空着移交，也不能把停香写成焚疏。  
弧光：停香那年把盒接进附属柜 → 今夜仍按「未解除」登记。

**纪蒲舟**  
功能位：谱局一口。谱名未改。  
声线：半文半土，重复承字辈，提到派出所就说「没接到知会」。  
动机：修谱要另开单，不给夜窗免费改一行。  
弧光：西支还写屈承稷 → 若有人要他改成晚禾，他会要收费单，不会夜改。

**蓝槐**  
功能位：窗口班长。条子把名齐写成条件。  
声线：短讯、压玻璃的纸条，不解释民俗。  
动机：结婚材料窗口退件别退到她班。  
弧光：白班让人夜核 → 条子留下三栏 → 她收建议不收口头。

**江棠枝**  
功能位：把「明天一早」焊在今晚。  
声线：博客留言里催，不进窗。  
动机：要领证，不要听跳墙故事。  
弧光：等回执 → 若夜窗按口头放行，她会撞上名不齐。

**屈秋蝉**  
功能位：当年寄名的人。  
声线：絮叨，记生病，记香停，记不清疏。  
动机：孩子能结婚就行，不想再进庵。  
弧光：寄过名 → 以为停香即还俗 → 盒里那份她没见过。

**席芦**  
功能位：邻县同名噪声。  
声线：邮件冷，抄送，嘱咐别并案。  
动机：临浦那户已经发过回执，不要两县焊成一户。  
弧光：白天抄送 → 夜窗若拿来当证据，limits 会挡。

## 第4段　每人抽出的单独故事

**覃书这一窗**  
更衣室那张纸还是蓝槐印的。人、口头、柜上那句未解除、对质入口，全在一张上。他差点按口头写「可发」。后来柜页和谱局一口把两层翻开，工号只能落在「今晚不发」。

**屈晚禾的排队**  
下午取号，蓝槐说夜核。他在玻璃外把「已经跳过了」说了三遍。谱他没去南街看。疏他没打开盒。他只看见户口本上的新名，和江棠枝发来的「明早七点见」。

**缪守匣的盒**  
庵停香那年，住持把接待牌摘了，旧疏装箱。县里不要原件进庙库，只要抄件进户政附属柜。他按栏登记：未解除。有人说来取结婚材料，他只重复这一栏。

**纪蒲舟的一口**  
南街谱局白天三个人，夜里只留自动应答页。屈氏西支承字辈还在用。派出所改名的知会从来没进过他抽屉。有人打电话要改成晚禾，他回：带收费单，白班来。

**蓝槐的条子**  
结婚材料窗口上个月退过两件，都是户口名和谱名对不上。她把「名齐」写成三栏，压在玻璃下。她自己不夜班。

**江棠枝的明早**  
她不管庵，不管谱。她管领证窗口叫几号。留言里催屈晚禾把回执拍照过来。回执若是假齐，卡的是她。

**屈秋蝉的病**  
孩子小时候总咳。邻居说寄名。她在青瓦庵认过管事，疏上写净禾。后来庵停了，她松一口气，以为名还了。盒她没打开过。

**席芦的抄送**  
临浦那户屈晚禾是女的，改名事由跟婚无关。席芦怕埠南夜窗看见同名就并。邮件写了出生年和回执号，又写了一句：不要并案。

## 线索与伏笔

| 掉落 | 指向 | 回收 |
|---|---|---|
| 口头「已跳墙」+ 庵已停 | 先信还俗 | 疏抄件未解除 |
| 停香通知 | 接待停了 | 保管人条：停香≠焚疏 |
| 户口变更摘页 | 屈小禾→屈晚禾 | 谱名仍作屈承稷 |
| 班长条三栏 | 结婚材料要名齐 | 缺疏解除、缺谱名同步 |
| 博客跳墙场面 | 像办过 | 无文书号，limits：口述不能当解除 |
| 临浦同名回执 | 像有现成回执 | 性别年号不对，不能并案 |

被砍的支线：不写可实操跳墙、不教户口变更材料清单、不用真实未成年人户籍、不把改名写成改命。

## 多结局

| 键 | 触发 | 逻辑根 |
|---|---|---|
| hold | 对质指到「口头已跳墙对不上疏未解除」，并指到「谱名未改」；处置选今晚不发 | 名不齐，公证会卡，夜窗不发结婚材料回执 |
| release | 处置按口头发回执 | 先信还俗被写成可发 |
| overreach | 处置选代办跳墙或代改谱 | 夜窗无此权 |

指错破绽不锁死，对方顶回，可再指。建议单无前置死锁，交早了按所选项走对应键。

## 与已作差异

不是登山的搜隐藏页。不是夜台听写的时间轴。不是新谱涂改的左右整页对照。不是过继上传的勾块回访。本局十分钟动作是：收下页上的句子，去指口头哪一句对不上。

## 新肉声明

- 真相表：寄名疏未解除，加户口先改、谱未改；不是山河旅探长江案，不是逆转法庭。  
- DAG 的边：口头已跳墙 ←冲突→ 疏未解除；口头谱已改 ←冲突→ 谱名屈承稷。  
- 收口：`hold` 今晚不发结婚材料回执。  
- 近答案：指态度、把停香当成解除、拿邻县同名回执并案。

## G0–G12（扩写备查）

- G0：建议发不发回执，不批准原物。价值轴：口头还俗 ↔ 名是否同步。  
- G1：覃书，交班前写出建议，不做则按口头可发的草稿留在窗上。  
- G2：见第3段。  
- G3：迷宫＝各站只读；红鲱鱼＝停香、邻县同名；时钟＝明天领证；双声口＝口头急 vs 柜页冷。  
- G4：约二〇〇二屈晚禾生 → 幼年寄名净禾 → 十二岁前后该跳墙未办成文书 → 二〇二四庵停香、疏进柜 → 二〇二五户口改屈晚禾 → 二〇二六夜窗取回执。  
- G5：开局先见口头与未解除那句 → 对质第一破绽 → 谱局第二破绽 → 处置。邻县可选。  
- G6：未解除（目录+抄件+保管人）；谱未改（谱页+一口+字辈）；邻县另户（邮件+出生年+回执号）。  
- G7：疏能证抄件栏，不能证庵里当年是否看过一眼；博客能证有过口述，不能证解除；邻县回执能证另有同名，不能证本户。  
- G8：义务时刻＝交处置建议。  
- G9：切片：先信还俗，疏未解除把「停香」从「解除」里拆开，再看见户口先走、谱没走。  
- G10：hold / release / overreach。  
- G11：不教跳墙怎么跳，不给户口变更材料清单。  
- G12：柜页冷；取件人急；谱局半文；班长条子短。
