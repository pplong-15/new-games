# 改名对质　专章 A

梯度：中阶单线。引擎：从页上保存一句 → 对质页一侧是口头说法 → 点字段冲突的那一句（authority 恒为 recommend）。
不套登山灰栏目搜一词，不设听写轴，不摊左右整页对照，不写网格员上传。

## 对标卡

1 类型层：封闭世界网页解密；壳/体量钉登山。本局声明：工作台 + 附件站，页数不减。  
2 机制标本：山河旅探。  
3 钉死循环：从页上保存一句 → 对质页一侧是口头说法 → 点破绽。  
4 不是：不是登山搜隐藏页（没有顶栏一词开新页）；不是夜台听写轴（没有时段定性）；不是鬼媒婆左右对照整页（对质是指一句，不是勾两栏）；不是过继上传（不勾块回访）。  
5 梯度：中阶单线。  
6 玩家：埠南县户政夜窗覃书。今晚必须写出「发不发结婚材料回执」的建议。  
7 视角：内部操作员 + 来人推送口头。不是网格员，不是质检员，不是听写员。  
8 权限：recommend。表单不开放批准原物、不开放代办跳墙、不开放代改谱。  
9 民俗：寄名/跳墙/户口名/谱名。token＝未解除、谱名未改、名齐三栏。  
10 载体：夜窗对质台 + 附属柜/谱局/须知/邮箱/博客/问答。  
11 开局三十秒同屏：覃书、屈晚禾口头已跳墙、柜目录「未解除」可收下、对质入口。  
12 第一动作：看见未解除那句，点收下，进对质，点「寄名早解除了」。送。  
13 主提交：指破绽（要已收下对得上的句子）；终局再交处置建议。  
14 成组：一处破绽一次判。不成组闪绿穷举。指错顶回，不公布正解。  
15 正确收口：`hold`。口头已跳墙对不上疏未解除；户口名改了谱名未改；今晚不发。  
16 近答案：指态度；把停香当成解除；拿邻县同名回执并案。  
17 limits：页上用局内口气写能证什么、不能证什么。邻县不能并案。  
18 失败：指错顶回；交错走出 release / overreach；可作废重开。禁止死档。  
19 站点：见下表。一所有者一皮。  
20 DAG：见下。无环、无悬空。  
21 不写：真法事、改户口教程、真实未成年人户籍、已禁人名视角。  
22 十分钟动作验收句：涂黑文案后，玩家在重复「收下句子，去指口头哪一句对不上」。  
23 新肉：真相是疏未解除加谱未改；边从本户四套名长出；收口是不发结婚材料；近答案从停香/态度/邻县长出。  
24 遮掩自测：陌生人不会说出长江本格或逆转法庭。差事是户政夜窗核名。

## Token DAG

```
        ├─ 附属柜抄件 / 保管人 / 停香 → 加固未解除；停香≠焚疏（shu-tingxiang）
        ├─ 户口摘页 hukou-yigai → 屈小禾已改屈晚禾
        ├─ 谱局入口 / 一口 / 字辈 → pu-chengji、pu-weijie
        ├─ 对质点「谱上也改了」→ T-crack-pu
        ├─ 班长条 / 结婚材料须知 → zhi-mingqi、zhi-ye
        ├─ 对质点「夜窗就能发」→ T-crack-hun（加固，不替代前两破绽）
        ├─ 博客跳墙场面 → kou-wushu（口述不能当解除）
        └─ 邮箱邻县（可选）→ lin-buning；对质点「邻县回执能用」→ 顶回或拆并案
                │
                └─ 交处置 → hold / release / overreach
```

无环。处置单无前置锁，避免死锁；两处主破绽未指就选 hold，仍走 hold，理由写得薄。邻县不是必经。关闭页不是门。

## 逐题五步

### 题0　开局收下第一句

- 看见：班前纸写覃书、屈晚禾说已跳墙、柜目录未解除、对质入口。  
- 能做：点收下「未解除」，点进对质窗。  
- 映射：任务成立，先信还俗会被口头送上门。  
- 触发：持有 shu-weijiechu。  
- 错：直接交「按口头发」。机器照收，走 release。

### 题1　对质第一破绽（送）

- 看见：一侧是口头「寄名早解除了」，一侧是已收句子。  
- 能做：点「寄名早解除了」。  
- 映射：口头已跳墙对不上疏未解除。  
- 触发：T-crack-shu。  
- 错：点「我都排队了」→ 对方顶：急不代表疏撤了。点「庵都停了」→ 对方顶：停香是庵的事。

### 题2　柜页加固

- 看见：抄件栏未解除；保管人写停香不是焚疏。  
- 能做：再收加固句，或不收也能凭开局那句。  
- 映射：接待停了，名还可以挂着。  
- 触发：shu-tingxiang。  
- 错：把停香页当成解除证明。

### 题3　谱局第二破绽

- 看见：谱名屈承稷；一口写未接知会；户口摘页已改晚禾。  
- 能做：收下谱名句，回对质点「谱上也改了」。  
- 映射：户口先改，谱未改。  
- 触发：T-crack-pu。  
- 错：用户口已改去打「谱已改」——字段对不上，对方顶：你看见的是户口本。

### 题4　名齐与权限

- 看见：班长条三栏；须知写夜窗只出建议。  
- 能做：收下名齐句，点口头「夜窗就能发」。  
- 映射：名不齐不能当可发；夜窗无批准权。  
- 触发：T-crack-hun。  
- 错：选代办跳墙或代改谱，走出 overreach。

### 题5　邻县暗线（非必走）

- 看见：席芦抄送，女、一九九九、临户改字八八四一。  
- 能做：收下「不能并案」，点口头「邻县回执能用」。  
- 映射：同名噪声。  
- 触发：lin-buning。  
- 错：把邻县回执当本户解除。

### 题6　交处置

- 看见：三选项，权限写建议。  
- 能做：不发 / 按口头发 / 代办。  
- 映射：hold 才对上两层。  
- 触发：对应三键。理由按已指破绽与已打开页生成。  
- 错：三路都合法提交。

## 每步解锁

对质窗开局可进。附属柜、谱局、须知、邮箱、博客从夜窗桌面进，不靠搜词开门。邻县不挡交单。

## 教学、反馈、四级提示

教学写在班前纸：收下句子，去指口头哪一句对不上。没有进度条。页脚只是编号。

反馈：
- 指对：那一句口头被卡住，对方改口或哑。  
- 指错：对方把理由顶回来，不闪哪句才对。  
- 未收下对得上的句子就点：回「你还没把对得上的那句从页上收下」。  
- 关闭页：夜窗联查白班才开。  
- 禁止页：代办跳墙、代改谱不对夜窗开放。

四级提示（抽屉，前三档不写最终键）：

1. 口头要拿柜里的栏对，不要跟态度吵。  
2. 停香和解除不是一栏；谱和户口也不是一栏。  
3. 先收未解除再点「早解除」；谱页上的承稷拿去点「谱上也改了」。  
4. 口头已跳墙对不上未解除；户口名改了谱名未改；处置选今晚不发。不要代办。

## 判定卡

### 卡1　寄名早解除

正确答案：点口头「寄名早解除了」，且已收未解除。  
必要证据：shu-weijiechu。  
充分证据：开局目录那句即够。  
近答案：态度；停香；博客跳墙场面。  
排除：态度无字段；停香页写接待停；博客无文书号。  
等价：无。  
部分对：顶回，指出这不是栏上的冲突。

### 卡2　谱上也改了

正确答案：点口头「谱上也跟着改成屈晚禾了」，且已收谱名仍作屈承稷。  
必要证据：pu-chengji。  
充分证据：谱局入口或谱页其一。  
近答案：用户口已改去打；用邻县回执去打。  
排除：户口摘页只证派出所；邻县是另一户。  
部分对：对方顶「你看的是户口本」。

### 卡3　夜窗就能发

正确答案：点「夜窗就能发结婚材料」，且已收名齐三栏或夜窗只出建议。  
必要证据：zhi-mingqi 或 zhi-ye。  
近答案：班长「名齐了」被听成「已经齐了」。  
排除：条子写的是条件，不是已经齐。

### 卡4　处置

正确答案：hold。  
必要：建议选不发。两处主破绽已指则理由写全。  
近答案：release；overreach。  
部分对：未指破绽就 hold，仍 hold，理由薄。

## 干扰、失败、limits

干扰：停香、排队态度、博客跳墙、邻县同名、修谱收费。  
失败：指错顶回；release / overreach；可作废重开。  
limits：疏抄件只能证明柜里这一栏，不能证明庵里当年看过一眼算不算跳墙；博客不能当解除；邻县回执不能并案；夜窗不能批准原物，不能证明公证处今夜会怎么判，只能预见到名不齐会卡。
