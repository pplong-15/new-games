# 闸 A · 桥头信息港

结论：**PASS**，可进开发。开发已按此稿落地第一版。

## 七维

1. **人物立住** PASS  
   刘石桥短句、吴秋改口划句、章绣把门牌说两遍、何小满嘴快、龚助工号套话，能从台词分开。陈迈只出现在回执，符合「买名进来」不是侦探。顺子不是人，误认页写明。

2. **台词像真人** PASS（补了页内对白）  
   何小满「不问我憋得慌」、电工「我管的是漏水」、龚助「我又不是去你家清帖的」、吴秋半句划掉。不是说明性旁白堆设定。

3. **剧情顺** PASS  
   石桥问了一句才改须知；吴秋关站七天复活才过户；何小满问了才有迁往「待送达」；龚助按规章退款才把办公室写成目的地。没有突然相爱式跳跃。

4. **恐怖类型** PASS  
   信息层：名跟送到绑在一起。反派不是单纯恶人。吴秋是活下来的人。没有 jump scare。

5. **线索可闭环** PASS  
   开局词在首页。一词两页、同名电工、口令在店名、四结局各要一套 token。近答案：顺子寻人、电工登录、空门牌缺迁出则拒。暗线祭桥不挡过户。

6. **厚度** PASS  
   关系网：石桥—何小满—章绣—吴秋—陈迈—龚助。三层反转（垃圾帖 / 关站没用 / 章绣要找的是人不是门牌）。暗线祭桥+2009原稿。四结局各有逻辑根。

7. **可英文化** PASS  
   谜题对象是来源、身份、时间线、规矩含义，不拆字、不靠字形。  
   「顺路」一词两义：栏目名与网名是**同一个词**，英译占位一律 `RideAlong`（board name = handle），不是谐音梗。  
   「名」跟域名绑：英文用 domain name / the name，不另造字谜。

## 开发红线（不可改）

- 玩家是买下过期域名的人，不是失踪者家属、不是质检员、不是论坛访客侦探。
- 主循环仍是读页→抽一个汉字词→站内搜。不要加任务 HUD。
- 关站不解绑。四结局逻辑根不能并成一个「找到凶手」。
- 没有「把单改回章绣还住的家」可选项。
- 主线不靠 F12、外搜、真实人名。
- 图是用户上传快照，不要六站同一套圆角卡片。
