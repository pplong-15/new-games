# 地券密级 — Modular Package（拆解版）

> 这款游戏本身是**多页面结构**（已模块化），无需拆解 base64。本目录提供可修改清单和结构说明。

## 结构

```
地券密级/
  - 中文版: 入口 `introduction.html`，48 页 HTML，1 JS，11 CSS
  - 英文版: 入口 `introduction.html`，48 页 HTML，1 JS，11 CSS
```

## 版本

中文版、英文版

## Agent 修改规则

1. **先读 `manifest.json`** 了解入口页和结构。
2. **改什么**：HTML 页面里的文本（剧情、对白、档案）、CSS（主题配色）。
3. **不改什么**：页面内的交互 JS 逻辑、谜题答案、校验逻辑。
4. 修改后逐页验证能正常打开、核心流程可走通。
