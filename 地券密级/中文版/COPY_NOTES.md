# COPY_NOTES　各站书写习惯

按 game-copy-humanize 0.9。习惯绑站点，不绑人物职业。改文案时先对习惯，再口语化。

| 站 | 习惯 | 怎么写 |
|---|---|---|
| introduction.html | B 冷陈述体 | 短，交代班和抽屉。不讲密级理论课。不写「综上所述」。 |
| public/* | B 冷陈述体 | 馆讯、目录、须知。收在字段和门条。缺的位置不补套语。 |
| desk/* 值班台、登录、备注 | B 冷陈述体 | 表、工号、回执。错了只说工号或口令不对。 |
| desk/shift.html、mail/zhai.html | F 结巴预演体 | 翟浦改口、句子断、请假又补半句。 |
| mail/qu.html | A 絮叨漏白体 | 曲晚棠先规矩后改口，口令从闲话里漏。 |
| mail/spam.html | B 冷陈述体 | 设备科群发，无关。 |
| gov/* | B 冷陈述体 | 红头摘录。禁「显然／须注意／综上」。催的是格子，不是抒情。 |
| forum/* | E 群嘴拼贴体 | 楼层、楼中楼。侯启明烦，葛秋萍问完又收，找羊是噪声。 |
| news/* | D 史笔半文体 | 通稿骨架，据乡里口径／发布会。不替馆方补转写。 |
| baike/* | C 讲古立规体 | 先立要项，再写不要做什么。不给写券范文。 |
| blog/shen.html | H 回忆缠绵体 | 绕柜子说话，不点骨。 |
| classified/hou.html | A 絮叨漏白体 | 黄页客气里漏出怕后墙。 |

屏幕禁：主线、搜词、汉字词、进度条、关卡、通关、解锁、线索、结局、源码、本游戏。

权威句只写查阅备注／建议另核，不写批准原件。
