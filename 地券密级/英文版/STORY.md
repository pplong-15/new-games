# 地券密级　故事

对标机制：Need to Know。工牌登入不同密级，看见同一档号的不同版券文。不是手机，不是上传台勾字段，不是灰栏目教第一词。权威恒为查阅备注 / recommend，不批准原件，不教写券。

## 1. 设定

安浦县档案馆把一批二十世纪的买地券扫描件挂进三套目录。公开层给展陈和网上目录；内部层给馆员核对宅基地、公墓证；限制层锁原钞件转写，夜班默认进不去。

买地券是给地下神明的契约名分：时间、钱主、四至、中保、亡者。宋以后常一式两件。缺券、错名、两件缺一，旧话叫冢讼。当代对应是公墓使用证、地籍和展陈说明互相打架。馆里只做著录和查阅备注，不裁地，不迁葬，不认定原件真伪。

同一档号「安档-地券-1983-047」在三层里不是同一句话。工牌能进哪一层，你就只能看见那一层的钱主和四至。公开层看起来像一张完整的侯家券。内部层把东至挪到还住人的屋后。限制层把亡者写成另一个姓。

本局不教人写阴契，不用真实墓地当事人，不开棺。玩家是夜班助理岑禾，抽屉里有上一班留下的临时工牌。

## 2. 故事（时间线）

表面：八月二十一日周五夜班。文保所缪秋白下午把查阅申请甩到数字化室：047 要在明早例会前补查阅备注，五栏都要有字。侯启明通过所里申请看公开目录，说要核对西坡旧界。馆长不在。曲晚棠白班走时在交接本上画了两下：公开层自己点，内部用翟浦那张牌，限制层她不建议夜班进。

岑禾入职三个月。她会开扫描件、会填表，不会判地。抽屉里有一张「见习-夜」工牌，套里还夹着翟浦的内部牌。她本来只想把公开层抄进备注，六点下班。

先信的解释：三层是为了保护在世后人隐私。公开层写侯万石买地、侯成山葬西坡，时间一九八三年冬月十六，中保写后土神祇，像展柜里该有的样子。2016 年墓券展用过这一版。侯启明住的屋子，公开四至东至石阶，和他手里的宅基地证对得上。

第一层推翻：内部层用翟浦工号 QP-夜-04、口令 nanshan047 才能进。同一张扫描，钱主改成侯万川，备忘写「公开层误植兄名」。东至写成侯宅后墙。曲晚棠 2019 年分拣备忘写：与一九九一年宅基地公告冲突，不对公众展示。中保不再是神祇，是申敬之，时任南岭乡文书。内部还夹一句：侯成山另葬东岗，此券亡者栏后改。公开层那张「完整侯家券」是展陈口径，不是原钞件。

第二层推翻：限制层要用曲晚棠备用密级牌 QT-密-07、口令 jiaojie083。原转写钱主是葛万川，亡者是岑守山，时间写甲子年冬月十六，没有换成一九八三。四至东至「现住屋后墙」，西至旧渠。调阅日志上，申敬之 2018 年退休前批过「分柜存放」。他早年在券上作中保，后来当馆长，再后来把有自己名字的那一层锁起来。

岑禾的祖父也叫岑守山，南岭人，一九八三年冬月下葬。县志词条里另有一个东溪岑守山，1962 年故，不是同一个人。限制层那个名字对得上南岭这一房，对不上东溪。她若在备注里把亡者唯一写成岑守山，系统会退回：查阅备注不得对原件作唯一认定。她若只抄公开层，侯启明满意，限制层继续锁着，祖父的名字不会出现在明早的例会上。

翟浦上周已经撞过限制层。他给值班邮箱留了句难听话，随后请假。曲晚棠不是灭迹的人，她信「柜里柜外分开写」。申敬之博客里只剩半句：柜外那张要能挂，柜里那张不要见人。侯启明在本地黄页找人看旧界，怕的是屋后那一墙。葛秋萍在乡帖里问父亲葛万川八十年代是不是在南岭帮过忙，没人答到点子上。

岑禾的抉择不在迁坟，在五栏备注写哪一版。写完提交，系统只收建议。天亮以后谁被问话，取决于她写了哪一层。

## 3. 人物小传

**岑禾**　功能位：夜班助理，把看见的字段写成备注。声口：短，怕填错，会在交接本上骂自己一句。动机：三个月试用，想把夜班做满。弧光：以为抄公开层就能下班，后来看见祖父的名字和自己的工牌在同一抽屉里。

**曲晚棠**　功能位：密级分拣。声口：改口，先写规则再补一句「你别进限制」。动机：展陈要一张完整券，原钞件另柜。弧光：从「分开是规矩」到给夜班留备用牌，自己也不敢写进备注。

**申敬之**　功能位：旧中保，后任馆长。声口：旧人博客，句子绕，不点名。动机：退休前把有自己名字的一层锁上。弧光：乡文书画押 → 馆长分柜 → 只在日志里留「分柜存放」。

**翟浦**　功能位：上一班数字化。声口：急，句子断，会写错再补。动机：不想再碰 047。弧光：进过限制层，请假，把牌和口令留给下一班。

**侯启明**　功能位：在世住户，申请查阅公开层。声口：黄页上客气，帖子里烦。动机：东至若写成屋后，房子先乱。弧光：从「核对旧界」到怕内部那一墙被写进所里的会。

**缪秋白**　功能位：文保所经办。声口：催，只问五栏齐不齐。动机：明早例会不能空表。弧光：不关心谁是亡者，关心表能不能投影。

**葛秋萍**　功能位：限制层钱主的女儿，暗线。声口：问完又收回。动机：想知道父亲当年在南岭干什么。弧光：发帖，没有得到能用的答复。

**侯万石 / 侯万川 / 侯成山**　功能位：公开、内部用名。本人不出场。万石是兄，万川是弟，成山被写成亡者但内部说另葬东岗。

**葛万川**　功能位：限制层钱主。声口：只在女儿问句里。迁出已久。

**岑守山（南岭）**　功能位：限制层亡者，岑禾祖父。不出场。另一岑守山在东溪，1962，误认岔路。

## 4. 每人抽出的故事

**岑禾**：傍晚接班，抽屉里两张牌。她先把公开层抄进草稿，觉得能交差。内部层把东至推进住家。限制层出现祖父的名字。她可以只交公开层回家，可以把内部冲突写上不提限制，也可以把三层打架写进备注，或者冲去认定亡者——最后一项会被退回。

**曲晚棠**：2019 年按申敬之退休前的批示分柜。她相信展陈不能把宅基地冲突摊给观众。今晚她给夜班留了密级牌，又在信里写「用完放回」。她怕的是夜班把限制层写进能投影的表。

**申敬之**：1983 年前后在南岭乡文书室作中保。2016 年墓券展要一张能挂的侯家券。2018 年他批分柜，然后退休。博客只剩绕着柜子说话。

**翟浦**：夜班一个人对着三层。他进了限制层，写过一稿备注，被退过或自己删了。请假条只写家里有事。邮箱里剩半句：别只看公开层。

**侯启明**：屋后墙外是公墓西坡。公开目录的东至是石阶，他睡得着。内部若被所里看见，回访会先问这堵墙。

**缪秋白**：所里例会要五栏。她把申请写得规矩，截止日期写在抬头。她不会来档案馆。

**葛秋萍**：在乡帖问父亲的名字，楼里有人扯羊、扯水渠。她把后半句删掉，只留「帮过忙」。

**南岭岑守山**：1983 年冬月下葬。名字在限制层，不在展柜。东溪那个同名是别人。

## 5. 线索与伏笔

- 引言 / 交接本写出内部工号口令、密级牌用法、祖父南岭 1983 冬月。
- 公开 047 给展陈版五字段。
- 文保申请把档号和「五栏备注」放在眼前。
- 内部 047 + 分拣备忘推翻钱主、四至、中保、亡者栏后改。
- 宅基地公告与公开东至相同、与内部东至冲突。
- 限制 047 + 调阅日志给出原转写与申敬之分柜。
- 百科买地券立核对要项，并写干支或为套语。
- 县志东溪岑守山 1962，排除同名。
- 申敬之退休短讯 + 博客：中保与分柜。
- 翟浦邮件：别只看公开层。
- 曲晚棠邮件：密级牌 QT-密-07、口令 jiaojie083。
- 黄页侯启明寻人看旧界。
- 乡帖葛秋萍问葛万川（暗线，不挡提交）。
- 1979-012 是另一张券，字段不能写入 047。
- 扫描仪保养信、找羊帖、水渠帖是噪声。

## 6. 多结局

| 键 | 触发 | 逻辑根 |
|---|---|---|
| public | 五栏都按公开层写，未采用内部/限制冲突 | 展陈口径交差，侯启明要的那版被复述 |
| internal | 钱主或四至采用内部冲突，亡者不按限制层唯一认定，也不写三层亡者冲突 | 所里会碰到屋后墙，限制层仍锁 |
| three | 亡者写两版冲突建议另核，且中保写出申敬之，且到过限制层 | 三层都进备注，晨会会问分柜 |
| overclaim | 亡者栏选择「据此认定即岑守山」 | 越权定性，系统退回，须改写 |
| empty | 未齐五栏就交 | 所里退空表 |

## 7. 单案种子

- 标题：地券密级
- 钩子：同一扫描三层密级，工牌决定你看见谁的四至
- 主角：岑禾
- 欲望：交完备注下班
- 冲突：公开层能交差，限制层有祖父的名字
- 反转：展陈侯家券 ← 内部改界改钱主 ← 原钞件葛/岑、中保即前馆长
- 结尾钩子：备注是建议，柜子不会因为你写了就打开
- 所需素材：三层券文、工牌、交接本、文保申请、宅基地、百科、同名词条、邮件、博客、乡帖、黄页
