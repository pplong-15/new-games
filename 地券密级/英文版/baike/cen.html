1 This Dongxi man

The gazetteer appendix has a Cen Shoushan, Dongxi Village, died of illness in 1962. No maidiquan cataloging. No Nanling West Slope sizhi. This lemma does not establish a link to any 1983 deed. This specific connection is ruled out if the only evidence is the shared name.

2 Nanling has another

Nanling Township has another man of this name, buried in 1983 winter month (dongyue). He is not this lemma. If a restricted layer in the archive shows the same name, exclude by village and year. Do not write this Dongxi line into the 047 wangzhe box.

Merging same names is a common error. If duty has only this encyclopedia line and no Nanling household record, identification still cannot be made. The grandfather line is in the handover-book margin. It is not in the gazetteer.
