Office-meeting extract · 03-14

Tonight’s file House plot Cemetery certificate

A viewing note records how each source writes. “They fight each other; recommend recheck” is allowed. “On this basis, determine the original’s deceased is so-and-so,” “permit cadastre correction by a given layer,” and “agree to relocate a burial” are not.

A maidiquan is a title contract. It is not a contemporary land-use certificate. When the office holds it against a cemetery certificate and a house-plot notice, it only marks conflict. It does not pick a unique authentic layer.

If duty staff overreach into a determination, the system returns the note and the meeting records the name. Return is not a punishment for opening a cabinet. It is to keep a viewing note from becoming a ruling.
