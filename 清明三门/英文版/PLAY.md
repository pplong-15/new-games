# PLAY　专章 A

梯度：知识留存。一句话循环：开班选开三户 → 核对采信 → 交班纸页收回 → 已采信留下 → 用留下的知识交备注。开局三十秒：杭疏、邻穴投诉备注、三扇已能点的门、钟、白板同屏；第一扇邻穴投诉几乎送。权威：recommend，只交备注，不改号，不放行原物。

## 对标卡

1. 类型层：封闭世界网页解密；壳/体量钉登山。本局声明：工作台 + 附件站，不是搜词站。
2. 机制标本：Blue Prince。
3. 钉死循环：开班三扇门选开 → 班内核对采信 → 交班清空 opened → verified 留下 → 用留下的知识交备注。
4. 不是：不是 Hypnospace 巡站（巡站不丢桌面、不限三户）；不是登山搜隐藏页（没有一词开新页）；不是随机无信息抽卡（每户都有可采信字段）。
5. 梯度：知识留存。
6. 玩家：涟县东岗园预约台夜班杭疏；清明前夜必须交邻穴烧纸投诉备注。
7. 视角：班次重置后留下知识。投诉已推到桌上。避开已禁视角。
8. 权限：recommend。表单可画出改号/放行，正确解永不选。
9. 民俗：到坟/登记/纸钱消防变成可提取字段；寒食禁火作历史层对照；传说不作结案。
10. 载体：值班台三扇门 + 柜里另五户 + 钟 + 白板 + 备注单。
11. 开局三十秒：人、差事、三扇门、钟、白板同屏。
12. 第一动作：点邻穴投诉，读灰在邻界，采信「邻界有灰」。送。
13. 主提交：备注四栏成组。
14. 成组：四栏齐才判。逐格不闪绿。
15. 正确收口：`note`＝串穴核销 + 码走烈士园集体扫墓 + 供品到十二区私坟 + 只交备注。
16. 近答案：鬼烧邻穴；把十二区写成集体预约；改号/放行。各被须知、户档、权限栏排除。
17. limits：页上写「这些来源不能证明夜里有人从坟里出来 / 不能证明是谁的手」。
18. 失败：栏不齐退回；写成鬼走 `ghost`；越权走 `overbook`。不毁 verified。
19. 站点：见下表。一所有者一皮。
20. DAG：见下。无环、无悬空。
21. 不写：踏坟实操、真烈士名单、已禁人名视角。
22. 十分钟动作验收句：涂黑文案后，玩家在重复「选今晚看哪三户，交班，带着已采信的再来，最后成组交备注」。
23. 新肉：真相是集体码给私坟送货；DAG 边是码↔回执↔流水；收口四栏是本园字段；近答案从传说帖和权限钮长出，不是庄园房间名。
24. 遮掩自测：不看商标，陌生人说不出 Room 46，也说不出登山失踪词。

  └─ 开 shuo → seen-shuo → 可采信 v-lore-ghost（近答案，不能当正确栏）
交班：opened 清空；seen 与 verified 留下
交备注（四栏成组）
  ├─ 串穴核销 + 烈士园集体 + 十二区私坟 + 只备注
  │     且已有 v-ash-neighbor, v-code-martyr, v-deliver-12, v-cross-hexiao → note

无悬空：串穴采信的两个前置由批次与回执产出。第一班开投诉+顾户+批次即可留下三枚；第二班开配送+核销+考勤即可写下正确备注。开错户不毁档，再交班即可。

## 逐题五步

### 题1　邻穴投诉（送）

1. 看见：引言三扇门最左写「邻穴投诉　条皖让你先开」；钟和白板在同屏。
2. 能做：点开门，读投诉单，点「采信邻界有灰」。
3. 映射：申柏报的是邻界纸灰，差事成立。
4. 触发：opened 含 tousu；verified 含 v-ash-neighbor；白板多一句。
5. 错：把传说帖当第一扇——门能开，但不能代替投诉采信。

### 题2　户与码（对照）

1. 看见：十二区户档写私坟顾松年；集体批次写烈集码、南阶。
2. 能做：两户都开过并分别采信。
3. 映射：私坟不是烈士园；码不是十二区自家约的。
4. 触发：v-gu-private、v-code-martyr。
5. 错：把十二区写成集体预约——户档「私坟」栏在。

### 题3　回执与流水（第二来源，需留下的知识）

1. 看见：回执穴号十二区三十七；流水同一条码记南阶又记十二区。
2. 能做：交班后开配送与核销；有码和送货两枚才允许采信串穴。
3. 映射：一码两记，货在私坟。
4. 触发：v-deliver-12、v-cross-hexiao。
5. 错：只开过回执就写串穴——按钮不亮，写「还缺对照的那一页」。

### 题4　抢同一天（第二层）

1. 看见：工会催南阶签到；顾晚禾写当天要到十二区。
2. 能做：开考勤户，采信 v-same-day。
3. 映射：考勤和私坟抢清明当天。
4. 触发：白板多一句「同一天两处要人」。
5. 错：据此改号——走 overbook，不是正确栏。

### 题5　备注（成组收口）

1. 看见：值班台「交邻穴备注」。
2. 能做：四栏一次交。
3. 映射：只建议，不改原物。
4. 触发：四结局之一。
5. 错：近答案见判定卡；不闪哪一格对。

## 判定卡

### 卡A　备注四栏

正确答案：串穴核销 / 烈士园集体扫墓 / 十二区私坟 / 只交备注。  
必要证据：v-ash-neighbor、v-code-martyr、v-deliver-12、v-cross-hexiao。  
充分证据：以上四枚即可，不必开寒食。v-same-day 加固第二层，不另开第五栏。  
最近三个错：鬼烧邻穴；码写成十二区私坟预约；处置改号或放行。  
排除：园务须知「传说不作结案」；户档私坟 + 批次南阶；权限栏写不得改号。  
等价写法：无。四栏选项固定。  
部分对：指出冲突栏，不公布正解。例如性质对、码向写成十二区：「预约码这一栏和批次对不上。」

### 卡B　串穴采信按钮

正确答案：已有码走集体、货到十二区，才能采信一码两记。  
近答案：只见过流水；只见过传说。  
排除：缺一枚前置则按钮灰，句子写「今晚还缺能对上的那一页」。  
部分对：不闪绿。

### 卡C　见过与采信

正确答案：交班后 opened 空，verified 仍在；未采信的户要重开才读全文。  
近答案：把本班打开过当成已采信，拿去填备注。  
排除：备注校验只认 verified，不认 seen。  
反馈：「见过的纸页不够，白板上没有这句。」

## 解锁

不靠第几步。交班钮一开始就在。备注入口一开始就在，交早了走 thin。串穴按钮靠 token 持有，不靠班次数字。

## 烟雾弹 / 死路

- 传说帖：鬼烧邻穴。采信后仍不能当正确性质。
- 寒食旧罚单：去年有灰，不能证明今夜是谁的手。
- 口误「列急」：噪声，划掉。
- 假入口：园务导航、论坛家园、邮箱写邮件，`javascript:void(0)`。
- 公开民俗页：教动词，不给穴号。

## limits

- 投诉单：能证明邻界有新灰，不能证明鬼，不能证明是顾晚禾亲手烧。
- 户档：能证明顾松年是十二区私坟，不能证明家属动机合法。
- 批次与码页：能证明码发给粮库工会南阶，不能证明所有持码人都到了南阶。
- 回执：能证明货放到三十七穴，不能证明南阶当天有没有人。
- 流水：能证明同一条码被记了两处，不能证明谁授意。
- 考勤与留言：能证明同一天两处要人，不能当改号依据。
- 传说帖：能证明有人这样讲，不能结案。
- 旧罚单：能证明去年寒食十二区有灰、禁烧令已在墙上，不能给今夜定性。
- 县志摘录：能证明寒食禁火是旧层，不能证明当代有人从坟里出来。

## 新手不迷路

- 30秒：引言能答我是杭疏、要交邻穴备注、能点三扇门、钟和白板在、先开投诉。
- 链：投诉灰 → 户是私坟 / 码走南阶 → 交班 → 回执与流水 → 备注。
- 反馈：开门有计数；采信白板加句；交备注立刻进一页，不静默。
- 进度：白板分「见过」与「已采信」；本班已开 x/3。不是分数条。
- 梯度：第一扇送；中段要交班再开；收口成组。
