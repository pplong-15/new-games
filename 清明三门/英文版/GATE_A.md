# GATE A　故事层七维

验收对象：`STORY.md`。不碰 HTML。

## 1　人物立住　PASS

杭疏（夜班交差、嫌表格）、条皖（限开三户、防改号）、顾晚禾（私坟当天没车）、缪石桥（只要南阶签到）、申柏（灰不要记在亡父头上）、皮厚山（按穴放下）、仇麦秋（教见过不算数）、纪南楼（旧单只写现场有灰）。功能位分开。硬问三人声线：条子短句、家属絮叨改口、工会套话补人数，不共用一张嘴。

## 2　台词像真人　PASS（进开发后按 COPY_NOTES 落页）

框架避开说明性旁白当对话。投诉急、回执秃、园长条冷、传说群嘴，四种习惯预留。开发期禁止把「串穴核销」念成议论文，禁止金句收尾。

## 3　剧情顺　PASS

限开三户 → 第一班只能看见投诉/户档/批次的一层 → 交班知识留下 → 第二班才能对回执与流水。关系不靠突然和解。每场目的：起=差事与三扇门成立，承=灰与户与码分开，转=一码两记且抢同一天，合=备注一次定性。顾晚禾与缪石桥不需要见面，互锁在「同一天、一个码」。

## 4　恐怖类型成立　PASS（克制信息层，非 jump scare）

不适来自：集体码给私坟送货、邻界纸灰、考勤格子比坟前的人先被填写、寒食旧单与新禁烧令对照。反派不是鬼，也不是恶园长。条皖要的是别改号。传说只作近答案。

## 5　线索可闭环　PASS

投诉给出邻界灰；户档给出私坟；批次给出集体码；回执给出十二区穴号；流水给出一码两记；考勤与家属留言给出抢同一天。四结局互斥：四栏正确 / 写成鬼 / 越权 / 栏不齐。寒食旧单不挡主线。伏笔表有掉落与回收。

## 6　设定可单列、故事够厚　PASS

第1段设定与第2段时间线分开。弧光人物有；抉择点≥2（第一班开哪三户；备注写串穴/写鬼/改号）；结局≥3。厚度：杭疏–条皖–限开互锁，顾晚禾–缪石桥–同一天互锁，申柏–邻界灰–杭疏必须交备注。反转两层：先信鬼烧邻穴 → 推翻为串穴核销 → 更深是集体考勤与私坟抢同一天。非必走暗线：寒食日旧罚单。

## 7　可英文化　PASS（本局按用户要求不英文化上线，契约已预留）

核对靠预约码、穴号、地块、表单四栏，不靠拆字谐音。术语表已随故事交付。无功能谐音梗。「烈集」是局内编号前缀，不当字谜。

可进玩法与开发。
