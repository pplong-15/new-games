Extract

A cooperatively run funeral furnace mouth shall be lit only on the funeral host's application. This extract is from a photocopy of an old county notice. One corner is missing. The missing piece is the issuing name, cut on purpose, so the sheet cannot be matched to a real agency. A craftsman, a night helper, or a go-between shall not approve in another's place. Zhizha is a list of burnable paper offerings. Work is complete only when class and count compare. This extract states how the rule is written. It cannot determine whose goods burned tonight.

Fifth-seven, end-seven, and burial day are common windows for burning paper figures. Opening-day festive crafts shall not enter a funeral furnace. A shop number in breach is recorded.

The extract is set in a serif face. No national emblem. The footer writes fictional, so the sheet is not taken to a real yamen for a seal match. A seal that does not match still does not authorize using this extract to sue a shop.
