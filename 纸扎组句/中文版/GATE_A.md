## 1 人物立住　PASS

## 2 台词像真人　PASS（文本层）

故事层已规定各站书写习惯。预定：引言絮叨改口；夜班台冷断；文具店土广告；催文急而重复；娄石相册碎怨；街坊楼群嘴；县站先立规再摘。无「综上所述」式说明腔设计。开发期按 `COPY_NOTES.md` 落盘，本维先过框架。

## 3 剧情顺　PASS

两单同一晚进铺 → 夜班手按童女记 → 堆上出现红金 → 发票户名是邵浦 → 店群里人还在问狮头 → 炉口未开 → 只能建议不能准烧。井秋白与邵浦不是突然翻脸，是一丧一喜叠夜。麦老夹在两笔钱中间，符合铺主。无纸人成真，无突然恋爱。

## 4 恐怖类型成立　PASS

中式丧仪恐怖：五七前夜，开业彩扎码进丧堆，发票品名和丧单冲突，活人还在店群说话。反派不是单纯恶人——麦老接两头活，井秋白要向家里交差，邵浦回避丧事仍走这家铺。情绪落点是「货混了、人还在」，不是纸人开口。limits 挡住把照片当已焚铁证。

## 5 线索可闭环　PASS

伏笔均有掉落页与组句回收。三结局触发条件写在句卡六格与权限栏，不靠作者宣布。暗线（喜丧混炉旧投诉、分炉通知）可挖、非必走。

## 6 设定可单列、故事够厚　PASS

第1段设定（纸扎/彩扎分时分堆、匠人无焚化权），第2段时间线有起承转合。人物弧光：盛麦从按童女缺件记到守权限只写混堆。抉择点≥2：已焚童女 / 混堆未焚；只建议 / 准烧或教扎法。结局≥3。  
厚度：盛麦—麦老—井秋白—邵浦—娄石互锁（催著录、催童女、开业货、拍错堆）；反转两层（先信缺童女 → 推翻是彩扎混堆 → 更深是发票品名与丧单冲突且邵浦还在店群说话）；暗线喜丧混炉。抽掉组句钩子，兄弟一丧一喜叠夜仍成立。

## 7 可英文化　PASS

解谜靠货主、品名、混堆、炉口、在世、权限，不靠拆字谐音。术语表已随故事交付。无功能谐音梗。本闸只交占位表，不上英文化成品。

## 结论　PASS

可进玩法。开发红线：

- 玩家只 `recommend`，不准批准焚化，不准教扎法。
- 娄石照片必须带 limits，不得写成已焚铁证。
- 循环是采词组句整句交，不做灰栏目搜隐藏页，不做左右对照台，不做六栏方案卡，不做逐人定性。
- 正确收口键 `filed` 不许改：邵浦开业彩扎混进邵庭丧扎，今夜未焚，邵浦在世。
- 禁用人名：陈迈、裴晚、沈南、周引娣、招招、闵科、程石、狄厚、芮秋、沈梭、卞梁、褚慈、尤石、卜田穗、匡守业、耿素秋、林阿盛、路桂芬、方正平、卫棠、岑禾、蒲生、裘石、韩洲。本局用盛麦、麦老、井秋白、邵庭、邵浦、娄石。
- 屏幕不出现：主线、搜词、汉字词、进度条、关卡、通关、解锁、线索、结局、源码、本游戏、隐藏页、唯一解。
