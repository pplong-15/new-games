# 夜台听写　文案习惯（humanize 0.9）

书写习惯是站点的，不是人物标签。听写叠音、代字、口头禅都留着。不灌水，不加金句。

| 站点 | 习惯 | 怎么写 |
|---|---|---|
| 班前纸 `introduction.html` | B 冷陈述体 | 工号、三项、权限停在建议。不抒情。 |
| 值班机桌面 / 时间轴 | B 机内便笺 | 短句，点开绿条才有听写。不解释民俗。 |
| 八段听写 | B + 夹口语 | 黑底听写保留自称和叠音。蒲生旁注改口，不升成事实。 |
| 交接 / 便条 / 草稿 | A 絮叨漏白体 | 米秋葵括号多、重复先听时段。第四张才写满。蒲生怕手快。 |
| 标注单 | B 冷陈述体 | 权限写建议。回执按已打开的页换理由，不写海报句。 |
| 站内信 | B 短讯 | 翟台生甩点，困了就停。 |
| 礼簿五页 | C 讲古立规体 | 盛麦先立代字和正项，半文半白。西厢是屋子。 |
| 讣栏 | B 报馆体 | 通讯员口气。不登遗容，旧稿只对照。 |
| 村栏 | D 史笔半文体 | 油印、计日、过道。土，略硬。 |
| 医院夜板 | B 表格体 | 打卡和留言摘抄。行了哈。不写病情。 |
| 槐记分类 | A 店口气 | 落款莫吵价看货。学徒补铁丝。 |
| 班线 | B 小站告示 | 时刻写死。字条油渍。 |
| 带柜目录 | A 絮叨 | 米秋葵私人小记。粮通知不是奠。 |
| 锁频 | B 机内回执 | 夜班打不开。不是故障彩蛋。 |

## 声口对照（防同声）

- 蒲生：复述时刻，改口，不敢发明。  
- 翟台生：短，甩五点半。  
- 米秋葵：啰嗦，括号，先听时段。  
- 仲槐：莫吵，催播音改口。  
- 晚秋：乏，代交，放完就走。  
- 季萍：干脆，六七我出，头七不管。  
- 厚水：咳，把带子叫成回来。  
- 栾守一：印过了，不好当场改。  
- 柏川：行了哈，九点五十打的卡。  
- 盛麦：记代字，正项和零头分开。

## 结局动态

`desk/annotate.html` 读 `localStorage.yt_seen` 与勾选。优先级：true → erfang（钱记二房或西房）→ tape（勾柏川在场或 22:14 选柏川）→ hold。理由跟判定对齐，不把对纸说成信听写。
