# 风格圣经　三份柜　VP1　2D

锁死：正交网页正视。机制是班次留条，不是搜隐藏页。不借边检桌、真搜索、进度条、全站圆角卡、花园迷宫符号。

## 相机 / 比例 / 线 / 光 / 材质

- camera_angle: 网页正视。无 2.5D 桌面。
- character_prop_ratio: 无精灵。可读比是「三扇门 : 打开过纸篓 : 已证实夹板」。
- line_weight_at_1x: 值班功能描边 2px；已证实夹板双线；方笺红格 1px。
- light_dir: 顶光平铺。禁止压暗当难度。
- material_id: 2010 夜班值班台 + 各所有者自己的纸（处方格、木纹柜单、蓝行账、备案绿头、HIS 灰）。

## 两栏（不唯色）

- 打开过：虚线、斜纹纸篓、折角、交班清空。
- 已证实：双线夹板、顶夹、钉形、留下。

## 控件

- 主操作 ≥44 CSS px。
- 检索不是主操作，说明书皮隐藏。
- :focus-visible 3px 金线。
- 320 / 390：两栏上下叠，门热区百分比不改。
- prefers-reduced-motion：取消拒条斜印。
