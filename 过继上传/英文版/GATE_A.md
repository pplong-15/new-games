# GATE_A　故事层

## 七维

### 1. 人物立住　PASS
卞梁怕扣分、素秋改口、晚禾懒、伯川把人说成房、守礼含糊、谭婶声明没进门、尤广只问栏数。换掉署名仍能听出谁在说话。

### 2. 台词像真人　PASS
框架里预留改口、口头禅、公司套话、科长冷句。禁止说明性旁白上场。开发期按 COPY_NOTES 各站习惯写，不写「综上所述」。

### 3. 剧情顺　PASS
死 → 命继红纸 → 户政拒变更 → 注销改主 → 修谱补录 → 卷尺份额 → 工单。每场都把下一张可打开的材料交到手上。没有突然相爱式关系跳跃。

### 4. 恐怖类型成立　PASS
不是鬼打墙。压迫来自：你勾的那一版会变成上门问句；孩子可能被文件推走；女儿一直在却进不了谱。反派不是单纯恶人——伯川要交差，守礼要学费，尤广要栏数。

### 5. 线索可闭环　PASS
红纸、无迁入、谱补、量院子、按错印、绿色主页，各有掉落页。兼祧是死路，不产出上传块。六结局各有触发。

### 6. 设定可单列、故事够厚　PASS
第 2 段按时间线走。关系网：素秋–伯川–守礼互锁，晚禾、小满、卞梁压在同一张纸上（≥3 节点）。两层反转：迁户手续 → 孩子没住过 → 争的是后院。暗线：晚禾旧空间与补贴，非必走。抉择点：五栏各选一版 + 是否签发。

### 7. 可英文化　PASS
不靠拆字谐音。术语表已随 STORY 交付。命继／嗣书作制度名，不作字形谜。

## 结论
**PASS**。可进玩法与开发。

## 开发期红线
- 玩家只有 upload / recommend，按钮禁止出现批准、核定通过、同意过继。
- 不写人口买卖玩法；不写异姓收养必然遭殃（本案两孩都姓耿）。
- 上传不可逆；回访提纲必须跟已上传块对齐。
- 开局同屏：工单、二十二点截止、上传台。
- 屏幕禁止：主线、搜词、关卡、通关、解锁、线索、结局、源码、本游戏。
- 禁用人名：陈迈、裴晚、沈南、周引娣、招招、闵科、程石、狄厚、芮秋、沈梭。
- 不做登山式搜隐藏页、不做片库、不做旅游帖、不做质检六站批原物。
