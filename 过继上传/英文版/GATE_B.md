# GATE_B　开发验收

## DAG
从工单／分组目录出发，户政附件、文书与谱、巷与信箱、须知与旧单均可到达。晚禾主页与子页依赖 `visit("letter")`。上传栏依赖已摘块。三栏签发进提纲与回执。兼祧、回执、垃圾、旧工单无钮，不悬空。无环。

新块 `heir-zupu` / `kind-measure` / `live-wanhe` 写入 `BLOCKS`，`previewLines` 与 `pickEnding` 跟勾选对齐。五栏 id 未改。截止 22:00 未改。无批准钮。

## 可点
- 值班台同屏：工单、系统钟 22:00、上传台、分组采集目录。
- 来源页摘钮可点；摘后回台出现对应单选。
- 一栏一版，上传后该栏单选禁用。
- 未齐三栏且未到点：签发留在值班台。
- 到点未齐：签发进空单退回。
- 晚禾未读信：主页与留言／相册／说说均挡；读信后可进、可摘。
- 邻巷旧单无摘钮，不能把姚户字段传进本单。
- 权威钮只有「上传此栏」「建议回访口径并签发」。无批准。

## 引擎

## 离线
