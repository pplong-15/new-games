# COPY_NOTES　每站一种书写习惯

改写前选定。书写习惯 ≠ 人设。

| 站 | 习惯 | 怎么写 | 不写 |
|---|---|---|---|
| 引言 | A 絮叨漏白 | 卫棠自己嘀咕，改口、怕交晚又怕写错。工号、首目标从抱怨里漏。 | 说明书腔、金句、「我是玩家」 |
| 文书室（含回单、备忘） | B 冷陈述 | 短、硬、本台不办。霍勉躲，回单像预览章。 | 站队抒情、完成度分数 |
| 馆对外 | 套餐口吻 | 拆窗口、讲价从略、侧门周二周五。土、挤。 | 文旅腔、现代大卡 |
| 晚报 | 通稿 | 来源、版次、照登、未到现场。杭疏桐值班摘。 | 小说旁白、金句收尾 |
| 宗亲会 | D 史笔半文 | 名录过录、私记、纪要摘。半文骨架白话填。 | 真谱、真祠堂、国徽 |
| 县图家礼 | C 讲古立规 | 先立介质与点主，再推回文书室。不教口诀。 | 科仪实操、朱砂教程 |
| 地方帖 | E 群嘴 | 晚香急、祁蔓窗口腔、纸扎店打岔。楼层自洽。 | 一人讲完真相 |
| 公共信箱 | 各人声口 | 蒲半文通知，祁一个「收」，霍勉自发自收。 | 统一公文腔 |
| 殡葬公示 | B 冷陈述 | 摘要表、旧通报点名。不装法庭。 | 真机关名、国徽 |

仲裁：事实 > 声口 > 顺口。不把领奖稿写成今夜目击，不把传真当丧期主件，不教伪造祖先，不批准挪牌。

屏幕禁用：主线、搜词、汉字词、进度条、关卡、通关、解锁、线索、结局、源码、本游戏、隐藏页、唯一解。
