# 牌位勘误 · 故事

对标机制：镇山契（多源并行核对 + 方案卡六栏 + 只提交建议）。不是鬼媒婆对照台，不是登山搜隐藏页，不是 QC-447 质检六站。民俗：神主 / 点主 / 安位 / 昭穆。玩家是沥江县殡仪馆文书室临工卫棠。

---

## 第1段　设定

沥江县殡仪馆把丧期里用的纸位叫「临时灵位」。纸位不是木主。木主要点主才成主。点主是礼生拿朱砂，在「王」上加一点成「主」。馆里业务组只印红纸，不代点。安位是把写成的牌放到哪一龛。东边昭位给父辈，西边穆位给下一辈或旁支，外姓不进本家龛。

还有一种牌不走丧期窗口：生位，也叫长生禄位。活人给自己或在世长辈预留的位子。生位可以在家龛里占一格，不能排进今晚要送去厅里的丧期纸位。排进去，等于把活人写成亡者。

配氏写在双人牌上。已故配偶可以写。在世继室若要写，须注「在世」，不能写成考妣双亡。离了的、还活着的，不宜再写回亡者身边。

牌位在当代法律里没有处分权。馆方文书室只做著录建议：讳对不对、配氏该不该写、龛位有没有占错、人是在世还是已故、依据哪份主件、建议能管到哪。不批准挪牌，不代点主，不改原打印件。

网页上能打开的，是馆内灵位单、馆对外须知、晚报讣告栏、翟氏宗亲会旧站、县图家礼影印、地方帖、文书室公共邮箱、县殡葬服务公示。它们能互相对，不能证明坟里躺着谁，也不能让一张建议变成成主。

## 第2段　故事（时间线）

表面：今晚二十二点前，卫棠要把一排临时纸位的著录建议交上去。第三块牌写着翟禾生。翟禾生还在粮库上班。

真相：牌面上的翟禾生不是业务组手滑。宗亲会蒲敬山把一张生位名单传进馆里，要先占东昭。业务组祁蔓的套餐模板把「应入祀」当成亡者。霍勉怕再惹一九九九年那种投诉，交代按打印件著录。翟晚香留下字条，求别把她弟弟写成死人。

### 起（傍晚到刚打开页）

卫棠是临工。白班文书请了假，霍勉把钥匙丢给她，说今晚有一排纸位要出建议，明天厅里安位。工号写在更衣柜纸条上：卫-0821。口令不用猜，条子写明用「卫-0821」。

她进台面。灵位单六行。姚炳川那块干净：亡者是他，配氏孙妩已故，西厅穆位，委托单和讣告对得上。佟三喜那块刺眼：外姓，却写在东昭旁格，像谁把别家的牌塞进翟龛。谭淑慈那块纸位出了丧期还没换成木主，馆规里算错位，但人确实故了。第三行最凶：先考翟公禾生，配江纫氏，龛位东昭。

卫棠第一反应是抄错了。丧主签字，名字落到亡者栏，这种事她白天见过。霍勉交接写着：按业务组打印件著录，别自找麻烦。抽屉里另有一张翟晚香的圆珠笔字：我弟还在，粮库的人，别写上牌。

她不是侦探。她是今晚必须交差的临工。台面上有跨站书签：馆对外、晚报、宗亲会、县图、地方帖、公共邮箱、殡葬公示。方案卡六栏空着。权限印在卡头：建议。

### 承（先信抄错，把件摊开）

馆对外页把套餐写得很老实：临时纸位随丧事走，生位另开窗口，不进今晚那一排。安位须知写东昭属父。点主须知写馆方只印不点。

晚报讣告栏有翟守椿：八月十四病故，丧主翟禾生，继室孟秋萍。同一叠里有八月十八地方版，翟禾生还在县粮库领防汛值班奖，人站在照片说明里——说明是文字，照片本页不给看。江纫十九日打进热线，说别把她写成亡者配氏，她一九九八年就离了，人在县城开铺。

委托单摘要在殡葬公示里：亡者翟守椿，丧主翟禾生，配氏栏空着，继室孟秋萍签字。打印件却把丧主填进了亡者。

到这一步，卫棠仍可以停在第一层：祁蔓手滑，模板把丧主写成亡者。交建议时把讳改回翟守椿，像改一个错字。

### 转（生位名单，先信再推翻）

宗亲会旧站名录写翟禾生在世，东房长孙，粮库。翟守椿已故。昭穆页写东昭给父辈。生位页写长生禄位不进丧期龛。传真页露出来：蒲敬山八月二十发给业务组，标题「应入祀预留」，名单第一行就是翟禾生，备注「东昭先占，免被继室挪走」。

公共邮箱同一封还在。祁蔓回了一句：套餐默认应入祀即出纸位，今晚来得及。她不是要咒人，是窗口要关，名单要消化。

地方帖里翟晚香把话摊开：我弟没死。娘（她称孟秋萍）要给爹占东昭。蒲书记要给活着的长孙留生位，也要东昭。业务组一张纸，把活人印成先考。楼下有人骂祁蔓。祁蔓回得短：模板就这样，有意见走文书室建议口。

县图家礼影印把规矩写死：未点主的纸位不成主；在世已离不宜入双人牌；生位与亡者神主不是一种东西。影印页盖的是馆藏章，不是法令。

第一层「抄错」被推翻。不是手滑。是生位被当成丧期亡者排进去。东昭只有一格。占住了，翟守椿进不去，孟秋萍也挤不进配氏。蒲敬山信自己在护长房。孟秋萍信自己在护亡夫。祁蔓信自己在清窗口。霍勉信自己在避祸。

更深一层不挡路：一九九九年馆务通报写过一回，生位混进丧期排，家属告到县里。当时值班的年轻书记员就是霍勉。他被点名。他今夜写「按打印件著录」，不是懒，是怕自己再当那支笔。公共邮箱里还有他那年给自己留的草稿，没外发。不看这封，六栏也能填对。

江纫的事是第二处拧巴，不是钩子本身。打印件配氏写她。她在世，且已离。继室孟秋萍在世，若写入须注在世，不得写成双亡。佟三喜是外姓入祀的近答案，跟翟家这张牌不是一回事。谭淑慈是超期纸位，人故了，只是该换木主。

### 合（方案卡，两处抉择）

六栏开了：讳、配氏、龛位、在世或已故、主件、权限限度。卫棠要交。交了由白班责编决定挂不挂。窗一过二十二点，打印件仍会按原样送去厅里——除非建议写的是暂扣改著录。

抉择一：讳写谁。写翟禾生，就是按打印件，活人继续当先考。写翟守椿，才是按委托单和讣告。

抉择二：权限写到哪。写「批准撤牌 / 代点主 / 直接改打印件」，系统退回，回单作废。写「只建议著录，不挪牌，不代点」，才是这张卡收的。

配氏、龛位、在世栏、主件栏会分出半对的路：只改江纫、不改主讳，活人仍在亡者格；主件若勾宗亲会生位名单，等于承认蒲敬山那张传真能定丧期牌。

暗线不挡路。霍勉一九九九年的草稿只解释他为何怕。不看也能交对。

抽掉「牌上写了活人」这个钩子，故事还在：一格东昭，亡父、继室、宗亲会、业务窗口、怕事的夜班，把一个临工夹在中间。恐怖是信息对不上，不是牌里爬出鬼。

## 第3段　人物小传

**卫棠**  
功能位：临工，今晚唯一能交方案卡的手。  
声线：只在引言里用她的嘴，碎，改口，怕交晚了又怕写错。  
动机：把活人和死人分开，好下班。  
弧光：从「一定是抄错」→看清是生位占东昭→若越权去撤牌会被退；能做的只是建议暂扣改著录。

**霍勉**  
功能位：夜班文书，钥匙和交代的来源。  
声线：短，躲，不解释怕什么。  
动机：别再当一九九九年那支笔。  
弧光：从「按打印件」→建议口仍在→他不拦卫棠交，也不肯自己具名。

**祁蔓**  
功能位：业务组出纸位的人。  
声线：窗口腔，嫌烦，不认咒人。  
动机：应入祀名单要在关窗前消化。  
弧光：从「模板默认」→被楼下骂→把皮扔给文书室建议口。

**蒲敬山**  
功能位：宗亲会传真的发送口。  
声线：半文半白，像通知。  
动机：长房生位先占东昭，免得继室把位子写走。  
弧光：从「预留」→预留被印成先考→他仍可能赢，只要卫棠主件勾错。

**翟晚香**  
功能位：把「弟弟还在」写进抽屉的人。  
声线：急，口语，不怕难听。  
动机：别让粮库的人明天看见自己的讳在厅里。  
弧光：从留条→上帖→若建议写暂扣，她的话才落到纸上；她自己不能点主。

**翟禾生**  
功能位：被写成先考的活人。人不到场。  
声线：无对白。留下领奖稿、名录「在世」、丧主签字。  
动机：他要等木主，不认馆里的红纸。人活着，牌先死了。  
弧光：缺席本身施压。

**翟守椿**  
功能位：真正的亡者。人不到场。  
声线：无对白。留下讣告和委托单。  
动机：无。他已经故了。东昭若被生位占，他进不去厅。

**孟秋萍**  
功能位：继室，要给亡夫占东昭。  
声线：不在论坛说话，只在委托单上签字。  
动机：牌是她男人的，不是长房预留。  
弧光：她若被写成双亡配氏，也是被写错的活人；正确写法是注在世，或不写入今晚这张丧期牌。

**江纫**  
功能位：已离、在世、被印回配氏的人。  
声线：热线更正里一句，干脆。  
动机：别把铺子老板写成亡妇。  
弧光：从被写上→打进晚报→卡上仍可能被勾回去。

**姚炳川 / 孙妩 / 佟三喜 / 谭淑慈**  
功能位：干净对照、外姓近答案、超期纸位。不是工具贴纸：姚的件对得上，用来证明「对得上长什么样」；佟证明外姓入祀是另一件事；谭证明人故了也会错位。

## 第4段　每人抽出的单独故事

**卫棠的今晚**  
她五点半接到电话，说白班请了假。她骑车到馆，霍勉已经走了，钥匙在门垫下。她先以为是六张纸对六份委托，抄完就走。第三张写成翟禾生以后，她去找晚报，又去名录，才明白不是抄写练习。她可以按霍勉的话交，明天有人来吵，吵的不是她——临工名不印在回单上。她也可以写暂扣。写了，白班会问她是不是多事。她若勾批准撤牌，窗直接退。她的弧是：临工想少惹事，最后只能在建议的格子里把活人拎出来。

**霍勉的怕**  
一九九九年他年轻，生位混进丧期排，家属堵门。通报点了他的名。后来他升到夜班文书，专写「按原件」。他不是要害翟禾生。他要一张自己没具名的打印件。他把建议口留给卫棠，等于把一九九九年的笔塞给临工。不看旧通报，也能理解他为何写得那么短。

**祁蔓的窗口**  
她五点要关窗。蒲敬山的传真四点五十到。模板有一栏叫应入祀。她点了出纸。楼下骂她咒人。她回：我印纸，不点主。她的弧是：赶工的人把一种牌当成另一种牌，事后只肯把皮推给文书室。

**蒲敬山的东昭**  
他管名录。孟秋萍是继室，不是原配。他怕东昭写成守椿配秋萍，长房的生位就没了。他发「预留」。预留被印成先考，他不一定改口。他的弧是：护谱的人用错了窗口。

**翟晚香的两张纸**  
她先给文书室留条，字写丑。没回音就去地方帖。她不能点主，家里规矩要男丁。弟弟不肯认红纸。她夹在娘和书记中间。她的弧是：从求人到骂人，最后仍要靠一张她填不了的建议卡。

**翟禾生的缺席**  
他在粮库值班。讣告上他是丧主。牌上他是亡者。名录上他在世。他要等木主。三份网页同时成立，人还在骑车回家。

**孟秋萍的签字**  
她在委托单上签字，配氏栏她空着，觉得自己还活着不该先上牌。打印件却把江纫填回去。她要的是亡夫的东昭，不是自己的成主。

**江纫的电话**  
她在铺子里接到亲戚传话，说牌上有她的氏。她打进晚报热线。她不回翟家，也不争龛。她只要名字离开亡者那一行。

## 多结局

| 键 | 触发 | 逻辑根 |
|---|---|---|
| hold | 讳=翟守椿；配氏=孟秋萍注在世（或不写入、不写江纫）；龛=东昭属亡者，生位不得占；在世栏=牌面翟禾生为在世；主件=委托单与讣告；权限=只建议不挪牌不点主 | 多源对上，建议暂扣改著录 |
| print | 讳=翟禾生，或主件=打印件/生位名单，且权限仍是建议 | 按窗口原件走，活人留在丧期排 |
| half | 配氏改对、主讳仍是翟禾生；或龛位改对但在世栏仍勾已故 | 只拧了一处，钩子还在 |
| over | 权限勾批准撤牌 / 代点主 / 直接改打印件 | 越权，回单作废，原件照送 |

正确收口是 hold。print / half / over 各有根，不是作者宣布。

## 单案种子（备查）

- 标题：牌位勘误  
- 钩子：丧期纸位写了粮库还在上班的人  
- 主角：卫棠  
- 欲望：交差下班，别把活人送去厅里  
- 冲突：一格东昭，生位与亡者抢窗口  
- 反转：先信抄错 → 生位占昭 → 霍勉怕的是旧案  
- 结尾钩子：建议能暂扣，原物仍不归临工  
- 所需素材：灵位单、讣告、名录、传真、家礼影印、方案卡
