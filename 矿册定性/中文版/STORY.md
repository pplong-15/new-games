# 矿册定性　故事

对标机制：Return of the Obra Dinn（名册上每个人给一个去向）。不是 Roottrees 同名排除，不是 Hypnospace 巡站。
民俗基底：legend-mine-haunt。事故后把遇难解释成窑神索祭。游戏动词是对照安监、抚恤、请假、香火账，给网页矿册逐人勾去向，只交复核建议。传说不能当结案。禁止真实矿难受害人姓名。

---

## 第1段　设定

石岭县西洼煤矿已经停产多年。县里要出新一版县志，工矿志这一章必须有一份「西洼窑事故名册」。名册不是安监原卷，是后来有人把晚报、庙碑、旧花名册、香火账扫进同一张网页，十个名字并排，初稿几乎全勾成井下。

县志办主任牟砚秋雇了临聘韩洲。权限只有三件事：打开各站存档、给每一行勾一个去向、写出复核建议。不能改原册，不能替遇难家属签字，不能把传说写进志稿正文当结论。去向只有四档：井下、地面、已迁、误入册。

地方口述说：腊月十八祭窑神，事故那年窑神还要一个名额，碑上才写得成八个人。晚报跟过这句。庙里香火账也出现过碑上没有的名字。安监摘要只写三人入井。抚恤只给这三人发过。有人当天的请假条还夹在矿办旧邮箱里。

窗口错位写在日历上：该做复工安全评估的那几天，矿部和庙里在忙祭。瓦斯和通风在技术页，神罚在口述里。两套话不能焊成一句。

本局县名、矿名、人名、庙名都是虚构，勿去现实对照。

## 第2段　故事（时间线）

表面：网页矿册缺一个名额，窑神要人，韩洲只要把第八个补进井下。  
真相：井下只有三个。第八个是请假的人。碑上另外几个有的在地面，有的早就迁走，有的是还愿。矿部需要「神要的」来压住通风责任。

### 起（二〇二六年八月二十一日　下午到截稿）

韩洲第一天进县志办工矿志复核台。牟砚秋丢下一句：今晚二十四点前把十行去向勾完，明早她要对稿。上一任临聘戴厚山没做完就走了，抽屉里剩几张便条。

韩洲先打开的是石岭晚报资料间。头版旧闻写得明白：窑神还要一个名额，碑上八人，民间说少一个窑就不肯歇。庙管委会站把碑文挂在网上，霍成山、翁二海、尚小满后面跟着宁广福、葛万才、蓝守田、尹福来、曲培义。复核台里的网页初稿几乎全勾井下。先信解释成立——还缺的那一个，就是宁广福。

玩家此刻能做的：打开名册面板，去安监旧站、工会卷宗、庙账、矿工论坛、矿办旧邮箱对每一行。建议单随时能交，交早了容易把传说写成结论。

### 承（对源，先信名额）

碑和晚报把八个人焊在一起。祝长河在庙里管香火，他不是骗子，他信腊月十八少一个人祭不下去。牟砚秋要的是能跟「地方文化」对得上的一章，少惹口述打架。

韩洲若只停在这一层，会把宁广福、葛万才勾进井下，蓝守田、尹福来也会跟着旧花名走。曲培义在晚报里被写成遇难，调度室那夜的话没人听。

### 转（第一层推翻）

安监旧站的事故摘要不认八人。当班入井只写霍成山、翁二海、尚小满。地面岗写曲培义在调度、邢贵林在灯房、谭秋生在井口检身。通风页记的是风机停转，不是神罚。

县总工会抚恤卷只给霍、翁、尚三户发过钱。宁广福那一行空白。矿办旧邮箱里有他当天的请假：县城妇幼，妻子桂绣英临产。香火账后页却有宁广福事后捐的香资——人还在，才写得上捐。

蓝守田二〇一〇年迁柏岚县，尹福来二〇〇八年就办了务工迁出。矿史馆词条写明：停产前有人把旧年终花名整页复印进网页，迁出的人没划掉。

葛万才在香火账上写的是还愿，不是遇难。邮箱里另有一张石岭建材城送货回执，事故当天他的车在县城，不在井口。

先信的「第八个」被请假条、抚恤空白和事后捐香掀开。

### 合（第二层，以及今夜抉择）

戴厚山便条里有一句难听的：矿上要八个人，庙里才肯把复工那天写成祭。曲培义后来在矿工论坛发过帖，说调度室玻璃都麻了，人在地面，风机停转他报过，上面让他少说。霍成山家里不要「神要的」，要通风那一页进志稿。

更深的一层不是鬼，是手续：凑名额让口述和复工对齐，旧花名省得一笔一笔划。韩洲勾的每一行都会变成复核建议。牟砚秋可以不高兴，可她收的是建议，不是批准章。

四种勾法会走向不同后果：

1. 三人井下、三人地面、两人已迁、两人误入册，传说不进正文。  
2. 宁广福或葛万才仍勾井下，志稿沿用「民间亦记第八人」。  
3. 霍、翁、尚被勾成地面或误入册，遇难户从这一章里变薄。  
4. 地面和迁出搅在一起，稿退回重核。

灯管还在响。二十四点是主任的点，不是窑神的点。

## 第3段　人物小传

**韩洲**  
功能位：临聘，工号落在建议单上，勾错也落到这张工号。  
声线：短、复述、改口，敢把一行再读一遍，不敢发明第八个死人。  
动机：想把这单交出去，不想明天被霍家和庙里两头堵。  
弧光：进门时信名额 → 对完请假和抚恤，能说出「传说不能当结案」。

**牟砚秋**  
功能位：主任，施压，不替临聘对每一行。  
声线：短讯体，不解释，只甩截稿。  
动机：工矿志明早要对稿，口述打架别进她科室。  
弧光：下午丢下一句「你自己勾」→ 若建议写技术原因，她得加批注，会烦但收。

**戴厚山**  
功能位：上一任临聘，把拒绝写在便条上。  
声线：碎、骂、漏半句，爱用「别」和「先」。  
动机：自己不肯把宁广福写成井下，怕后任图快。  
弧光：对过请假条就走了 → 抽屉留下四张只指方向的纸。

**宁广福**  
功能位：被写成第八个的活人。  
声线：本人几乎不出场，出现在请假、捐香、妻子口述里。  
动机：那天在县城等孩子，后来捐香是怕庙里怪他没在。  
弧光：花名还在矿上 → 事故日请假 → 被人写上碑 → 事后还去添香。

**桂绣英**  
功能位：把宁广福从井下拉回来的那张时间表。  
声线：急、补句子，只关心孩子和请假条还在不在。  
动机：不要抚恤，要人从碑上下来。  
弧光：产房那天不知道矿上出事 → 后来看见晚报才找工会。

**曲培义**  
功能位：地面调度，知道风机停转。  
声线：论坛里骂、改口、又缩回去。  
动机：想留下「人在地面」，又怕再被叫去问话。  
弧光：当夜报过通风 → 被按住 → 多年后在帖里漏一句。

**祝长河**  
功能位：庙管事，把八个名字当成能祭的单位。  
声线：半文半白，重复腊月十八，不讲风机。  
动机：少一个人，他这庙的祭就圆不上。  
弧光：真心信窑神 → 香火账却留下活人捐资，他自己不拿账当技术页。

**霍成山 / 翁二海 / 尚小满**  
功能位：真正入井的三个人。霍是班长，翁跟班，尚是新来的支护。  
声线：本人不说话，出现在安监、抚恤、灯房台账。  
动机：家属要的是技术原因进志，不要神要的。  
弧光：入井 → 灯未回 → 抚恤三户。他们不是名额。

**邢贵林 / 谭秋生**  
功能位：灯房和井口检身，用来把「在矿上」和「在井下」拆开。  
声线：邢在论坛回灯，谭只出现在检身表。  
动机：邢怕自己发的灯被写成殉职证明。  
弧光：当班在地面 → 初稿仍可能把他们勾进井下。

**蓝守田 / 尹福来**  
功能位：旧花名没划掉的迁出户。  
声线：只在迁出卷和矿史馆说明里。  
动机：人不在石岭，不要突然变成遇难。  
弧光：办了迁出 → 年终表还在 → 被复印进网页。

**葛万才**  
功能位：还愿的外包瓦工，香火账上的烟雾。  
声线：送货回执冷，庙账土。  
动机：还的是去年许的口愿，不是给自己烧。  
弧光：事故日人在建材城 → 账上出现名字 → 碑文借走当第八个的备胎。

**钱不器**  
功能位：安监摘要执笔，把入井人数写死。  
声线：公文短句，不跟口述吵。  
动机：通风页要留在卷里。  
弧光：写过三人入井 → 看着晚报写成八人，他没有改稿权。

## 第4段　每人抽出的单独故事

**韩洲的一天**  
下午报到，工牌还是临时的。牟砚秋不带他认门，只指复核台。晚报第一篇就写名额，他差点按八人勾完。后来请假条从旧邮箱里翻出来，抚恤三户对不上碑上八行，他才敢在宁广福那一行改口。交建议的时候，他要么把传说写回去，要么把技术页留下。工号都在单上。

**牟砚秋的截稿**  
科室就她和一个临聘。工矿志这一章拖了两个月，戴厚山把宁广福那一行空着走了。她要的是能付印的表，不是再开一轮口述。韩洲若交来三人井下，她得加「民间另有祭名，不作事故结论」这种批注，她嫌烦，可事故单她更怕。

**戴厚山的尾班**  
他对过请假条，也去庙里抄过账。祝长河跟他说少一个人祭不圆。他在便条上写「别把名额当人数」，写完第二周没来。韩洲看见的是没写完的脾气，不是指南。

**宁广福和桂绣英的那天**  
十二月九日他们在县城妇幼。孩子晚上才生。矿上的电话打到产房已经乱了。后来有人拿晚报来，上面有他的名字。他去庙里添过一笔香资，想把名字从嘴里洗干净，账上反而多了一行。

**曲培义的夜和多年后的帖**  
风机停转他报过。上面说先祭再评估。调度室没塌，人在地面。晚报把他写进遇难，他气过，也怕。论坛那帖发了又改，最后留一句：玻璃都麻了，人没下去。

**祝长河的腊月**  
他守这庙二十年。事故那年腊月十八，他按八个名字摆了香。少一个，老人们不答应。香火账他不假，可账不是安监。韩洲若来问第八个，他会把碑指给人看。

**霍成山那一班**  
霍带着翁二海和尚小满入井。灯房邢贵林发了三盏灯。灯没回来。工会后来只给这三户办抚恤。霍的女人不要窑神，她要风机那一页被人看见。

**邢贵林的灯**  
他在灯房。台账上三盏出、三盏未回。初稿有人把他也写成井下，只因为他在矿部路上班。他后来在论坛回过一句：发灯的人没跟着下去。

**谭秋生的井口**  
检身表有出、有入。霍那一班入了。曲培义没入。宁广福当天没有检身记录。谭自己站在井口坡，爆炸那一下他在地面蹲下来。晚报没写他，初稿有一版把他勾进井下，后来又改回地面，网页留了两层。

**蓝守田的迁**  
二〇一〇年四月迁柏岚县，矿上办过离职。二〇一一年年终花名还有他，保管员懒得划。网页一复印，他就成了遇难。

**尹福来的务工**  
二〇〇八年九月走，人在外省工地。家里寄过香，庙账写「尹福来寄」，不是「尹福来故」。碑文抄名的时候把「寄」字吃了。

**葛万才的还愿**  
外包瓦工，去年许过口愿。事故当天他的农用车在石岭建材城卸砖。账上「葛万才还愿」被晚报理解成「葛万才也在里面」。他后来还来问过：我还的愿，怎么变成我。

**钱不器的摘要**  
他只写三人入井、风机停转、地面三人在岗。稿子出门以后，晚报和庙碑继续走自己的。他没有改晚报的章。

## 线索与伏笔

| 掉落 | 指向 | 回收 |
|---|---|---|
| 晚报「还要一个名额」+ 碑文八名 | 先信第八个是宁广福 | 请假条、抚恤空白、事后捐香 |
| 安监入井三人 | 霍、翁、尚井下 | 抚恤三户、灯未回 |
| 安监地面岗 | 曲、邢、谭地面 | 论坛调度帖、灯房回帖、检身表 |
| 迁出卷蓝／尹 | 已迁 | 矿史馆旧花名复印说明 |
| 香火账还愿 + 送货回执 | 葛万才误入册 | 碑文借名 |
| 通风页、戴便条、曲帖 | 凑名额为了祭和复工对齐 | 暗线，不勾也能交 |
| 桂绣英找工会 | 宁家不要抚恤 | 晚报后续 |

被砍的支线：不下井实操、不开真实矿难名单、不写「再祭一个就可复工」。

## 与已作差异

不是金罂同名的「两个同名按年/址排除」，不是腊月巡站的关站，不是过继上传的勾字段。本局十行各有一个去向，对的是当班位置和在不在册，不是认哪一格。

## G0–G12（扩写备查）

- G0 Thriller / Crime 义务：给名册定性，不批准原物。价值轴：传说结案 ↔ 技术结案。  
- G1 韩洲，今夜二十四点交十行建议，不做则戴厚山的空表原样付印。  
- G2 见第3段。  
- G3 迷宫=各站权限（临聘只读）；MacGuffin=能付印的十行；红鲱鱼=窑神名额；私人化=工号韩洲；时钟=截稿；双声口=安监公文 vs 庙/晚报口述。  
- G4 二〇〇八尹迁出→二〇一〇蓝迁出→二〇一一·十二·九事故→腊月十八按八人祭→抚恤三户→网页复印旧花名→戴厚山拒勾→二〇二六韩洲临聘。  
- G5 玩家先见晚报/碑/初稿，后见安监三人，再请假与抚恤，迁出与还愿可穿插，通风为暗线。  
- G6 每条主结论≥3源：井下三人（安监+抚恤+灯），宁误入（请假+抚恤空+捐香），葛误入（还愿账+送货+检身无），蓝尹已迁（迁出卷+矿史馆+碑误抄），曲地面（安监岗+本人帖+检身无入井）。  
- G7 安监能证当班位置，不能证家属心情；香火账能证有过捐资，不能证死亡；晚报能证口述流通，不能证人数。  
- G8 义务时刻=交复核建议。  
- G9 切片：宁广福一行，先信井下，请假条价值从「缺一个人」转为「活人被写进碑」。  
- G10 adopt / legend（erase、chaos 为额外行为结局）。  
- G11 不告诉玩家真实矿难对照，不给「再祭一个」的操作。  
- G12 文件口吻=安监/抚恤；活人口吻=论坛曲培义、庙祝长河。
