# 矿册定性　文案习惯（humanize 0.9）

书写习惯是站点的，不是人物标签。改口、漏字段、重复嘱咐都留着。不灌水，不加金句。

| 站点 | 习惯 | 怎么写 |
|---|---|---|
| 临聘纸 `introduction.html` | B 冷陈述体 | 短句交代工号、四档、只出建议。不抒情。 |
| 复核台 `office/*` | B + 短讯夹条 | 牟砚秋短、不解释。戴便条碎、第四张才写死。名册是表。 |
| 安监旧站 `anjian/*` | D 公文节选 | 钱不器短句，入井与口述分开。通风页不跟神罚吵，只挡。 |
| 晚报 `news/*` | B 报馆体 | 米晚晴图快焊花名。社会组抄碑。后续才肯补妇幼。 |
| 庙站 `temple/*` | C 半文土口 | 祝长河认祭不认罐笼。账上捐、寄、还愿分写。 |
| 工会 `union/*` | B 卷宗体 | 房阿菊只认三户。假条、迁出各是各的钉。 |
| 矿工帖 `forum/*` | A 论坛改口 | 老曲骂完缩。邢灯房护台账。老李说完又行吧。 |
| 矿史馆 `museum/*` | D 词条注 | 传说层黄条。花名漏划写成说明，不写成鬼。 |
| 旧邮箱 `mail/*` | B 邮件体 | 劳资短、知会一句。建材回执冷。 |
| 联查中转 | B 机内回执 | 「找到 N 份」「查不到」「不对临聘开放」。不上搜词、汉字词。 |

## 声口对照（防同声）

- 韩洲：复述字段，改口，不敢发明第八个死人。  
- 牟砚秋：短讯，甩截稿。  
- 戴厚山：便条漏半句，第四张才不耐烦。  
- 祝长河：半文，重复腊月十八。  
- 曲培义：帖里骂，随即改一嘴。  
- 桂绣英：只要名字从嘴里拿下来，不要钱。  
- 钱不器：摘要不跟口述吵。  
- 房阿菊：发放底，挡第八份。

## 结局动态

`office/result.html` 的理由段读 `kc_seen`：见过假条/邮箱、抚恤、晚报/碑、入井/迁出，各走不同句子。判定优先级与 `register.js` 的 `pick` 一致：erase 先于 legend，再 chaos，全对才 adopt。
