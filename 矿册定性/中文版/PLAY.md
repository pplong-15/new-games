## Token DAG

```
[开局：韩洲、十行、截稿、晚报名额先可见]
        │
        ├─ 读晚报/碑/初稿 → T-传说八人
        ├─ 读安监入井 / 抚恤 / 灯帖 → T-井下三人
        ├─ 读地面岗 / 调度帖 / 检身 → T-地面三人
        ├─ 读请假抄件或邮箱原件 / 抚恤空行 / 捐香 / 后续 → T-宁误入
        ├─ 读还愿账 / 送货回执 → T-葛误入
        ├─ 读迁出卷 / 旧花名 → T-蓝尹已迁
        ├─ 读通风 / 复工错位 / 戴便条（可选）→ T-凑名额
        └─ 名册勾齐送复核 → adopt / legend / erase / chaos
```

无环。建议单无前置锁，避免死锁；交早了走错结局。通风与戴便条不是必经。

## 逐题五步

### 题0　进台看见十行

- 看到：临聘纸说明韩洲、四档、只出建议；复核台把晚报名额和名册面板放在同层。  
- 能做：开名册，或先点晚报、碑文。  
- 映射：任务成立，先信解释（还缺一个名额）被摆在嘴边。  
- 触发：持有开局 token。  
- 错：按初稿全勾井下就送。系统照收，走 legend 或 chaos。

### 题1　先信名额

- 看到：晚报「窑神还要一个名额」、碑上八名、初稿多勾井下。  
- 能做：把宁广福、葛万才理解成第八个。  
- 映射：Obra Dinn 先接受现场最响的说法。  
- 触发：T-传说八人。  
- 错：把传说直接写成志稿结论。权限页已写不许。

### 题2　用安监和抚恤钉死井下三人

- 看到：入井名单霍翁尚；抚恤三户；灯三盏未回。  
- 能做：这三行勾井下。  
- 映射：能证明入井的，只有这三人。  
- 触发：T-井下三人。  
- 错：把地面岗、迁出户勾进井下；或把这三人勾成误入册。

### 题3　用请假和账推翻第八个

- 看到：宁广福请假去妇幼；抚恤无他；香火账事后捐；晚报后续桂绣英否认。  
- 能做：宁广福勾误入册。  
- 映射：名额不是人数。  
- 触发：T-宁误入。  
- 错：继续勾井下，走 legend。

### 题4　拆地面、已迁、还愿

- 看到：曲邢谭地面岗；蓝尹迁出；葛还愿+送货。  
- 能做：三行地面、两行已迁、葛误入册。  
- 映射：在矿上 ≠ 在井下；账上有名 ≠ 遇难。  
- 触发：T-地面三人、T-蓝尹已迁、T-葛误入。  
- 错：把迁出当井下，把还愿当遇难。

### 题5　交建议（伦理点）

- 看到：送复核，权限写建议。  
- 能做：十行勾齐提交。  
- 映射：临聘不批准原物；传说不能当结案。  
- 触发：四结局。回执按已读页换理由。  
- 错：四路都合法提交，没有「必须选对才能点」。

## 每步解锁

不靠刷新楼层。新档靠站内链或联查命中。晚报、安监、工会、庙在复核台首页已经点名，前几步是送的。便条按点击展开，不替勾选。

## 四级提示（戴厚山便条，前三档不写死十行）

1. 方向：先对当班位置，别先对庙里的人数。  
2. 范围：抚恤和入井名单是一摞，碑和晚报是另一摞。  
3. 操作：宁广福那天的假条还在，账上还有他事后的香资。  
4. 完整：霍翁尚井下；曲邢谭地面；蓝尹已迁；宁葛误入册。

## 新手不迷路

1. 三十秒同屏：韩洲、今夜截稿、名册十行、四档去向。  
2. 链：西洼 / 窑神 / 名额 → 传说；霍成山 → 入井；宁广福 → 请假；蓝守田 → 迁出；葛万才 → 还愿。  
3. 联查有中转页；交建议有回执。  
4. 进度用「建议未交 / 已交」和名册待核行，不上游戏条。  
5. 前步送词（西洼、窑神、名额、霍成山、宁广福写在临聘纸和复核台），中段才要主动对迁出和还愿。

## limits

- 只 `recommend`，不批准原册、不教下井、不教伪造抚恤。  
- 答案由页上可见文字推出，不靠 F12、外搜、改 URL。  
- 主线不依赖真实矿难受害人姓名。
