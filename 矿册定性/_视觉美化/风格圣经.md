# 矿册定性　风格圣经　polish-20260823

相机锁死：正视 2D 网页平面。无透视、无一层视差、无 Canvas 粒子、无插画房间冒充公文。中英同一相机；英文开局仍用同一张空桌静帧，不另出图。

比例：名册是后台表，不是关卡条。桌面宽名册三列（姓名 / 初稿 / 四档）；320 / 390 每人一块：姓名+初稿在上，四档 2×2 在下，十人十档全在，禁止横滑藏档。所有者栏宽按皮（青台 960、红头 1000、晚报 960、庙 778、论坛 960、百科 960、邮箱 960、卷宗 min(800,92%)、联查盒 720），窄屏只把栏拉满，不把十套皮收成同一张卡。

线宽 1x：1px 实线为主。选中档 2px 实线 + 左 5px 内条 + 加粗 + 「✓」；未选 1px 虚线。警告空行 2px 虚线框 + 左 8px 实条。焦点 3px 点线。禁止 8px 全站圆角白卡。

主材质 `material_id=county-web-2010-fluorescent`：2010 年前后县级站 HTML 表 / float / 宋体或雅黑栈，略糊 JPEG 静帧。引言唯一纸面：灰底白卡片临聘纸。联查命中是另开灰结果盒；禁止是黑底红字整页，不是模态。

光：顶光，无动态光。强调色只绑功能（联查提交钮、空行警告、禁止页、焦点），不绑四档对错、不绑 adopt 正解。

## 名册状态（不唯色）

| 态 | 形状 / 字 | 不靠什么 |
|---|---|---|
| 未选档 | 1px 虚线框、字重正常 | 不只靠灰字 |
| 已选档 | 2px 实线 + 左内条 + 加粗 + ✓ | 不只靠填色 |
| 空行警告 | 虚线匣 + 左实条 + 加粗句 | 不只靠红字 |
| 焦点 | 3px 点线外框 | 不靠 hover |
| 回执 adopt | 实线匣 + ■ 标题前缀 | 不给正解镀金 |
| 回执 legend | 虚线匣 + □ | 近答案，不是死档 |
| 回执 erase | 双线匣 + × | 与 adopt 不同框 |
| 回执 chaos | 点线匣 + ↺ | 可作废重开 |
| 减动 | 工会戳不旋转 | 戳框仍在 |
