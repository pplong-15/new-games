# 风格圣经　过门路单

相机：正视驾驶座，锁死。不引入透视或 Canvas 粒子。

比例：人（路单身份栏）: 门（静帧堂屋）: 手持纸（副驾公文）≈ 标签 : 景 : 物件。纸必须大于按钮字。

线宽：公文 2px 实线；夹板红栏 1px；后视镜壳 5px。

主材质：夜间乙烯仪表 + 六种纸/屏，不是同一张奶油卡。

三色锚：
- 主 #141612 座舱
- 次 #e6dcc8 字
- 功能 #c45c3a 只绑「本单听这一份」长按

所有者（涂黑标题仍要能指）：
1. 车队 — 发黄铅印、宋体、歪红方印
2. 铅笔 — 撕边、格子、楷斜、铁夹
3. 喜条 — 红口折纸
4. 丧条 — 黑挽边折纸（与喜条同叠不同页）
5. 短信 — 功能机壳 + 绿灰 LCD
6. 路单 — 木夹板铁夹红栏表
7. 后视镜 — 镀铬椭圆玻璃

禁：边检亭、便利货架、园图、全站圆角白卡、金头更官方。

减动：长按斜纹立刻满，不取消形状差。
