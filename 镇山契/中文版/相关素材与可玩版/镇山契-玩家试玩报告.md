# 《槐县历史专卷数字化复核项目：镇山契》玩家试玩报告

### 1. 这是什么体验

这是一款**极度冷峻、克制却又后劲极大的“档案考据与证据链质检”叙事解谜游戏**。如果类比的话，它就像是《奥伯拉丁的回归》遇上了《Papers, Please》，外加层层包裹的中式地方志怪与现实历史悲剧。

玩家的身份是 2026 年槐县历史专卷数字化复核项目的质检员（QC-447），面对工单 `QA-26-0813-447`。你的核心任务不是扮演能打能杀的侦探，也不是去轻率地“脑补破案”，而是坐在电脑前，对着 1964、1971、1974、1982、1998、2004 直至 2026 年跨越数十年的各种数字化档案副本（公文、现场勘查卷、录音波形图、病历卡、DNA 亲缘图谱、建筑测绘差值图、地质滑坡报告）进行**证据链边界核对与数字质量把关**。

最让人脊背发凉也最抓人的地方在于游戏对**“职业边界”**的执着——它时刻提醒你：
- “数字化副本同页不代表实物同处”；
- “分类只证明材料归位，不证明事实真伪”；
- “时间或空间相合，不等于超自然因果成立”。

整部作品把“冷冰冰的行政质检流程”与“深藏在纸背与夹墙阴影里的槐县儿童失踪、荒村伪造民俗、二十年隐居与山崩之夜”融合得极为惊艳。

### 3. 卡点与误导

1. **思维惯性带来的“过度推论”陷阱（最大卡点）**：
   - 普通推理游戏往往鼓励玩家“大胆假设，指出真凶”，但本游戏的核心规则是“证据到哪里，结论就停在哪里”。
   - 例如在第 4 章第 3 项中，“1998-07-19 23:41 的北坡滑坡时间恰好落在第三夜窗口”，很多玩家会本能地选择“证明了超自然机制引发山崩”，但正确选项必须选择“仅形成条件相合，自然机制充分，不确认额外因果”。如果脑补过多就会直接报错。
2. **覆写层与还名阶段的信息混淆（细微卡点）**：
   - 在第 3 章第 1 步提取 1974 覆写层字段时，选项中混有“三个匿名位置号”与“三名儿童姓名”。我一度以为应该选儿童姓名，但仔细看原始档案才发现：1974 年恶徒在覆写契约时根本没有写真名，写的是冷冰冰的代号（`POS-EAST-1` 等），名字是 2026 年通过现代医学与户籍卷宗重新考证还原出来的。
3. **“第三夜”的计算口径误区**：
   - 如果按常识以 72 小时（3×24h）倒计时或者自然日（00:00-24:00）来算，就会算错。必须严格遵循 1964 年地方民俗规定的“显式民用日期与 18:00—次日06:00 夜班表”来界定第一夜、第二夜与第三夜。
4. **精妙的故事误导**：
   - 1998 年警方的旧结案报告单方面把所有责任扣在“阿山”头上，制造了强烈的先入为主假象；
   - 所谓“古老神圣的镇山契”，底层其实是三户轮守的互助契约，后来被某些人在 1970—1974 年恶意刮改，伪造成了残酷的“三基一守、生人替死”的迷信伪契。

### 4. 乐趣和烦点

#### 🌟 乐趣所在：
- **极具信服力的档案质感与中式怪谈**：
  从病历卡的字迹、骨折愈合阴影、正射影像图、到泛黄的毛笔契约与覆写痕迹，美术和文案营造出了一种极其冷峻的年代真实感。
- **“还名”带来的强烈情感冲击**：
  当方小禾、邓梅、许有生这三个被掩埋在荒村历史尘埃中半个世纪的名字，通过一处处骨折旧伤、牙齿充填、学籍档案和亲缘图谱被重新拼凑、一一对应并摆脱匿名代号时，那种“以制度与证据还逝者以尊严”的成就感非常震撼。
- **克制而高级的叙事留白**：
  游戏没有为了廉价的爽感强行给出一个非黑即白的玄幻答案，而是让自然机制（暴雨与页岩软化）和民俗巧合（第三夜无后手）并存，把未决的问题诚实地留在档案里。

#### ⚠️ 烦点所在：
- **跳转回执的操作链稍显割裂**：
  每完成一项核对，流程通常是：`保存面板 -> 提示返回工作台 -> 点击读取回执 -> 点击留在工作台/标为已读 -> 点击打开当前复核面板`。在多面板联动的复杂步骤（如 U1 四面板、三儿童三面板）中，这种频繁的“进出工作台”会让沉浸式心流被打断。
- **多选题报错反馈偏生硬**：
  当一个包含 4~5 个复选框的面板提交失败时，系统只会提示通用的红字“当前组合仍有字段不符合要求”，玩家很难知道是“多选了一项过度推论”还是“漏选了一条客观事实”，容易演变成排除法试错。
