## 0. 本轮采用的新定义

本报告完全采用以下定义，不再把“乡土制度压迫”本身视为中式恐怖：

> **中式恐怖，是由中国本土的鬼神观、生死观、民间信仰、仪式和禁忌实际产生的恐怖。人情、家庭、宗族压迫与历史创伤可以解释悲剧为什么发生、谁利用了仪式、谁承担代价，但不能单独构成中式恐怖。**

因此，本作必须同时具备四层：

| 层级 | 必须存在的内容 |
|---|---|
| 本土超自然本体 | 明确的神、鬼、魂魄、生死归属或人与非人秩序 |
| 仪式运行机制 | 契券、姓名、方位、交接、禁忌为什么在该信仰中有效 |
| 人为悲剧机制 | 谁篡改、利用或违反仪式，谁从中获利，谁承担现实伤害 |
| 超自然后果 | 至少一项后果在创作者真相层由本土超自然规则真实产生 |

玩家证据层可以继续把超自然因果标为 `unresolved`，但创作者真相层不能也保持“不知道”。

如果删除鬼神、仪式和禁忌后，故事仍可原样成立，那么它只是乡土罪案或制度悬疑，不是本报告所说的中式恐怖。

## 1. 执行摘要与评分

### 1.1 总体判断

v3.3 的法证调查骨架明显强于中式恐怖骨架。玩家可以完成一条相对扎实的：

```text
错卷纠正
→ 传言分层
→ 门闩验证
→ 八人登记与第九人
→ 隐藏空间
→ 身份恢复
→ 契文与滑坡时间吻合
→ 归档选择
```

但现稿的中式恐怖主要仍是：

```text
旧文书描述了一套仪式
＋现代档案流程与它长得相似
＋三日后出现一次自然可解释的坡体位移
```

这会使玩家产生“设计很巧”的反应，却未必产生“这里真的存在一套本土鬼神秩序”的恐惧。

## 2. 应继续保留的部分

以下方向是正确的，不应因本轮重构而推翻：

- “第九位到访者”由门槛口径和隐藏入口推得，不再拿旧尸凑人数；
- 阿山只被排除为独自造成全部死亡者，不输出超出证据的法律无责；
- U1身份、门闩接触、守者角色和致死责任被拆成不同命题；
- 三名儿童分别恢复姓名、生活材料和身份链；
- 阅读、搜索、OCR和恢复姓名不会惩罚玩家；
- 公开网页在fresh、中段、结局态保持同一事实；
- 地质链足以解释坡体位移，避免“看到异常就宣布鬼神”；
- 最终操作发生在玩家有现实权限的工作范围内，而不是突然让玩家施法；
- 两种选择都应有现实收益和代价，不标好坏结局；
- 不使用鬼脸、闪屏、血字、尖叫、读取真实用户名和设备信息。

这些内容是下一版仍应使用的推理与伦理底盘。

## 3. P0：故事逻辑与创作者真相没有闭合

### P0-1：作者层没有任何真实的超自然真相

现稿把以下内容全部设为 `unresolved`：

- 旧契是否有效；
- U1是否是守者；
- 儿童是否因契被害或被束缚；
- 1998滑坡是否存在超自然因果；
- 2026档案操作是否触发旧契。

这在玩家证据层是谨慎的，但在创作者真相层意味着作品自己也不知道有没有鬼神。按本轮定义，这仍然是民俗题材的档案悬疑。

#### 必须建立双层真相

```text
creator_truth：故事世界实际发生了什么
player_claim：网页证据允许玩家确认到什么程度
```

例如：

| 命题 | 创作者真相 | 玩家证据状态 |
|---|---|---|
| 北坡山神是否存在 | true | unresolved |
| 1974恶契是否被受纳 | true | highly_compatible / unresolved |
| 三名儿童之魂是否被错误名分束缚 | true | unresolved |
| U1是否承担守位 | true | compatible_only |
| 1998坡移是否含超自然作用 | true，借自然链显现 | unresolved |
| 降雨与页岩是否足以解释坡移 | true | confirmed |

“自然机制为真”和“超自然同时为真”可以并存。不能用创作者也不知道来制造假深刻。

### P0-2：“镇山契”没有非人契约方

当前“契”只有档案操作条件，没有回答：

- 人在和谁立契；
- 对方为何有权管理北坡；
- 人方得到什么；
- 人方必须付出什么；
- 谁见证、谁收券；
- 违反后为什么产生相应后果。

没有非人契约方，“契”只是一个魔法配方。

#### 下一版必须锁定一套单一体系

推荐：架空南方丘陵汉族村社的“北坡山神契”。

```text
人方：槐北众户／三社
非人方：北坡山神，村民俗称“坡公”（虚构地方称谓）
所涉对象：北坡界地、排水沟、祠址和山路
人方所得：借界开沟、建祠、居住和取水的许可与庇护
人方义务：供灯、守更、按期交牌、妥善接引坡界内无祀亡魂
见证：香首、水首和三户户主
物质凭证：人间存券、告山副券、合缝印、守牌
```

不要同时把山神、后土、土地、城隍、祖先和孤魂写成可以互换的同一存在。

### P0-3：没有明确的生死观与亡魂状态

当前三名儿童只是：

```text
遗骸身份
＋地坪位置
＋“三童镇基”文字对应
```

但作品没有回答他们死亡后处于什么状态，为什么姓名、位置和契文会影响魂魄。

#### 推荐的虚构地方生死观

必须明确标注为槐北虚构地方异文，而非全国通行民俗：

- 有姓名、有家属接领并完成安置的亡者，才可以“归家入祖”；
- 无名、异地秘密埋葬、无人接领者成为“无祀魂”；
- 坡界内的无祀魂暂归山神辖域，需以灯引路、由活人守夜，等待家属或村社接领；
- 契券若把人的姓名改写为位置、物件或职役，非人一方会按契中名分执行；
- 三名儿童的恐怖不是“童尸能量强”，而是活人抹去他们的姓名，把三个具体的人改写成三个灯脚位置；
- U1的恐怖不是“傻子通灵”，而是其姓名被撤去后只剩一个不能退出的守位。

由此，恢复姓名有伦理价值，但不会自动解除物质契券；身份纠错与仪式解除仍是两件事。

### P0-4：原契与恶契的规则互相冲突

现稿同时存在：

```text
守者不得离
三日有人接才算交守
先看三日
三日内有人接
满三日后再交
```

永久不得离与轮流交守不是一套规则；“三日内”“满三日”“第三自然日”也不是同一算法。

#### 必须把原契和恶契分开

推荐结构：

**原契：**

- 三户轮灯；
- 三名孩子只负责引灯过门，随后回家；
- 一名成年人雨夜守更、听水看石；
- 守满三宿后，下一户合券接牌；
- 后手接，前手才能退。

**1974恶契：**

- “引灯后归”被改为“三名落灯脚”；
- “轮户守更”被改为“一人守界”；
- “后手接，前手退”被改为“后手不至，前守不退”；
- 因接收栏长期空白，守位变成事实上的永久拘禁。

这样三夜交接和不得离不再互相矛盾：不是绝对不能交，而是没有合法接手者就不能退。

#### 唯一允许的状态机

下一版必须把契约状态写成可执行规则，禁止同一处“三日”一会儿表示最低保管期，一会儿表示最长移交期，一会儿又表示灾变倒计时：

| 状态 | 成立条件 | 可进行动作 | 失败后果 |
|---|---|---|---|
| `DORMANT` 旧券散失 | 两券未合、守牌无有效经手 | 阅读、扫描、OCR、数字拼接 | 无仪式效力 |
| `OPEN` 契券续开 | 两券实体合缝、合同印复原、守牌入组、固定经手人落押 | 在第三夜鸡鸣前完成有效交牌或退契 | 经手人处于临时看契位 |
| `HANDED_OVER` 已交手 | 后手以同一实体守牌和尾券接押 | 前手退出，后手承担下一轮 | 不触发空守 |
| `VACANT` 守位空缺 | 前手退出或实物被拆散，且没有有效后手 | 只能执行退契补救 | 第三夜出现“坡开”条件 |
| `RETIRED` 已退契 | 还名、撤职、告山退券、遗骸安置、守牌收回均完成 | 正常保存史料 | 旧契不再续开 |

“第三夜”只从`VACANT`形成后的首个完整夜晚起算；不要再折算为精确72小时15分。

### P0-5：历史仪式时间线没有锁定

1970交割笺早于1971—1974三名儿童失踪和三次地坪工程，却被用来解释四件契、末校和三日交手。当前无法回答：

- 改契何时写成；
- 三次失踪发生在契前还是契后；
- 三处地坪何时与仪式结合；
- 何时告契、合券、画押；
- U1何时被指定为守者；
- 旧契何时真正开始生效。

#### 推荐固定时间表

| 年份 | 创作者真相事件 |
|---|---|
| 1964 | 原始“借山守坡契”被民俗调查记录；采用轮灯、守更、三宿交牌 |
| 1970 | 掌权者借祠堂修缮开始修改契文，但尚未完成受契 |
| 1971 | 第一名儿童失踪；第一次地坪工程 |
| 1973 | 第二名儿童失踪；第二次地坪工程 |
| 1974 | 第三名儿童失踪；第三次地坪工程；恶契两券合缝并举行一次明确的告契、受契、交牌仪式 |
| 1975 | U1的姓名从正常名册中消失，被写入守位或交手尾券 |
| 1982 | “守人离，三日北坡开”的残余说法进入公开地方材料 |
| 1998 | U1离开；三名成人死亡；第三夜发生坡移；自然与超自然因果同时存在 |
| 2026 | 水损材料与实体契券重新进入修复、著录和处置流程 |

具体年份可调整，但顺序不得再模糊。

### P0-6：现代档案操作缺少物质仪式桥

山神不能识别：

- OCR结果；
- 数据库布尔值；
- `QC-447`账号；
- “组合著录”这个现代元数据概念；
- 玩家是否在网页上勾选了一个框。

如果现代触发只依赖这些内容，它仍然是SCP式数据库异常，而不是本土仪式。

#### 推荐修改

真正的仪式物只保留：

```text
人间存券半叶
＋告山副券半叶
＋合缝印
＋守牌／交手尾券
```

方位图、访谈页、修缮账只是证据，不是魔法组件。

玩家的网页操作必须代表一个现实物质动作：

1. 玩家确认两半契券属于同一件文物；
2. 生成“实体合缝复原”或“分片封装＋数字参见”建议；
3. 档案保管员或修复员按已授权方案操作实物；
4. 一个有固定世界内身份的人完成经手签名；
5. 另一责任人接收或留下空白接收栏。

玩家可以使用固定虚构身份，不读取真实玩家姓名。操作账号和仪式责任人不得偷换。

#### 必须回答“无意操作为什么会生效”

建议锁定为：1974恶契已经被受纳，现代人不是重新发明仪式，而是在续动一件仍有效的旧契物。因此是否相信鬼神不重要，但必须同时满足四项物质条件：

```text
实体两券合缝
＋旧合同印恢复完整
＋守牌与尾券进入同一实体组
＋一名有现实权限的经手人在实物处置单落押
```

少一项都不生效。拍照、扫描、OCR、数字拼接、临时并排、数据库关联和阅读正文一律不生效。这样既保留“无意触犯禁忌”的恐怖，也不会把任何普通档案操作变成任意触发器。

### P0-7：初始状态已经近似满足旧规则

`WT-26-04` 已经把四件材料放在同一保全盘，`QC-447`又是保管席位。玩家会合理质疑：为什么开场不算重成？

必须改成：

> `WT-26-04`只是一张水损待核任务清单。四件实物仍分别置于独立隔离套及原保管单元，只在系统中被同批次引用。

“四件”也不应继续作为魔法数量。它最多说明1974某一历史包件恰有四张记录。真正有仪式效力的是两半契券及交手物。

### P0-8：两结局没有清楚的超自然因果模型

现稿两边都看到同一条轻微坡体位移：

- A分支：玩家没有离岗、仍在暂存，坡却动了；
- B分支：没有重新成契，玩家也未被确认是守者，坡也动了。

这会同时削弱两个解释。选择不改变任何世界因果，最终更像象征性问卷。

下一版必须在创作者层选择一种明确模型。

#### 推荐模型：不对称真相、有限可见差异

**A｜实体合券复原：**

- 创作者真相：恶契被临时续接；经手人处于待交手位置；三名儿童的旧束缚继续；
- 玩家可见：坡体整体稳定，但三个旧灯位附近的浅层压力数据异常同步，接收栏仍空；
- 自然解释：修复工程、含水变化和传感器误差均可能造成该数据。

**B｜分片封装＋数字参见：**

- 创作者真相：没有续契，旧束缚开始松动；三条向旧村路方向的浅层位移借降雨条件发生；
- 玩家可见：局部小幅位移，未达预警阈值，无人伤亡；
- 自然解释：持续降雨、软弱夹层和坡脚冲刷仍充分。

两边都不能标好坏：A维持地表秩序，却可能继续束缚亡魂；B可能让亡魂离位，却使山体发生小幅变化。玩家无法从网页证明这种解释。

如果主创坚持两边显示完全相同的监测正文，则必须另给两边不同的、与契约物质状态相关的项目日志，否则分支在叙事上没有实际作用。

### P0-9：“第九位到访者”与镇山契缺少因果桥

目前第九人是人数谜题，镇山契是后段仪式谜题，二者主要靠U1同时出现在两条线中连接。

禁止为了强接而写“九为极数”“第九人必是祭品”等万能数字玄学。

推荐明确：

- “第九”只是1998案卷的法证标题，不是仪式数字；
- 第九人之所以重要，不是因为九有法力，而是因为他从隐藏室跨出，证明被从登记制度中抹掉的人真实存在；
- 玩家确认U1后，再通过守牌、生活痕迹和契券尾栏发现：这个未被登记的人正是恶契里的守位承担者；
- 两条线通过“被抹去的人”连接，而不是通过神秘数字连接。

## 4. P0：中式鬼神本体不足

### 4.1 当前元素不少，但有效元素很少

现稿已有：

- 门槛；
- 祠庙；
- 守夜；
- 三灯；
- 三童；
- 契函；
- 山坡；
- 三日；
- 骑缝章；
- 接收空栏。

问题不是数量不足，而是这些元素被数据库化：

```text
门槛 = 人数分类器
三灯 = 坐标点
契 = 组合包件
守者 = 质检席位
三日 = 精确倒计时
坡体位移 = 结尾巧合
```

它们没有共同构成“鬼神如何看待人、死者如何安顿、仪式为什么有效”的世界观。

### 4.2 下一版的最低中式恐怖要求

至少必须让玩家逐步理解：

1. 槐北人相信北坡是有主之地；
2. 开沟、建祠和安置无主亡者都需与山神立券；
3. 姓名决定死者是“归家之祖”还是“坡界无祀魂”；
4. 三灯原本负责引路，不是祭祀能量装置；
5. 守者原本是临时接引和守界的人；
6. 活人篡改契文后，把三个孩子从“人”改写成“位置”，把一名守者从“人”改写成“职役”；
7. 非人一方不主持正义，只按受纳的契文执行；
8. 自然条件是山神显效的载体，而不是与超自然互相排斥的另一答案。

### 4.3 禁止民俗万能拼盘

除非完成具体地区、历史与传承链考据，否则禁止混入：

- 童男童女天然适合献祭；
- 纯阴八字；
- 龙脉、风水、山神、后土、城隍、土地公同时管同一件事；
- 红绳、朱砂、黄符、纸人一页全上；
- 七七四十九、九九归一等无来源数字解释；
- 儿童亡魂天然更凶、能量更强；
- 少数民族祭山仪式被拆成若干视觉符号移植给虚构汉族村落；
- 神明能够读取网页、账号和数据库状态。

中式恐怖的真实感来自一套地方信仰的内部一致性，不来自中国符号的密度。

## 5. 悬疑结构诊断

### 5.1 当前反转阶梯

现稿大致包含：

```text
阿山可能杀死三人
→ 阿山无法独自完成
→ 存在第九名未登记进入者
→ U1可能是林文
→ 三名儿童与旧灯位相容
→ 契文被改
→ U1离开与第三日坡移吻合
→ 玩家工作与旧手续重合
```

优点是每一层都有资料支持；问题是后四层密集堆在B08—B12，中间缺少足够的角色反应、误信和方法变化。

### 5.2 第一层误信不够坚固

“阿山杀了三个人”主要来自论坛传言。谨慎玩家一开始就会把它视为村民污名，而不会真正相信。

必须增加两条不依赖恶意偏见的可见事实：

- 三名死者均倒在阿山锁链作用区附近的初步示意图，后来通过精确血迹和链长纠正；
- 破门人员记录阿山身上有与现场相同的灰尘或油污，但后来证明来自日常被锁位置。

这些只能使怀疑合理，不能伪造证明。

### 5.3 B07—B09像换了另一个游戏

U1身份链完成后，主线突然转向三名儿童和仪式布局，缺少一个可见问题把两者连接起来。

推荐因果桥：

> U1生活痕迹中发现一块被磨平姓名的旧守牌；牌背编号不是人名，而与1974交手尾券和三次地坪编号同组。玩家追编号，才进入儿童与契文线。

这样玩家不是因为“剧情进入民俗章”而查儿童，而是继续追U1为何没有名字。

### 5.4 B11是答案复述，不够像推理

玩家看到“守人离，三日北坡开”，再填写“第三日、北坡”，属于抄答案。

推荐改为相对日期与地点双推导：

- 1982资料只保留残句或地方计夜法；
- 另一份守更记录给出“三宿从交牌后的首夜算”；
- 玩家用U1离开时段推算三个可能窗口；
- 地质索引按日期和监测点检索，只有一个窗口返回坡移记录；
- 玩家随后发现自然地质链同样完整。

### 5.5 B12会把恐怖解释成Excel

逐栏填写“前置条件／四件／同函／末校／三日／移交”，会让系统替玩家总结全部规则。

建议改成物质操作：

1. 对齐两半契券的纸边；
2. 拼合半枚合同印；
3. 用旧订孔确认历史关系；
4. 在1974尾券与现代处置预览之间比较接收栏；
5. 系统只报告纸张、印章和签名状态，不输出“仪式相似度”。

让恐惧发生在玩家发现两个接收栏都空着的瞬间。

## 7. v3.4 推荐玩家操作结构

保留十三个Beat编号也可以，但建议按下表重排：

| Beat | 核心页面与动作 | 方法变化 | 恐怖/悬疑作用 |
|---|---|---|---|
| B01 卷号归位 | 比对卷皮、底片袋、扫描批次；发现袋口半枚合缝印 | 字段比对 | 普通错卷中出现一个暂不解释的物质异常 |
| B02 传言分层 | 把论坛原话、转载删节和尸检事实分栏 | 来源分类 | 建立第一误信，同时教玩家不把传言当事实 |
| B03 阿山作用区 | 计算链长、血迹形成区和可触范围 | 几何推理 | 推翻“唯一活人＝凶手” |
| B04 门闩与音序 | 组装门闩、排列声音与脚印时序 | 物理搭建＋音频排序 | 证明有人可在门外完成闭锁 |
| B05 八名过槛者 | 将首次进入、重入、门外递物分类 | 规则应用 | 得出八人，但急救残句仍多出一个 |
| B06 隐藏空间 | 叠合建筑图、通风孔、生活痕迹和足迹 | 空间叠图 | 第九人从墙内进入；恐怖由空间产生 |

| B08 三个孩子 | 三条不同形式的小型身份调查，完成后单独提交姓名 | 多渠道身份核验 | 先让玩家认识三个孩子，再展示地坪关系 |
| B09 原契生活生态 | 灯油簿、轮更牌、排水记录、饭食支领、1964抄本 | 制度重建 | 让原仪式先作为真实地方生活出现 |
| B10 恶契形成 | 对照删改、三次工程、1974合券与画押 | 版本差异＋时间线 | 人为篡改与真实受契同时浮现 |
| B11 第三夜检索 | 推算夜数、检索坡段、叠加地质链 | 相对日期推导 | 自然解释成立，但契的吻合无法消除 |
| B12 实体契券处置 | 合缝预览、合同印、接收栏、两种授权处置 | 物质复原＋责任预览 | 玩家发现自己正位于旧交手结构中 |
| B13 知情选择 | 实体合券复原／分片封装＋数字参见 | 行动型分支 | 选择改变真实物质状态与创作者层超自然后果 |

### 7.1 节奏规则

- 不得连续超过两个“表格比较”Beat；
- B04、B08、B10之后必须有世界内反应或人物材料，让玩家从技术推理回到人的代价；
- B09以前至少出现三次不解释的民俗物质痕迹，避免后半突然换题材；
- B10不得同时公布儿童、恶契、山神、守者和现代触发五项答案；
- B12完成后先让玩家离开工作台，再收到一条普通的处置待办，避免同页立刻弹出终局按钮。

### 7.2 建议时长

- 主线中位时长：90—120分钟；
- 含三条以上假路线与普通浏览：120—155分钟；
- 单个必经Beat首次无提示探索不宜超过12分钟；
- B08三名儿童总时长控制在12—15分钟；
- 任意两个连续Beat不得使用完全相同的核心操作。

## 8. 可玩性诊断与改法

### 8.1 当前问题

- B07同时承担身份、门闩、守位三种判断，认知过载；
- B08要求连续完成三条身份链，容易成为重复劳动；
- B09、B10连续叠图；
- B11只填已有答案；
- B12再填规则表，后段会产生强烈行政疲劳；
- 三条可选假路线与主线的鬼神方法没有关系，玩家可能把它们视为旁支成就；
- 终局确认文本过长，恐惧会被法律免责声明冲掉。

### 8.2 三名儿童的操作去重

三条身份链必须使用不同方法：

| 人物 | 建议玩法 | 学到的字段 |
|---|---|---|
| 方小禾 | 成绩单班级、教师评语与迁出名册核对 | 同名不能只凭姓名，需要学校与日期 |
| 邓梅 | 儿童画背签、照片人物顺序与亲缘记录核对 | 私人物件需要来源链 |
| 许有生 | 疫苗批号、年龄区间与亲缘摘要核对 | 医疗记录只能证明有限身份字段 |

三个结果可以并行完成，完成一人后显示其生活材料，不把三人压成“三个进度格”。

### 8.3 终局表单减负

玩家首屏只确认：

1. 实物是否合缝复原；
2. 是否建立组合著录关系；
3. 当前经手人与下一接收人分别是谁；
4. 是否保留人物身份、死亡责任和超自然因果为空；
5. 最终提交。

详细未决命题放入可展开附件，不再首屏列二十余项。

### 8.4 提示系统

每个关键Beat维持四级提示：注意位置→方法类型→具体字段→直接答案。提示不得说：

- “去看1974版本”；
- “这就是恶契”；
- “你正在成为守者”；
- “正确路线”；
- “仪式条件已完成4/5”。

失败反馈只能描述缺少的观察，例如：

> 两张券的编号已经对应，但还没有证明纸边和合缝印属于同一次装订。

## 9. 错误路径与普通噪声重构

### 9.1 保留并深化现有三条错误路径

| 假路线 | 入口真片段 | 深入步骤 | 正常闭合规则 | 方法奖励 |
|---|---|---|---|---|
| 赵成海红绳 | 他确实领过防汛红绳 | 领物簿→材质页→核销记录 | 时间、纤维直径和染料不符 | 学会物证不能只看颜色 |
| 2004伪日记 | PDF确为2004创建 | 账号史→扫描批次→1998封存清单 | 数字化时间不等于纸本形成时间 | 学会文件史与内容史分开 |
| 废矿暗道 | 后山确有旧矿 | 矿图→高程配准→封堵记录 | 距离、高差和完整岩层排除连通 | 学会地图必须配坐标与高程 |

### 9.2 新增两条民俗相关假路线

#### 假路线A：“三童”只是三只灯座的俗称

- 入口：另一地区资料把三角灯架称作“童子灯”；
- 玩家行动：查术语索引→打开器物照片→比对槐北方位图；
- 中间加强：槐北旧图确实没有儿童姓名；
- 闭合：1974灯籍出现三个真实姓名的残笔、三次地坪时间与三名儿童失踪分别对应；
- 学到：民俗词不能脱离当地记录直接套用。

#### 假路线B：“守山人”只是正常林场岗位

- 入口：县志中确有巡山、护林、守坡岗位；
- 玩家行动：查工资簿→值勤区→工作内容；
- 中间加强：其中一名职工也姓林；
- 闭合：正常岗位有工资、轮班、离岗记录，U1没有这些字段，只在契券尾栏和隐藏室生活痕迹中出现；
- 学到：同一称谓可能属于完全不同的制度。

### 9.3 普通噪声比例

新增加的民俗和档案网页至少维持：

- 60—75%普通内容；
- 15—25%主题相邻内容；
- 5—15%红鲱鱼与可深入假路。

普通内容应包括：

- 灯油支领、守夜饭食、排水沟清理；
- 祠堂漏雨、门轴维修、灯罩更换；
- 正常山场纠纷、借界、还愿、雨季禁山；
- 不同年份的值夜人员、请假、换班和遗失守牌；
- 无关的地方志、婚丧资料、农事节令和档案修复记录；
- 普通404、缺页、重复扫描、权限提示和索引更正。

每个网站必须先像为普通用户服务的真实网站，再承担剧情线索。

## 10. 中式恐怖氛围设计

### 10.1 不以“元素多”为目标

全作建议只反复使用四组核心意象：

1. **门槛**：谁被算作进入者，谁被留在界外；
2. **灯**：本来用于引路，后来变成固定人的位置；
3. **契券合缝**：人间文字如何被非人一方接受；
4. **空白接收栏**：上一人不能退，下一人迟迟不来。

这些意象必须在普通用途、历史滥用和现代重现三个层次反复出现。

### 10.2 恐怖递进

| 阶段 | 玩家感受 | 页面表现 |
|---|---|---|
| 早段 | 奇怪但可解释 | 半枚合缝印、磨名守牌、重复的空接收栏 |
| 中段 | 有人被从记录里抹掉 | 隐藏室、无名生活痕迹、三个独立儿童身份 |
| 转折 | 民俗被人为改造成伤害工具 | 改字、地坪、1974受契记录 |
| 后段 | 鬼神秩序可能真的照字执行 | 案前异文、第三夜吻合、自然与契文同时成立 |
| 终局 | 玩家进入相同的物质交手结构 | 两半契券、经手签名、下一接收栏空白 |

### 10.3 需要一个“不可被社会解释完全吃掉”的余量

当前同一条自然坡移不足以承担这一任务。下一版至少需要一项与本土鬼神规则一致、但不构成廉价实锤的现象，例如：

- 三个旧灯位附近的浅层传感器在第三夜按旧引灯顺序出现短促变化；
- 分存分支的三条小幅位移分别朝向三名儿童原村路方向，而总体地质机制仍成立；
- 实体合券后，保管记录显示三个灯位的土样含水变化同步，但无法排除修复和测量误差。

必须在创作者真相层确认这不是纯巧合；玩家层仍可标为未决。

禁止使用：网页自动变字、凭空出现玩家姓名、摄像头鬼影、倒计时归零、突然尖叫。

### 10.4 声音与视觉

允许：

- 雨打旧瓦、木梆报更、灯芯轻爆、纸页摩擦、库房卷帘门；
- 合缝印、折痕、污渍、灯烟、旧铅笔号；
- 工作台普通白灰蓝界面与旧页偏黄纸色的代际差异；
- 关键推理后短暂停止环境声，而不是播放恐怖音乐。

禁止：

- 所有重要字都用血红；
- 红绳、黄符、纸人、朱砂同时出现；
- 正确证据自动高亮；
- 一进入民俗页网站就变黑；
- 让儿童遗物承担惊吓音效或视觉机关。

## 11. 推荐的单一民俗世界观

### 11.1 地域口径

推荐设定为：

> 架空的南方丘陵汉族县域，长期多雨，北坡由风化页岩和泥岩构成。槐北村社以山场、梯田、沟渠和小型祠庙为生活空间。

不得直接复制某个现实少数民族祭山仪式。真实祭山传统往往与具体族群、农业周期、村寨组织和禁山规则紧密相连，不能只取白石、巫师、鼓舞等视觉符号。非遗资料可作为“地方信仰必须嵌入生产生活”的方法参考，而不是素材零件。[中国非物质文化遗产网关于祭山习俗的资料](https://www.ihchina.cn/luntan_details/8424.html)

### 11.2 鬼神秩序

```text
北坡山神／坡公：管理坡界、山路、土石和坡界内未被接领的亡魂
家祖：有姓名、有家属接领、完成安置的亡者
无祀魂：无名、秘密埋葬、无人接领而滞留坡界者
守更人：活人中的临时看界者，不是巫师
香首／水首：人间见证和实际防灾负责人，不是神职万能人
```

丧葬仪式中通过“开路”“送魂”等方式帮助亡者进入另一秩序，是中国多地生死观中可见的基本逻辑；但不同地区仪式差异很大，本作必须只写成槐北地方异文，不假装全国通行。[中国社会科学网关于丧葬仪式与亡魂归宿的讨论](https://www.cssn.cn/ztzl/ztzl_skwzg/ggfy/jyyj/shsj/202306/t20230606_5643011.shtml)

### 11.3 契券结构

宗教契券可以模拟现实契约，使人与神祇、亡者与阴界之间形成象征交易，并依靠双券、合缝、埋置等物质行为完成。[北京市文物局关于买地券、合同双券与神祇交易的考释](https://wwj.beijing.gov.cn/bjww/362760/362770/21243077/index.html)

本作可以借鉴其“契约结构和物质性”，但不得直接把买地券当成镇山契：

```text
人间存券：由村社保存
告山副券：置于山界祠址或界石附近
合同印：两券合缝才完整
守牌：证明当前经手与下一接手关系
灯籍：记录三户灯和引灯者，原本不是祭品名单
```

### 11.4 超自然能力边界

北坡山神只能：

- 在其山界内通过土、水、坡体、道路和无祀魂产生作用；
- 接受符合地方仪式的实物契券、告知和交手；
- 按契中文义和名分执行，不判断人间行为是否善良；
- 借已有自然条件显现，而非凭空制造全球灾难。

北坡山神不能：

- 修改网页；
- 读取数据库；
- 知道`QC-447`是什么；
- 远程诅咒看过资料的人；
- 让任何红绳、数字和符号自动有法力；
- 替人完成谋杀或免除人的刑事与伦理责任。

### 11.5 退契与还名

现稿只有“成契”和“应验”，没有退出机制。没有退契规则的契约会沦为作者想续就续的万能诅咒。

建议把真正解除恶契写成五个缺一不可的动作：

1. 在人券上恢复三名儿童和U1的本名，撤去“灯脚／守位”等职役；
2. 依法确认并安置三名儿童遗骸，使其重新进入家属与公共纪念秩序；
3. 取回或在原位废止告山副券，以地方既有形式明确告知退契；
4. 收回守牌，不再把它交给新的活人；
5. 人券、告券与修复记录分存，保留历史证据但不再合印续开。

这不应在本作结局中被玩家一键完成。玩家只能决定本次修复是否续开恶契，并生成一份后续退契调查建议。这样既保留故事余量，也让世界观知道“怎样才算真正结束”。

## 12. 虚构地方异文工作稿

以下只作为结构草案，不可直接伪装成真实历史民俗，仍需方言、年代语体和书写习惯校订。

### 12.1 原始借山守坡契

```text
槐北三社，共告坡公：借北坡一界，开沟立祠。
三户各供一灯，童子引灯过槛即还。
守更一人，执左券，听水看石。
满三宿，合券交牌；后手接，前手退。
香首、水首、三户户主同见。
```

需要注意：这是作者结构稿，不是“古人必然这样说”的仿古文。

### 12.2 1974恶契改写点

不要另写一篇整齐的新咒语，应通过涂改、挖补、覆写和尾券体现：

| 原文 | 恶契处理 |
|---|---|
| 童子引灯过槛即还 | “即还”被刮去，旁补“三名镇灯脚” |
| 三户轮灯 | 户名被改为三个具体人名或方位号 |
| 守更一人 | “更”被覆写为“界”或“山” |
| 后手接，前手退 | 补写“后手不至，前守不退” |

真正使恶契成立的不是改字本身，而是1974年发生了：

```text
两券合缝
＋告山副券归位
＋三名被错误写入灯籍
＋守牌交给U1
＋香首、水首或代理人完成画押／见证
```

### 12.3 1982地方旧话

不要直接刊印完整答案“守人离，三日北坡开”。可改为地方专栏中的残句：

> 北坡旧话只记得后半句：“前手空，第三夜看坡口。”问起“前手”是什么，来稿人说老人没有讲明。

另一份普通守更记录再提供计夜方法，玩家才能推导，而不是抄答案。

### 12.4 现代处置预览

```text
实体处置：合缝复原／分片封装
著录关系：组合著录／数字参见
执行人：档案保管员（固定世界内姓名）
复核经办：玩家所扮演的固定世界内角色
当前经手签名：____
下一接收签名：____
```

现代文书不得使用“守山、成契、交守”等民俗词。结构相似必须由玩家发现。

### 14.2 人类语言要求

- 论坛用户不应人人懂档案、法证和民俗；
- 老人口述允许重复、跳跃、忘记起算方法，不写完美答案句；
- 档案页只报告字段和限制，不替玩家解释“仪式成立”；
- 民俗站区分采风者原注、后期整理者注和本站编辑说明；
- 地质站不使用“应验、异象、守人离”等剧情词；
- 工作台不显示“仪式条件、当前进度、正确路线、危险选择”；
- 不同年代页面不能共享相同的作者腔和整齐三段式。

### 14.3 历史年代提醒

1966—1976年间正规的民间文学与民俗搜集工作受到严重影响。若保留1968材料，应设为更早采风笔记的私人抢救抄本、旧物清理夹带页，或直接改为1964原稿，不能写成普通公开采风项目。[中国民俗学会相关历史回顾](https://www.chinesefolklore.org.cn/web/index.php?NewsID=2811)

## 15. 结局设计原则

### 15.1 两个结局都必须完成调查

无论选择哪一项，都必须完成：

- 第九位到访者身份建议；
- 三名儿童身份恢复；
- 人为篡改与暴力责任的最窄结论；
- 原契、恶契与现代处置的来源说明；
- 明确的“本次复核已办结”。

不得让“不续契”变成拒绝调查或销毁证据。

### 15.2 两个结局都不能是纯象征

两项选择必须改变实体处置：

```text
A：两半契券合缝复原、共同封装、建立组合著录
B：两半契券分片封装、保留间隔、建立数字参见
```

现代职业后果、创作者层超自然后果和玩家可见记录都要分别写清。

### 15.3 结尾首屏

首屏只显示：

```text
本次复核：已办结
实体处置：已执行
人物身份建议：4项已分别提交
当前经手：已签／已结束
下一接收：空白／不适用
北坡监测：查看后续记录
```

详细命题、证据限制和司法待审核项放入可展开附件。

最后一句应来自普通项目或保管日志，不用作者旁白宣布恐怖。

## 17. 真人盲测指标

以下内容在真人测试前一律标记 `NOT_PROVEN`：

### 17.1 逻辑理解

- 至少80%的玩家能说出“第九”为什么成立，且不会把九解释成神秘数字；
- 至少70%的玩家能区分U1身份、守位、门闩行为和致死责任；
- 至少70%的玩家能说出原契与恶契至少两处本质差异；
- 少于20%的玩家把恢复儿童姓名理解为触发诅咒。

### 17.2 悬疑与可玩性

- 至少70%的玩家在每次反转前持有可陈述的阶段性信念；
- 至少60%的玩家主动进入一条2步以上假路线；
- 单个必经Beat无提示卡住率低于20%；
- B08、B10、B12不得成为连续三段最高疲劳点；
- 使用直接答案提示的玩家仍能继续完成结局。
- 主线中位时长落在90—120分钟，完整探索落在120—155分钟；
- 任一必经Beat无提示卡住超过12分钟的玩家少于15%。

### 17.3 中式恐怖

- 至少70%的玩家能说出：非人一方是谁、契约约束什么、违反会发生什么；
- 至少60%的玩家第一次明显不安发生在最终选择之前；
- 至少60%的玩家认为恐怖来自鬼神秩序与仪式，而不只是村中坏人；
- 若超过50%的玩家认为“其实全是人为犯罪和自然巧合”，则中式恐怖本体判定失败；
- 若超过35%的玩家认为“山神要求杀童，所以村民也没办法”，则伦理与因果判定失败；
- 玩家应能同时说出自然解释与超自然解释，且知道两者并不互相取消。

### 17.4 结局

- 至少70%的玩家能说出两种实体处置的现实收益和代价；
- 少于65%的玩家认为某一选择是作者指定的唯一正确答案；
- 两分支玩家均明确知道游戏已经结束；
- 两分支对“超自然已被网页证明”的误判率均低于25%。

> 活人为了利益篡改了契，把三个孩子从姓名改成位置，把一个人从姓名改成守位。人必须为这些现实暴力负责；但更可怕的是，北坡山神并不判断善恶，只承认活人郑重交给它的那份文字。几十年后，玩家没有施法，也没有相信鬼神，只是在合法完成一项实体契券处置时，再次站到了那个“前手未退、后手未接”的位置上。

只有当“人作恶”和“鬼神照契执行”同时为真，《镇山契》才真正成为中式恐怖，而不是带有民俗装饰的档案悬疑。
