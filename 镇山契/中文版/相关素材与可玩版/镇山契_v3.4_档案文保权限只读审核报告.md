# 《镇山契：第九位到访者》v3.4 档案、文保与权限只读审核报告

- 审核对象：`镇山契_第九位到访者_v3.4_创作者真相与仪式合同冻结稿.md`
- 审核日期：2026-08-13
- 审核范围：实体来源链、纸质文物/档案修复、跨机构调取、人员权限、A/B 两种实体方案
- 不在本报告范围：民俗本体、超自然规则、剧情优劣及文学润色
- 最终评级：**HOLD**

---

## 一、总评

当前稿的制度设计已有明显进步：数字清单与实体原件分开，玩家不能接触或签收原件，修复、移出、接收等角色也开始分离；B 方案的分件保管和数字参见方向基本可信。

但整体仍不能通过。核心问题不是少几个表单或专业名词，而是以下四层仍被混在同一条“来源链”中：

1. 作者设定的历史经历；
2. 材料检验所得的年代、同源或使用推断；
3. 原物首次被机构控制后的现代保管链；
4. 2026年的跨机构调用、检验与修复行为。

此外，A 方案目前明显是为了实现“北坡合券—共同保管—三夜无人进入”的剧情结果，反向设计现实流程。它尚缺少成立的办案目的、法定发现起点、多机构审批、受控检验场所、逐件独立保管和最终退还闭环。

因此：

- **A方案：HOLD**；
- **B方案：条件性 PASS**；
- **整体合同：HOLD**。

---

## 二、等级说明

- **P0**：不修改就不能通过，会破坏法定程序、证据链、原物安全或方案根本可行性。
- **P1**：方案可能成立，但当前写法不足以让专业人员相信，开发前必须修正。
- **P2**：术语、文书字段和表现精度问题，不一定破坏主线，但会使专业页面出戏。

## 四、P0：阻断问题

### P0-1｜“历史经历”与“现代保管链”混写

**位置：** §4.1「来源链冻结表」

**原句：**

> “1964村社形成 → 1970—1974刮改覆写 → 1998正殿东柜收取，原位照/扣押单/封袋连续……”

> “1964与人间存券同批形成 → 1974重新置入……→2026原位发现……”

**为什么不成立：**

1964—1974发生了什么，属于作者真相或依靠纸张、墨层、文字、位置所做的历史推断；它不是现代意义上的连续保管链。真正可以称为“机构保管链连续”的部分，只能从原物被正式发现、提取、编号、封装和接收后开始。

当前表格会让玩家误以为“1974被放入券龛”“同批形成”“同一牌号使用”都已经由连续机构记录证明。

**最小修改：**

将现表拆成四列：

| 字段 | 内容 |
|---|---|
| `creator_history` | 作者层确定的历史经历，不直接向玩家宣称已有文书证明 |
| `first_verifiable_node` | 第一个可由同期记录或现代发现证明的节点 |
| `institutional_custody_events` | 正式提取、编号、封装、移交、启封、复封、出入库 |
| `material_association_findings` | 纸张、墨层、断边、半印、磨损等检验结论 |

人间存券和守牌的现代保管链从1998年正式收取开始；告山副券从2026年原位发现开始；1974以前只能写成“作者层历史”或“材料与该年代相容”。

### P0-2｜2026发现物没有合法的第一步

**位置：** §4.1、§5

**原句：**

> “2026排水加固时原位发现，连续录像/封泥/取出封装/入库签收完整。”

**为什么不成立：**

建设施工中发现文物或疑似文物，项目人员不能自行完成“取出—封装—入库”。现实流程首先是保护现场和报告主管部门，由文物行政部门提出处理意见。若该物又可能关联1998年命案，还应另建公安机关的接收、勘验和案件关联路径。

连续录像只能证明操作被拍摄，不能代替停工、报告、现场处置意见、授权提取、提取清单和首次接收机构。

**最小修改：**

冻结如下流程：

```text
发现疑似文物
→ 停止该作业面并保护现场
→ 报属地文物行政部门
→ 因旧案关联同步报公安机关
→ 两部门到场并形成处理意见/勘验编号
→ 原位位置、方向、券龛状态、环境和病害记录
→ 由获授权人员支撑提取
→ 分别取得文物发现编号与案件关联编号
→ 明确首个实体接收和保管机构
```

两个编号可以交叉引用，但不能由项目组自行取走。

现行《文物保护法》第46条要求发现文物或疑似文物时保护现场并立即报告，由文物行政部门到场并提出处理意见：[《中华人民共和国文物保护法》](https://zwgk.mct.gov.cn/zfxxgkml/zcfg/fl/202503/t20250311_958788.html)。

### P0-3｜1998案件状态和当前法定保管主体没有冻结

**位置：** §4.1、§7.1

**原句：**

> “2026仍在警方受限保管单元。”

> “人间存券和交手尾券在警方案卷；守牌在另一受限物证单元。”

**为什么不成立：**

“警方”“受限单元”“警方案卷”都不是可以签批出库的具体机构。1998案件若为未破、撤案、移送起诉、已经判决或重新启动，2026年的保管权和调用权限会完全不同。

公安机关涉案财物原则上应由指定的涉案财物管理部门和专门场所集中保管，而不是由模糊的“项目单元”长期控制：[《公安机关办理刑事案件程序规定》](https://www.moj.gov.cn/pub/sfbgw/flfggz/flfggzbmgz/202101/t20210104_146527.html)。

**最小修改：**

增加一张法律状态表，至少冻结：

| 字段 | 建议冻结内容 |
|---|---|
| `CASE-98-STATUS` | 未破命案；2026因新物证正式启动复查，或另选一种明确状态 |
| 2026牵头机关 | 某县公安局刑侦部门 |
| 涉案财物保管主体 | 该局涉案财物管理部门/中心 |
| 原案卷保管主体 | 明确具体机构 |
| 每件原物 | 物证号、袋号、现库位、当前保管单位 |
| 技术支持单位 | 档案馆、文保/鉴定机构，仅提供技术服务，不取得案件处置权 |

### P0-4｜单一项目负责人没有跨机构批准权

**位置：** §7.2

**原句：**

> “项目负责人根据玩家建议签处置批准。”

> “玩家选择处置建议 → 项目负责人签批 → 固定修复员/保管员执行现实动作。”

**为什么不成立：**

项目负责人无权用一张内部批准，同时替代：

- 公安办案部门的送检决定；
- 涉案财物管理部门的出库手续；
- 档案保管机构的原件利用批准；
- 文物行政部门或收藏单位的保护修复批准；
- 受托鉴定机构的正式受理；
- 临时工作场所和运输安全批准。

玩家的意见只能是技术建议，不能成为法定执行授权。

**最小修改：**

将 `PM-26-01` 改为协调和汇总角色。增设审批矩阵：

| 事项 | 批准/办理主体 |
|---|---|
| 旧案物证送检 | 公安办案部门负责人 |
| 物证出入库 | 涉案财物管理部门 |
| 档案原件或认证复制件利用 | 档案保管机构 |
| 新发现物保护修复 | 文物行政部门及现保管/收藏单位 |
| 原件检验受理 | 具备相应范围的鉴定或保护修复机构 |
| 临时场所、运输、延期 | 对应主管单位分别批准 |

只有所有批准号齐全，PM才能下达执行协调单。

### P0-5｜A方案把不同权属原物合成一个“共同保护组”

**位置：** §7.3

**原句：**

> “守牌和尾券进入同一共同保护组。”

> “KPR-26-02实际接收共同保护组，并承担后续持续保管。”

**为什么不成立：**

这些物件可能分别属于警方物证、档案原件和新发现国家所有文物。把它们合成一个组，不能抹掉各件原有编号、封签、法律保管人和返还路径。

若守牌是木、漆或复合材料，还可能不适合与出土纸件共用同一微环境。单个现场保管员也不能取得所有机构的法定保管权。

**最小修改：**

将“共同保护组”限定为：

- 同一联合检查批次；或
- 同一外层安全工作装具中的独立分格单元。

每件必须保留独立：

- 原物编号；
- 内包装与封签；
- 状态单；
- 保管机构责任；
- 逐件签收和归还记录。

不得只签收“共同保护组1组”。

### P0-6｜A方案的文保与办案目的不成立

**位置：** §7.3

**原句：**

> “因告山副券出土后暂不宜长途运输，项目在北坡界内的临时保护工作间进行联合复核。”

> “修复员用可逆、无黏合保护装具对齐两券断边和原有半印。”

> “连续三个完整夜晚无人进入稳定间。”

**为什么不成立：**

一件脆弱到不适合长途运输的新出土纸券，不应未经状态调查便立即展平和断边试合；旧案物证也不应仅为“共同保管三夜”被送入施工和坡体风险区。

原件同源检验并不天然要求三件共同封装或共同留置三夜。现实上会优先采用校准影像、无损检测、独立支撑下的短时同场比较。现写法明显是先需要“三夜”，再倒推业务理由。

可移动文物修复应先经过价值评估、现状调查、病害评测和方案编制，再进入实施、效果评估与档案建立：[国家文物局《可移动文物修复管理办法》](https://www.ncha.gov.cn/art/2020/9/15/art_2407_164.html)。

**最小修改：**

A方案必须改成正式的“原件同场检验委托”：

1. 先说明认证影像和分地无损检测不能解决的具体问题；
2. 新券完成应急稳定和状态调查；
3. 经批准的方案确认可进行低接触或非接触比较；
4. 临时工作间通过文保、安防和地质安全评估；
5. 旧案物证有送检事由、调用期限和延期手续；
6. 所有物件保持独立包装和责任；
7. 检验后分别归还。

如果不能建立这套业务必要性，A方案就不应被描述为“预先批准的合法方案”。

### P0-7｜A方案结束后没有现实保管闭环

**位置：** §7.3结尾

**原句：**

> “第三夜记录形成后……进入 `REOPENED_SPENT`。”

**为什么不成立：**

作者层状态结束了，但现实原物仍停留在跨机构临时场所。合同没有写第四日启封、状态检查、重新封装、退回和原机构重新入库。

“下一实际接牌人为空”可以是民俗状态，但正式保管责任不能空缺。

**最小修改：**

补一条不改变剧情的第四日上午流程：

```text
送检人员＋鉴定材料管理员＋原保管单位人员共同到场
→ 核验门禁与环境记录
→ 双人启封
→ 原物前后状态对照
→ 各件恢复独立包装和封签
→ 分别退回原保管机构
→ 完成退还、运输、接收入库记录
```

## 五、P1：重要可信度问题

### P1-1｜“封袋连续”应改成“保管记录连续”

**位置：** §4.1

**原句：**

> “封袋连续”“出入库连续”。

**问题：**

纸质物证保存28年，可能因检查、重新包装或材料老化换袋换封。真实性来自每次操作均有记录，而不是同一只袋子从未动过。

**最小修改：**

增加逐事件字段：

`event_id、case_id、item_id、行为、法律文书号、机构、操作人、复核人、原袋号、新袋号、原封签、新封签、状态变化、时间、去向、签名`。

---

### P1-2｜2004数字影像来源不足

**位置：** §4.1

**原句：**

> “2004只扫描物证卡。”

> “2004仅隔袋扫描。”

**问题：**

物证卡和隔袋扫描不足以支持断边、墨层、半印、缺口和穿绳磨损等精细核验。后续玩家拥有的高清资料缺少形成事件。

**最小修改：**

二选一：

1. 2004只数字化物证卡及1998原位照片，2026经批准启封拍摄高清原物；
2. 2004已依法调用，由保管人核封、启封、拍摄、复封，并保留完整记录。

每张数字图必须显示生成事件、原物号和原件核对人。

---

### P1-3｜轮灯簿是原件还是复制件没有确定

**位置：** §4.1

**原句：**

> “1989旧账移交登记 → 1998调入案件附卷 → 2004扫描 → 2026核原卷。”

**问题：**

“调入附卷”可能是原件入卷，也可能是复制件附卷；而“2026核原卷”又暗示原卷仍由档案机构保管。

**最小修改：**

建议冻结为：原卷自1989年起留在县档案馆或乡镇档案室；1998年由该机构出具认证复制件附入警方案卷；2026年经批准在原保管地核验原卷。

档案利用在能够满足目的时，本来也应逐步以认证复制件代替原件：[《中华人民共和国档案法实施条例》第32条](https://www.saac.gov.cn/daj/xzfg/202401/2ebf9e8cc94a4f6cbff5a8210f25dc88.shtml)。

### P1-4｜`QC-447`的跨机构数字授权缺字段

**位置：** §4.2、§7.2

**问题：**

玩家能看到未破命案、未成年人、遗骸、家庭和档案信息，但合同没有说明谁授权、能看哪些字段、是否脱敏、可访问多久。

**最小修改：**

每条数字副本增加：

`grant_id、项目号、提供机构、批准人、利用目的、可见字段、脱敏版本、有效期、只读限制、下载限制、访问日志`。

---

### P1-5｜修复员权限过大，且修复动作早于法证记录

**位置：** §7.2、§7.3

**原句：**

> “修复员……开隔离套、材料检测、可逆展平和断边试合。”

**问题：**

修复员不能自行打开公安物证封袋；“材料检测”可能涉及取样；展平又可能改变折痕、压痕、纤维和墨层等证据状态。

**最小修改：**

固定顺序：

```text
物证管理员核验封签并启封
→ 完整影像、尺寸、折痕、压痕、墨层和纤维状态记录
→ 文书物证鉴定人确定检测方案
→ 修复员按批准方案实施保护性稳定或受控展平
→ 前后状态复核
→ 分别复封并签回
```

微量取样必须另列批准单、取样位置、消耗量和余样记录。

---

### P1-6｜纸券在雨坡保存52年的状态缺乏支撑

**位置：** §4.1、§7.3

**问题：**

若没有内层容器、排水条件和病害描述，纸质物在雨坡券龛中保存52年，出土后仍能当日清晰比对，不可信。

**最小修改：**

补充：

- 券龛高于持续渗水线；
- 有独立内函或包裹层；
- 发现时记录含水率、霉活性、虫害、脆化、粘连和墨迹稳定性；
- 先进行应急支撑和稳定；
- 联合检验发生在状态评估通过后的另一个日期，而不是发现当天。

---

### P1-7｜北坡临时工作间的安全条件不足

**位置：** §7.3

**问题：**

一方面该地区正在排水加固并可能发生坡体位移，另一方面又让所有关键原物在那里跨夜保存。

**最小修改：**

明确工作间位于经岩土安全评估通过的稳定平台，不在预警坡块内，并具备：

- 防水、防火、防盗；
- 门禁和视频；
- 温湿度、漏水和入侵监测；
- 备用电源；
- 双人应急进入；
- 应急转移路线和目标库房。

达不到则取消A方案。

---

### P1-8｜“连续三夜无人进入”不是修复要求

**位置：** §7.3

**问题：**

稳定期应由物件状态和环境曲线决定，不能预设为三夜。发生漏水、温湿度异常或霉变风险时，必须允许专业人员应急进入。

**最小修改：**

改为：

> “稳定观察期由批准方案和环境曲线决定；夜间无人常驻，但24小时远程监测，异常时由双人授权应急进入。”

剧情日志可以事后显示恰好三夜无人开启封存柜，但不能在专业方案中规定无论发生什么都不得进入。

---

### P1-9｜A方案的“最高强度同源证据”表述越界

**位置：** §7.3、§7.5

**原句：**

> “A为未来正式退契提供了最高强度的实体同源证据。”

**问题：**

共同保管和留置三夜不会增强证据。证据强度来自断边、印迹、材料、墨层等规范比较及鉴定意见。修复日志只能证明操作发生，不能替代鉴定结论。

原物不便移动或保存时，可以使用经原物核验的照片、录像或复制品，这也意味着A必须说明为什么B不足：[最高人民法院刑诉法解释第83—84条](https://www.court.gov.cn/fabu/xiangqing/286491.html)。

**最小修改：**

改为：

> “A为具备相应执业范围的文书物证鉴定提供一次受控原物同场比较条件。”

检验后立即分件归还。B则形成“影像和无损检测层面的限定结论”；若仍有具体残余问题，再另行申请原件同场检验。

---

### P1-10｜B方案没有最终接收单位

**位置：** §7.4

**原句：**

> “告山副券在北坡现场单独稳定并封装。”

**问题：**

封装不是保管终点；若纸件仍潮湿，直接密封还可能促发霉变。

**最小修改：**

写明包装方式由状态评估决定，并补充：接收机构、接收人、运输条件、封签号、库位和入库记录。若作为1998案件的新关联物证，应另行确定公安与文物部门之间的保管或委托关系。

---

### P1-11｜“材料检测”缺少统一协议

**位置：** §7.4

**问题：**

未说明检测是否取样、由谁实施、设备如何校准、不同机构产生的数据如何比较。

**最小修改：**

- 无损检测优先；
- 使用统一标尺、色卡和设备校准流程；
- 报告列原物号、仪器、参数、操作人、时间；
- 微量取样另行审批；
- 跨机构只交换经原件核对的认证衍生数据。

## 七、A/B方案单独裁决

### A：北坡现场实体联合复核

**裁决：HOLD。**

原件同场比较并非绝对不可能，但当前版本缺少：

1. 明确的1998案件状态；
2. 正式送检或检验委托；
3. 多机构审批矩阵；
4. 新券的状态调查与应急稳定；
5. 临时场所的文保、安防和地质安全条件；
6. 每件原物的独立内包装和法定责任；
7. 跨夜调用理由及延期手续；
8. 第四日退还和重新入库闭环。

专业上可以保留的最小版本是：新券稳定后，由多机构批准进行一次性、受控、短时、分件独立的原件同场比较；完成后立即分别归还。不能把“共同保管三夜”写成证据收益。

### B：分件独立封装＋数字参见

**裁决：条件性 PASS。**

方向可信，但还须补齐：

- 告山副券的法律身份；
- 首次和最终保管单位；
- 认证影像形成事件；
- 无损检测方案与校准；
- 取样审批边界；
- 最终入库和责任人。

B不应被故意写成“无法完成同源核验”。它可以形成影像和无损检测层面的限定结论；只有存在明确残余问题时，才申请A式原件同场比较。
