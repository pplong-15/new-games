## 0. 本轮定案

### 0.1 类型核心

本作不是“披着民俗外衣的档案刑侦”，也不把“人情、制度或人性之恶”当作中式恐怖本身。

本作的核心体验固定为：

> 玩家从一项正常旧案复核开始，逐步确认一套槐北地方山界契约曾被活人篡改，并留下了完整的受契物质痕迹；作者层中，这次受纳确实发生。在终局，玩家知情选择一种合规的实体处置方案，世界内人员据此执行。玩家随后发现，现代人并没有施法，却可能重新完成了旧契所承认的“合券、接牌、无人守夜”关系。

恐怖必须由以下五项共同产生：

1. **本土秩序**：山界、告山、三户轮灯、雨夜守坡、守牌交手、亡者接领；
2. **禁忌错位**：活人把三个家庭的公共责任改成三个儿童的位置，把轮值守更改成一个人终身守界；
3. **有效规则**：实物、山界、见证、实际安置和交牌会产生后果，阅读网页不会；
4. **当下卷入**：玩家的处置决定会导致固定世界内人员执行不同的实体方案；
5. **不完全解释**：作者知道超自然真实存在，玩家始终只能确认物证、时间和自然现象。

### 0.2 最终恐惧对象

不是鬼脸，也不是“山神索要儿童”，而是：

> 活人以真实安置、真实见证和真实交牌，把一份错误关系郑重交给了北坡；北坡不知内情，也不替死者申冤，只维持人自己公开成立的关系。

### 0.3 本稿明确废止的旧设

- 废止“网页、数据库、OCR、账号、电子签名能被山神读取”；
- 废止“扫描件拼在一起就自动成契”；

- 废止 `compatible_only` 作为命题状态；

### 2.1 唯一非人方

作者合同固定称谓：`北坡主`。世界内俗称“坡公”暂作工作名，须经地方语言审查后才可写入公开正文。

- 依附于槐北固定山界；
- 不是恶鬼，也不是主持正义的判官；

### 2.2 能力边界

北坡主只能：

1. 使尚未被人间接领的死者滞留或离开北坡界；
2. 维持已经成立的灯位、守位和交手关系；
3. 在降雨、渗水、坡脚冲刷、页岩软化等自然条件已经具备时，影响坡体变化的具体时点或起始位置；
4. 感知北坡界内对旧契物进行的告知、实际接牌、退牌和撤契行为。

北坡主不能：

- 读取网页、数据库、OCR、账号、IP、电子签名或真实玩家信息；
- 修改网页、扫描件或电子记录；
- 在北坡界外任意伤人；
- 控制人的思想或强迫人犯罪；
- 指定儿童、残障者或其他弱者为祭品；
- 凭空制造没有物理条件的灾害；
- 替人杀人或减轻人的现实责任；
- 因恢复死者姓名而惩罚任何人。

反事实锁定：

> 没有超自然作用，1998 年的坡体仍可能因降雨和岩层条件发生变化。北坡主影响的是变化落在第三夜、并从旧坡界某处先行发生，而不是创造了不存在的地质原因。

### 2.3 死者与姓名

槐北地方异文只区分：

```text
已受领亡者：
身份得到公开承认，遗骸或死亡事实由家属、村社或公共机构正式接领并安置。

滞界亡者：
在北坡界内秘密死亡或埋置，姓名被抹去、无人承认、无人接领的死者。
```

姓名规则：

1. 姓名本身不是咒语；
2. 姓名只有与具体死者、公开承认和接领行为相连，才改变生死名位；

4. 仅修改索引、找到姓名或展示生活材料，不能释放亡者，也不能触发旧契；
5. 历史原件不得涂改；还名必须通过新的身份确认、接领和退契文书完成。

锁定表述：

> 活人真正夺走的不是三个孩子的字，而是他们被人认领、被人安置、从北坡离开的资格。

## 3. 原契与恶契

### 3.1 1964 原契

1964 材料改为私人保存的村社契券与轮灯簿，不再写成 1968 年的常规公开采风项目。

原契不得出现儿童、童子、祭品或固定个人灯位。

```text
立约人方：槐北三个轮值户
非人一方：北坡主
所涉范围：北坡旧界、坡沟、山路和界内暂时无人接领的亡者
人方所得：在山界内开沟、行路、取水和接受坡地庇护
人方义务：维护排水；雨夜听水、看石、巡沟；为暂时无人接领的亡者留灯引界
```

原契操作结构：

1. 三户各供一灯，灯代表三个家庭的共同责任；
2. 每轮由其中一户派一名成年守更人；
3. 守更人保管唯一守牌；
4. 守更人退出后，下一户须在三宿交手窗内实际接牌；
5. 若三宿内无人接牌，责任回到三个立约户共同处理；
6. 原契存在明确撤契办法，不要求永久守位，不要求死亡或牺牲。

公开古语不得在本稿直接定稿。语义工作句为：

> 三户各灯，一人守更；三宿交牌，后手接，前手退。

### 3.2 1974 恶契

1974 恶契不是北坡主索要祭品，而是活人利用原契完成的一次欺骗性受契。

固定篡改：

| 原契关系 | 恶契行为 |
|---|---|
| 三户各灯 | 三个具体的人被以匿名位置安置到三个旧灯位 |
| 轮户守更 | U1 被固定为唯一守位 |
| 后手接，前手退 | 后手不至，前守不退 |
| 三户共同撤契 | 撤契条款被遮去，并在告山时不再宣告 |

创作者真相：

1. 三名儿童先遭受人类暴力并被秘密安置；北坡主没有要求、诱导或完成杀害；
2. 施害者把三处遗骸安置在原来三个户灯对应的位置；
3. 三人的姓名从公开记录中被抹去，告山时只以三个位置成立关系；
4. U1 在 1974 同一次受契中实际接过守牌，被固定为守位；
5. 两类行为在北坡界内由人类见证者公开实施，恶契因此被北坡主受纳；
6. 北坡主受纳的是活人公开成立的错误关系，不是对杀童行为的许可；
7. 杀害、埋藏、拘禁、抹名、伪造和掩盖均由活人承担全部责任。

### 3.3 儿童伦理硬条款

- 原契不需要儿童；
- 儿童不是天然通灵者、厉鬼、能量源或“纯洁祭品”；
- 玩家不得把姓名、照片或生活材料拖入仪式位置；
- 空间推理只使用匿名发掘单元 `HR-01/02/03`；身份关联在另一工具独立完成；
- 三人必须各自保留姓名和至少一项不可互换的生活材料；
- 可以确认“存在人工、重复的空间安置”，不能由此确认死亡原因、行为人和仪式动机；
- 儿童的确切死亡原因、行为人和掩盖经过必须另立作者私有法证表。该表完成前，`FULL_BUILD` 保持 `HOLD`。

## 6. 守牌、状态与唯一第三夜

### 6.1 守牌规则

全作只保留一个持续交接物：守牌。

- 守牌不是武器，也不承载儿童魂魄；
- 普通观看、拍照、扫描、编号、短时搬运和检测不构成接守；
- 现代账号、目录字段和电子签名不能代替接牌；
- 只有在北坡界内，一个活人实际接受守牌并承担持续保管，才可能成为新前手；
- 实际前手离开北坡、把守牌留在界内，且没有另一活人实际接牌，才形成空守；
- 空守窗口一旦成立，后续由取证人员封袋、搬离或入库不会自动取消；只有第三夜前在北坡界内完成有效后手接牌，或完成正式退契，才能关闭本次窗口；
- 机构名义上的“库房仍负责”不等于北坡界内有活人守牌。

### 6.2 历史主状态

| 状态 | 定义 |
|---|---|
| `ORIGINAL_CLOSED` | 原契正常轮值或正常撤契，不存在错误名位 |
| `EVIL_OCCUPIED` | 1974恶契已受纳，三处错误灯位成立，U1实际持牌 |
| `EVIL_VACANT_WINDOW` | U1离开，守牌无人实际接收，第三夜窗口启动 |
| `UNSETTLED` | 1998第三夜后果已经显现；窗口不自动重复，但错误名位仍未解除 |
| `REOPENED_CUSTODY` | 2026 A分支中，旧契物在北坡界内重组，固定保管员实际接牌并保管 |
| `REOPENED_VACANT_WINDOW` | A分支保管员离开北坡现场，守牌留在界内且无人实际接收，新第三夜窗口启动 |
| `REOPENED_SPENT` | 2026 A分支的新第三夜后果已经显现；本次窗口关闭，重新加固的错误名位仍未解除 |
| `RETIRED` | 还名、接领、退牌和告退全部完成，恶契永久终止 |

状态互斥。材料分开不等于自动退契，空白字段不等于空守，1998 第三夜后果也不会每三夜循环。

### 6.3 四个实现轴

实现时必须同时保存四轴，禁止只用一个布尔值：

| 轴 | 典型值 | 不得推出 |
|---|---|---|
| `material_state` | `ORIGINAL_DUAL / SEPARATE_HISTORIC_ACCEPTED / SEPARATE_VERIFIED / REJOINED_ON_SITE / SEPARATE_PRESERVED / RETIREMENT_SET` | 纸张关系不能推出守位或魂魄 |
| `custody_state` | `NORMAL_ROTATION / U1_HOLDS / VACANT_SPENT / KPR26_HOLDS / VACANT_COUNTING / RETIRED` | 档案责任不能自动翻译为民俗守位 |
| `spirit_state` | `UNBOUND / BOUND_UNCLAIMED / IDENTIFIED_BUT_BOUND / REINFORCED / RETIREMENT_PENDING / RELEASED` | 恢复姓名不能自动放魂 |
| `slope_window` | `NO_ACTIVE_WINDOW / NIGHT_1 / NIGHT_2 / NIGHT_3 / MANIFESTED_SPENT` | 自然位移不能自动证实山神 |

四轴是独立状态，不建立一张强制 1:1 映射。主状态只描述契的历史阶段；以下只定义合法组合约束：

- `ORIGINAL_CLOSED`：四轴初始组合为 `ORIGINAL_DUAL + NORMAL_ROTATION + UNBOUND + NO_ACTIVE_WINDOW`；
- `EVIL_OCCUPIED`：必须满足 `U1_HOLDS + BOUND_UNCLAIMED + NO_ACTIVE_WINDOW`，材料可在1974受纳后重新分存；
- `EVIL_VACANT_WINDOW`：必须满足 `VACANT_COUNTING + BOUND_UNCLAIMED + NIGHT_1/2/3`；
- `UNSETTLED`：必须满足 `VACANT_SPENT + MANIFESTED_SPENT`；材料可从 `SEPARATE_HISTORIC_ACCEPTED` 进入 `SEPARATE_VERIFIED` 或 B分支的 `SEPARATE_PRESERVED`；人物还名前为 `BOUND_UNCLAIMED`，三条身份链完成后为 `IDENTIFIED_BUT_BOUND`；
- `REOPENED_CUSTODY`：必须满足 `REJOINED_ON_SITE + KPR26_HOLDS + REINFORCED + NO_ACTIVE_WINDOW`；
- `REOPENED_VACANT_WINDOW`：必须满足 `REJOINED_ON_SITE + VACANT_COUNTING + REINFORCED + NIGHT_1/2/3`；
- `REOPENED_SPENT`：必须满足 `REJOINED_ON_SITE + VACANT_SPENT + REINFORCED + MANIFESTED_SPENT`；
- `RETIRED`：唯一合法组合为 `RETIREMENT_SET + RETIRED + RELEASED + NO_ACTIVE_WINDOW`。

身份链只允许改变 `spirit_state` 的“人间是否完成还名”部分，不得改变主状态、守位或坡体窗口。B分支只把 `material_state` 改为 `SEPARATE_PRESERVED`，主状态仍为 `UNSETTLED`。

### 6.4 唯一第三夜算法

只有“一个已经实际持牌的前手离开北坡，且无人实际接牌”才能产生 `T0`。

| 项目 | 冻结定义 |
|---|---|
| `T0` | 前手身体越过1964方位图标出的旧守界门槛，守牌留在界内且无人接手的时刻 |
| 第一夜 | `T0`之后第一个完整的槐北地方18:00—次日06:00区间 |
| 第二夜 | 紧接其后的第二个完整夜晚 |
| 第三夜窗口 | 第三个完整夜晚18:00—次日06:00 |
| 后果次数 | 每次有效空守只显现一次，之后进入 `MANIFESTED_SPENT` |
| 重新计时 | 后来有人真实接牌，随后再次无后手离开 |
| 中途取证 | 封袋、拍照、搬离和入库不等于接牌，也不重置或取消已经成立的窗口 |

1998 示例：

```text
U1越过旧守界门槛：1998-07-16 23:26
第一完整夜：07-17 18:00—07-18 06:00
第二完整夜：07-18 18:00—07-19 06:00
第三夜窗口：07-19 18:00—07-20 06:00
北坡首次报送：07-19 23:41
```

允许确认的最窄结论是“首次报送落在第三夜窗口”。不得写“山体在 23:41 才开始动”，也不得把 72 小时 15 分当作仪式公式。

### 7.3 A分支：北坡现场实体联合复核

现实动作：

1. 因告山副券出土后暂不宜长途运输，项目在北坡界内的临时保护工作间进行联合复核；
2. 人间存券、尾券和守牌按批准手续短期移入；
3. 修复员用可逆、无黏合保护装具对齐两券断边和原有半印；不补字、不重盖印；
4. 守牌和尾券进入同一共同保护组；
5. `KPR-26-02` 在修复员和移出保管员在场时实际接收共同保护组，并承担后续持续保管；这不是短时搬运或检测；
6. 当日闭馆后，共同保护组进入封闭环境稳定期；保管员越过旧守界门槛离开北坡，连续三个完整夜晚无人进入稳定间，也无另一活人实际接牌。

作者真相：

- 旧契物关系被重新建立；
- `KPR-26-02` 的实际接收短暂形成现代前手；
- 保管员离开后产生一次新的第三夜窗口；
- 三处错误灯位关系被短时重新加固；
- 在既有降雨、渗水和坡体条件下，第三夜出现一次低幅局部位移；
- 无人受伤，位移未超过常规应急处置能力；
- A为未来正式退契提供了最高强度的实体同源证据。

玩家可见：

- 联合复核日志、保护装具、两券断边/半印对应；
- `KPR-26-02` 接收和当日晚间闭馆记录；
- 下一实际接牌人为空；
- 第三夜低幅位移、同期降雨与土体含水变化；
- 自然解释充分；超自然因果 `unresolved`。

第三夜记录形成后，作者层主状态从 `REOPENED_VACANT_WINDOW` 进入 `REOPENED_SPENT`；不得停在倒计时中，也不得自动开始下一轮。

## 8. 真正退契

真正退契在本作中**不会完成**。作者必须知道它确实存在，避免旧契变成无限续写的万能诅咒。

## 11. 内容、提示与结局边界

### 11.1 内容说明

首屏非剧透说明：

> 本作涉及历史失踪、非法拘禁、暴力死亡、地方仪式与遗骸身份复核，不展示写实尸体或儿童遗骸特写。

可展开完整说明：

> 详细主题包括未成年人死亡、长期限制人身自由、残障污名、可能的仪式化伤害和无法确认的死亡责任。历史论坛保留少量时代性不当用语，现代页面会标明其为历史原文。

两级说明是伦理优先的有意取舍；真人盲测需记录它是否过度泄露后段方向。

### 11.2 四级提示

每个必经操作必须有：

1. `attention`：指出该看哪类异常；
2. `method`：告诉玩家比较/排序/分类的方法；
3. `bounded cue`：限定来源或字段范围；
4. `direct answer`：明确可执行答案，二次确认后显示，不自动提交。

错误提交只描述缺失观察或方法，不得一次性回显正确顺序、正确字段和正确结论。

### 11.3 两个结局共同边界

- 四个人物身份纠错均已独立提交；
- 原始卷宗和契券均不涂改；
- 玩家不会成为“第十人”“祭品”或真实守山人；
- 不宣布山神存在或契已生效；
- 不宣布儿童已获释；
- 不洗白任何现实暴力；
- 不把自然解释当成“超自然已排除”；
- 结局明确显示现实处置、下一责任人与仍未回答的问题。
