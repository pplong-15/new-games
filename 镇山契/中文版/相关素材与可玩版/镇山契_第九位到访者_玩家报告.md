## 一、这是个什么游戏

你是槐县历史专卷数字化复核项目的卷宗质检员 **QC-447**，工单 QA-26-0813-447。你只能通过五个"站内网站"（2004 地方 BBS、档案目录、民俗资料网、旧报扫描库、地质资料库）和工作台的只读数字附件，把一桩 1998 年的旧案一层层核清。游戏的核心玩法不是"猜凶手"，而是**证据分级**：每条说法只能落到它自己的来源强度上，答错不会扣血，只会被驳回。

- **规模**：18 个复核项（B01–B18，分 4 章）、26 个面板、5 条可选支线排除链（F01–F05）、6 条项目回执（R1–R6）、双结局（方案 A / B）。
- **存档**：localStorage 事件溯源（每个动作都是一条事件，可重放校验），实测正常。
- **回执门槛**：完成关键节点后必须回工作台读"项目回执"才能继续——这是强制节奏点。

## 二、全谜底（18 节正确解 + 谜底逻辑）

### 第一章　旧索引比原卷跑得快

**B01 卷号归位** — 命案原卷 `XGA-1998-0717-03`、滑坡原卷 `DZ-1998-0719-11`，2004 共同扫描批次 `HS98-R07`；**底片袋 B 应归命案卷 HS-98-0717**（2004 目录误挂在滑坡卷下——很多"矛盾"只是迁移挂错）。

**B02 说法分层** — 四条传言的真实身份：
- "阿山系唯一行为人" = **后期工作便签/转述**（原卷无此字段）
- "三人都是惊吓后自掐" = **对象错配**（把张大福一人的颈部损伤扩成三人）
- "冰化后门杠落下" = **论坛结构猜测**（现场清单无冰块、无融水沟）
- "周守义头部钝性损伤" = **尸检原卷字段**（唯一为真的一条）

**B03 阿山作用区** — 叠四层图：比例尺+柱环基点、链节最大可达区（外缘 1.43m）、两处暴力作用区（头部 1.74–2.02m / 颈部 1.61–1.88m）、工具与无拖移层。结论："**现有材料不支持阿山到达暴力作用区或成为唯一实施者**"（注意：这是排除连接，不是法律无责结论）。

### 第二章　第九位不是从外面来

**B04 声音时序** — AV-04 录音以 22:30 / 23:00 双报时为锚（不能用底片 23:44 定锚），六声顺序：**开板 → 赤足落地 → 撞击 → 抬杠 → 关门 →（约 4 秒后）落槽**。

**B05 门闩候选** — 门外关门的可行结构：**锥形暂托销＋导向环＋无结 U 形回收绳**（托住—关门—抽销—落槽—抽回绳）。对应痕迹：8mm 暂托销、双股旧棉纤维、轴向划痕、关门后约 4 秒延迟落槽声。**冰托说被排除**（现场无融水沟、无异常吸水带）。

**B06 八人登记** — 计数口径必须选"**21:30—23:30 仍活着且首次完整跨入正殿**"。八名登记者：赵成海、刘庆余、阿山、张大福、李有业、周守义、孙桂兰、林青（"巡查员"次日 00:04 才到门外，不计）。22:10 前离开的三人：赵成海（22:09）、刘庆余（22:08）、孙桂兰（22:07）。

**B07 桥头 M1** — BF-11 帧序：水尺空景 → 防汛员前景 → 路牌与远处男子 → 男子向村外 → 空景。底片**只能证明**：23:44 有一名**不在八人离场记录中的男子**向村外走。**不能认脸、不能证明进过正殿、不能等于 U1**。

**B08 建筑差值** — 外轮廓与内测统一坐标后，北墙剩余差值 **1.18 × 6.8 米** → 只够说"**存在未编号墙后空间**"，不能说明谁住、做什么用。

**B09 生活年代** — 墙后生活层从早到晚：**1974 修补线 → 1982 以后药袋 → 1998 前封存纸本 → 1998 救援新鲜断口**。只能保存"跨多个年代的生活痕迹"，不能填成"1975—1998 每天都在"。

**B10 U1、第九人和行为边界**（四面板，全书核心）
1. **匿名归一**：P-07（墙后木板）/D-03（暂托销）/W-02（旧绷带）样本谱一致 + 左足第二趾缺趾连续足迹 + 三条独立保管链 → 三件样本属于同一匿名者 **U1**。
2. **第九人回填**：U1 于 **22:47±1** 从墙后首次完整跨入正殿 → 按 B06 口径，他就是标题里的**"第九位到访者"**（八人表里没有他）。
3. **身份合取**：与林青全同胞 + 林青**唯一**有记录兄长林文 + 林文 1975 失踪窗 + 林文 1972 年左足第二趾缺趾旧伤 → **U1 = 林文**（QA-U1-FORENSIC 通过；**BF-11 不参与认脸**）。
4. **行为边界**：接触墙后木板 ✓confirmed、接触暂托销 ✓confirmed、23:26 离场 ✓confirmed；**门外落杠 unresolved、造成成人死亡 unresolved**。

### 第三章　所谓古俗，是有人后来改过的

**B11 后出文本表象** — 1970—1974 覆写层可见字段只有：三个匿名位置号、固定一人守位、"后手不至、前守不退"。**先记录表象，不判断它是原初古俗还是已被受纳**。

**B12 三人还名**（三条互不借用的独立身份链）：
- **方小禾**：1971 最后到校 + "随亲迁出"但接收地**无迁入回执** + 左桡骨陈旧愈合畸形 + 在世同胞弟弟全同胞模型
- **邓梅**：1973 健康卡 + "病亡"但医院/村医/墓地**三处均无接收** + 上颌乳磨牙特殊治疗痕 + 在世母亲母女模型
- **许有生**：1974 疫苗卡 + "落水失踪"但河道**无无名儿童接收** + 右胫骨旧骨膜反应 + 在世妹妹全同胞模型
- 边界统一：**身份链成立；接收空缺不证明死因/行为人/仪式动机**。

**B13 姓名与位置** — 匿名单元对位：UNIT-G14（1971 地坪层）→东一位、UNIT-G16（1973 补铺层）→西二位、UNIT-H15（1974 封面层）→北三位；现代目录还名：**东一位=方小禾，西二位=邓梅，北三位=许有生**。（匿名→还名分两屏，防止身份先验污染空间判断。）

**B14 原契复原** — 1964 底本的真制度：**三户各灯、每户派成年守更人轮值、三宿内后手接牌前手退、有明确撤契办法**。1970—1974 被人改写三处：**户→位置、成年轮值→固定守位、遮去撤契条款**。最窄结论：确认**人间刮改覆写**；"人改过"既不等于"必然无效"，格式完整也不等于"必然有效"。

### 第四章　先算出第三夜，再决定要不要重现关系

**B15 守牌来源** — 守牌 E98-O-031 与尾券：牌号 GT-74-1 一致、东北旧缺口对应、穿绳磨损与拓印相合、1998→2026 保管链连续 → 只确认**同一编号组的物件对应**；**没有任何来源证明 U1 理解、同意或承担守位**。

**B16 旧界门槛** — 1964 旧界线穿过正殿南侧外门门槛；配准后交点为 **23:26 正门处越过旧界门槛**（不是 22:47 从墙后跨入正殿，也不是 23:44 桥头）。仍不能确认他当时实际持牌。

**B17 第三夜计算** — 全书最漂亮的机制题：
- 前提必须是**条件式**："**若** 23:26 离界者当时实际持牌，且界内无活人后手持续接管"
- 起算点 T0 = 1998-07-16 23:26（Asia/Shanghai），当晚不足一个完整夜班，不计
- 第一夜 07-17 18:00—07-18 06:00，第二夜 07-18 18:00—07-19 06:00，**第三夜 07-19 18:00—07-20 06:00**
- 北坡局部坡移**首次报送 07-19 23:41**，恰好落在第三夜窗口内 → **条件相合**（不是持牌事实确认，更非因果确认）。本次模拟以 "blind"（未提前看结果）完成，完整性记录正常。

**B18 实体来源与知情处置**（三屏，结局分支）
1. 三件原物来源分开核：**人间存券**（1998 正殿东柜收取，警方受限保管）、**告山副券**（2026 北坡券龛原位发现）、**守牌**（1998 墙后生活层）；数字同页 ≠ 实体同处，阅读/OCR 不改变原物。
2. 两方案六项动作全部逐项预览；权限永远只是"**建议**"。
3. 提交 A 或 B（互斥），并勾选三项确认。

## 五、谜题设计点评

**亮点：**
1. **证据分级做得极较真**：几乎每个谜底的正确项都是"最窄结论"而非"最爽结论"。B03 排除"唯一行为人"但拒绝"无罪"；B07 承认底片但拒绝认脸；B17 让你算出窗口却强制用条件式——这种"克制感"是档案题材的灵魂。
2. **第九人的揭晓链条扎实**：匿名归一 → 口径回填 → 身份合取 → 行为边界，四个面板把"同一个人"和"他有罪"彻底解耦，这是多数悬疑游戏做不到的。
3. **假线索有闭环**：5 条支线不是红鲱鱼摆设，每条都给方法论（如"文件创建时间≠原件形成时间"），并在数据里埋了引诱错误答案的字段（1996 同名林文、论坛冰托说）。
4. **第四章的结构野心**：把"民俗规则"本身降格为待核对象（版本比较、墨层排序），最后连"专业检验是否民俗中性"都放进未决清单——结局不给答案，只给"条件相合"。
5. **无障碍/工程素质**：分级提示（4 级，直接答案需二次确认）、键盘可达、skip-link、打印样式、CSP 完全自包含离线、事件溯源存档带重放校验（损坏存档能截断恢复）。

**可改进：**
1. 26 个面板全是选择/勾选/排序，第三章连续 4 节（B11–B14）题型重复，节奏偏平；可考虑一题"自由输入编号"类变奏。
2. 回执门槛（读完回执才能继续）第一次出现时没有明示原因，容易误以为卡死（实测不是 bug）。
3. 支线入口藏在特定记录页的"沿页内参见继续核对"，容易漏（F03 的入口在一篇不起眼的游记里）。
4. B17 的"提前看过地质记录会降级为 seen_result"这个完整性设计很妙，但游戏内几乎不提示其存在，多数玩家不会意识到自己被"盲测"了。
5. 结局页"未决清单"很好，但 8 条未决项在游戏中的状态没有任何可视化汇总（进度页只有计数），通关后的"我到底核清了什么"全靠记忆。

**结论**：这是一个罕见的"把考据方法本身做成玩法"的中文档案谜案原型。谜底自洽、双结局完整、可玩性验证通过。推荐给喜欢《奥伯拉丁的回归》式推理的玩家；它的难度不在谜面，而在"忍住不下超出证据的结论"。
