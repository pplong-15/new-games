# 《镇山契：第九位到访者》v3.3 中式民俗恐怖专业审查与 v3.4 修改清单

审核对象：`镇山契_第九位到访者_中式恐怖核心重构审核执行稿_v3_3.md`  
审核结论：**REWORK / HOLD_BUILD**  
综合判断：**6.8 / 10**  
适用对象：主创、编剧、叙事设计、网页开发、QA

---

## 一、总评

v3.3 是一次实质进步。玩家终于不再只是阅读一段民俗说明，而是在完成正常档案工作时，逐渐发现自己的职业操作与旧手续发生结构重合。这是正确的恐怖方向。

但当前仍不建议进入网页开发。最核心的问题不是“不够吓人”，而是：

> 现稿设计出了一套会被档案系统条件触发的异常规则，却还没有设计出一种真正由地方社会长期维持、后来被人歪曲利用的民俗秩序。

因此现在的“归匣成契”更像 SCP 式异常状态机，而不像中国乡土社会中会真实存在的契约、轮值、祭祀与禁忌。

v3.4 不应继续堆阴森措辞、仪式名词或神秘文件，而应先把以下三个底层问题锁死：

1. 这究竟是谁与谁立的契，为什么要立；
2. 原本的地方制度如何运作，又怎样被掌权者篡改；
3. 玩家执行的现代操作，为什么会与旧制度发生真实而非作者强行安排的重合。

## 二、应保留的正确设计

以下内容方向正确，不应因本轮重构而推翻：

- 打开网页、阅读、搜索、摘录、OCR、人物身份纠错均不会触发仪式；
- 玩家必须在知情之后，才执行最后具有现实效力的职业动作；
- 三名儿童先作为三个独立的人恢复姓名、生活与身份，不先被称作“三童”或“祭品”；
- 地质链足以自然解释滑坡，但自然机制成立不等于超自然被证明不存在；
- “日期吻合”与“因果成立”严格分离；
- 两种归档方案在职业上都必须合理，不设置好结局、坏结局；
- 不使用鬼脸、血字、屏幕故障、真实倒计时或“你已成为守山人”等廉价惊吓；
- U1 的身份、门闩行为、守位相容性与三名死者的死亡责任继续分开判断。

这些是 v3.3 最有价值的底盘。

## 三、P0：开发前必须重构的问题

### P0-1：目前还称不上真正的“契”

当前“契”的核心是：

```text
四件＋同函＋末校＋押尾＋三日＋接收
```

这是一组程序条件，不是一份民间契约。

真正具有契约感的宗教或民俗文书，通常会模拟现实契约的社会结构：立约双方、所涉土地或事项、边界、义务、见证、中人、日期、实物凭证与失约后果。买地券、合同券等材料的效力也与合券、分持、埋置、画押等物质行为相关，而不只是满足几个抽象字段。参考：[北京市文物局对古代买地券结构的介绍](https://wwj.beijing.gov.cn/bjww/362760/362770/21243077/index.html)。

v3.4 必须先建立以下民俗本体：

| 项目 | 必须回答的问题 |
|---|---|
| 立约者 | 槐北三社、三户灯首、村族，还是祠堂香会？ |
| 受约者 | 北坡山场、后土、山主还是某位祠神？只能选一套地方信仰口径 |
| 所守对象 | 坡脚排水、山场边界、祠庙还是某个镇物？ |
| 村社义务 | 谁供灯油、饭食、守更人和维修材料？ |
| 守者义务 | 听水、巡沟、报险、守灯，具体做什么？ |
| 见证者 | 香首、中人、山场管事、三户户主分别承担什么角色？ |
| 交接物 | 守更牌、契券、钥匙、灯册或更牌，至少要有一个可传递实物 |
| 失约征候 | “北坡开”是神罚、预兆，还是旧人对地裂的经验性说法？ |

在这张表没有完成前，不要继续润色“归匣成契”的文案。

### P0-2：历史仪式与现代触发条件其实是两套东西

历史层是：

```text
三童执灯／镇基＋一人守夜／守山
```

现代层却是：

```text
四份纸件＋正式组包＋质检席位＋末校＋三日移交
```

现代条件里没有灯、儿童、位置或真实守夜，玩家实际上重演的是另一套程序。现稿只是让两套程序使用了相似词语，没有证明它们属于同一民俗结构。

#### 推荐统一方案：村社“轮灯守更契”

原始制度可以这样建立：

- 三户轮流承担灯油与守坡义务；
- 三名孩子只在入夜时引灯过门，随后各自回家；
- 一名成年人留下守更，观察排水沟、渗水、落石声与坡体异响；
- 守更牌、灯册和契券在约定夜数后交给下一户；
- 村里按户供粮、供油，免除守更户第二天部分劳役。

1970年以后，掌权者把它歪改为：

```text
引灯过门 → 镇灯脚／镇基
轮流守更 → 守山不得离
交牌换手 → 旧守不能离位
```

这样，“儿童、守者、山坡、契券、换手”才属于同一社会制度。真正的恐怖也会从“古老邪术”升级为：

> 原本用于共同防灾的互助规则，被掌权者改造成让弱者永远不能离开的制度。

这才是有中国乡土社会根基的恐怖。

### P0-3：开场其实已经近似满足“重成”

现稿中：

- 四件湿损材料已经进入同一个 `WT-26-04`；
- `QC-447` 已经是临时保管席位。

严谨玩家必然会问：

> 四件已经同盘，也已经有人保管，为什么08:40不算“重成”，17:20才算？

旧材料没有提供“临时同盘不算、正式组合包才算”的案前规则，只有作者合同在解释。

#### 推荐修改

把 `WT-26-04` 改成：

> 水损待核任务清单。四件原件仍分别置于四个隔离套及原保管单元，系统只建立同批次引用，不形成共同实体保管单元。

直到玩家完成以下动作时，才第一次出现新的共同单元：

1. 比对旧铅笔号；
2. 比对订孔；
3. 拼合骑缝章或合同印；
4. 生成正式组合目录；
5. 由有权限的经办人签署移交清单。

同时必须修正两点：

- “四件”只能说明1970年这一包恰有四件，不应直接升级为所有旧契的普遍铁律；
- “押尾”目前没有可靠案前出处，要么删除，要么补真实尾签、画押或合缝痕迹。

### P0-4：“三日”算法冲突，精确时间过于人为

现稿同时出现：

- 先看三日；
- 三日内有人接；
- 六月二十至六月二十三；
- 三个自然日；
- 精确72小时；
- 1998与2026都恰好72小时15分。

这些不是同一种计时规则。“三个自然日”也不等于从17:20到三天后17:20。

而且传统口述中的“三日”常存在起算日、过夜数和昼夜计算差异。精确到分钟复刻两次，不像民俗，更像作者设计的数字机关。

#### 推荐修改

只保留“第三夜”或“压三宿”这一口径：

> 压过三宿，鸡叫前有人换手，才算交清。

现代制度中删除“固定三个自然日”。让普通现实原因导致第三夜仍无人接收，例如：

- 周末受限库房不开；
- 暴雨交通管制，主管未到；
- 受限卷必须双人同时签收；
- 下一班接收人临时参加抢险。

1998和2026只需落在同一个“第三夜窗口”，不要都精确到72小时15分。

时间证据还应收窄为：

```text
U1离开记录与北坡首次报送记录之间的间隔吻合。
```

不能写成：

```text
坡体恰在该分钟开始移动。
```

2026监测时间同样只能是“本轮首次记录异常的时间”。

### P0-5：玩家职业权限仍为仪式服务

目前 `QC-447` 同时承担：

- 选择著录方案；
- 重组实体纸件；
- 最后校核；
- 实物保管；
- 关闭保全盘；
- 发起并完成移交。

现实档案工作中，著录、质检、验收、实体保管和移交是不同动作。建立资料关联也不等于把纸质原件重新装成一包。参考：[DA/T 18—2022《档案著录规则》](https://www.saac.gov.cn/daj/hybz/202206/beb7ba0f09ee4742ad4bb93bce2504b0.shtml)。

#### 推荐角色

玩家改为：

> 槐县公安局—县档案馆历史专卷联合复核项目的“著录复核经办员”。两种处置方案均已获得项目负责人书面预授权。

权限拆分：

| 动作 | 执行者 |
|---|---|
| 派生目录末校 | 玩家本人 |
| 生成组合或有界参见建议 | 玩家本人 |
| 实体移动 | 档案保管员 |
| 最终接收 | 另一名责任人带时间签名 |
| 审核处置 | 项目负责人 |

`QC-447` 只能是操作账号，不能被文书或民俗暗中当成一个真实的“守者”。

### P0-6：1968年代身份与语言不可信

1966—1976年间，正规的民俗采集和民间文学整理曾大面积停顿。1968年出现一份正常、公开、专业的“地方采风抄本”，必须有特殊来源解释。参考：[中国民俗学会关于相关历史阶段的回顾](https://www.chinesefolklore.org.cn/web/index.php?NewsID=2811)。

可选修改：

1. 改为1964年采风原稿；
2. 1968年只是某人从更早笔记中私下誊写的抢救抄本；
3. 材料夹在“四旧清理登记”或生产队旧物清点册中，被人暗中保存。

现有语言也混用了现代编辑术语和生造民俗词：

| 现有词 | 建议替换 |
|---|---|
| 三灯一更 | 三户轮灯、一人守更 |
| 方形更位 | 更桌、守更凳、夜更位 |
| 末校 | 点收、核过、末后点字 |
| 押尾 | 画押、尾签、合缝 |
| 移交 | 交手、换手、接牌 |
| 归匣成契 | 仅作作者后台名；世界内用“合券”或“重成一函” |

不同年代材料必须使用不同语域，不能共同复述终局算法。

#### 可直接使用的材料工作稿

1968残注：

> 散纸照旧次合回一函，末后点过的先替着看。

1970普通清单：

```text
旧页四张，共穿一线。
周×点过。
六月二十收，廿三交。
接手：____
```

1986口述整理：

> 老人只说要压过三宿，换了手才算交清。到底从哪一夜算，整理人当时没再问。

三份材料应互相补足，而不是三次重复答案。

### P0-7：三名儿童仍被作为仪式拼图使用

B08先恢复三个人的身份是正确的，但B10又要求玩家把“三条身份结果与三个工程区叠合”。这仍然让玩家亲手把三个孩子放回“三灯位”。

#### 必须分离

- B08完成三人的身份恢复、生活材料展示和正式提交；
- B10只使用匿名发掘单元 `HR-01/02/03`；
- 仪式图上不得出现儿童姓名、头像或生活材料；
- 比较完成后，另页说明发掘单元已有身份关联；
- 任何 `DER-CHILD-*` 不得改变 `riteState`。

另外，如果三处遗骸与三处灯位达到精确的一一重合，玩家必然会推断这是仪式化安置。此时不能仅靠结论表写“仪式动机未决”来消除暗示。

必须二选一：

1. 确认最窄命题：遗骸安置具有人工、重复的空间排列，但死亡原因和安置动机未决；
2. 把第三处改成部分重合或边界外，使“三童镇基”保持高度相容，而非几何实锤。

## 四、P1：不阻断逻辑，但会削弱中式恐怖的问题

### P1-1：民俗缺少普通人的生活生态

现在主要是抄本、契文、交割笺和规则比较，缺少“人为什么照做”。

建议补入70%非神秘材料：

- 三户轮流支领灯油；
- 守更人领取饭食或免第二天劳役；
- 某户欠了一轮油；
- 更牌丢失后补做；
- 雨夜排水沟堵塞；
- 村民抱怨“守一夜又不给工分”；
- 祠堂漏雨、灯罩更换、守更凳维修；
- 老人记得的是“谁家轮到守”，而不是完整咒语。

民俗越像一种普通社会制度，后来被人利用时越恐怖。

### P1-2：地域仍是通用中式恐怖拼盘

“槐县、南岭、西南民俗网、山神庙”还没有形成独特地方文化。

必须锁定虚构地区的生态与生产方式，例如：

- 南方丘陵汉族村落；
- 多雨、页岩坡、梯田或林场；
- 祠堂兼作雨夜守坡和物资存放点；
- 地方称谓、作物、运输方式与房屋材料保持一致。

不要把不同地区、不同民族的仪式符号随意混用。

### P1-3：恐怖进入太晚

前八个Beat基本是法证工作，到B09才进入民俗章，容易产生“换了一个游戏”的感觉。

应在前段只埋物质痕迹，不提前解释：

- B01：卷袋边缘出现被拆开的合同印；
- B03：阿山材料中出现旧守更牌的编号，但不解释用途；
- B05：普通守夜簿恰好采用“过槛者入正页”的计人规则；
- B06：隐藏室有长期灯烟和守更凳磨痕；
- B07：粮油支领记录显示某个“守更位”多年没有轮换。

玩家先觉得这些只是地方行政习惯，后面才意识到它们属于同一套秩序。

### P1-4：B12像答案表，不像推理

按“前置条件／四件／同函／末校／三日／移交”填六栏，会把恐惧变成Excel验收。

更好的操作是：

1. 玩家拖动四页，拼合订孔和骑缝章；
2. 用放大镜发现纸边的半枚“合同”印；
3. 将1970清单的空白接收栏与现代待签收栏并置；
4. 系统只显示客观差异，不总结“仪式成立”；
5. 玩家自行意识到自己正处在空白接收栏的上一格。

恐怖应发生在玩家看懂表格的瞬间，而不是系统弹出“结构相似”。

### P1-5：两种结局的心理重量不平衡

“有界参见”明显更像：玩家离开共同保管后，北坡发生位移。组合著录分支则只有“接收人空白”，力量较弱。

修法：

- 两个分支看到完全相同的监测记录、时间、哈希和正文；
- 系统不替有界分支计算“你离开后多少小时”；
- 组合分支第一视觉层保留“下一接收人仍空白”；
- 有界分支只显示共同单元关闭时间；
- 不用危险色、警告音或按钮措辞提示哪一项是坏选择。

### P1-6：“旧守已缺”和“交守失败”越过证据边界

U1离开不等于：

- U1就是守者；
- 守位一定中断；
- 1998至2026无人继任。

状态应改为：

```text
前一守位是否成立：compatible_only
守位是否在1998年中断：compatible_only
1998年后有无继任：unresolved
```

现实项目可确认：

```text
项目移交：逾计划时间15分钟，尚无接收签名
```

民俗层只能写：

```text
是否构成“交守”：unresolved
```

不能把现实签收字段直接等同于民俗规则有效。

### P1-7：结尾未决命题太多，情绪会被QA报告冲掉

完整命题可以留在内部报告，但玩家结尾首屏只保留五组：

1. 三名死者的责任；
2. 三名儿童的死亡原因与动机；
3. U1与守位；
4. 旧契及现代手续是否具有效力；
5. 滑坡的自然机制与超自然因果。

允许展开查看详细证据，不要首屏列二十余项状态。

## 五、推荐的 v3.4 核心命题

建议把故事核心改写为：

> 玩家发现，所谓“镇山契”原本是一套村社共同承担的雨夜守坡制度：三户轮灯，一人守更，按期交牌。后来，掌权者把“引灯过门”改成“镇基”，把“轮流守更”改成“守山不得离”，将共同防灾的规则变成了控制弱者的工具。几十年后，现代档案流程又在不知情中复现了它的合券与责任交接结构。

这个版本的恐怖有三层：

1. **生活层**：它曾是普通人对抗山洪、滑坡的互助制度；
2. **权力层**：有人篡改字词，使公共责任变成对弱者的终身禁锢；
3. **余味层**：现代制度与旧手续再次重合，但网页永远无法证明那究竟只是结构巧合，还是某种仍在等待接手的秩序。

这比“古老规则能识别数据库字段”更真实，也更具有中式恐怖的伦理重量。

## 六、推荐的材料分工

不同来源只负责证明一部分，不得每份都复述答案：

| 材料 | 只负责提供什么 |
|---|---|
| 1964/1968抢救抄本 | 原始轮灯守更习俗、散页照旧次合回 |
| 1970修缮清单 | 该次确有四页、编号、订孔、合缝章、空白接收栏 |
| 1970改本 | 字词如何被覆盖和替换 |
| 1986口述 | “压三宿、换了手才算交清”，但起算方法不明 |
| 1998卷宗 | U1离开与北坡首次报送的日期关系 |
| 2026制度 | 正常的复核、建议、保管与签收流程，不含任何民俗解释 |
| 2026监测 | 普通、自然可解释的坡体位移记录 |

核心原则：**材料彼此不完全同声，玩家必须自己拼合结构。**

## 七、建议采用的状态合同

不要使用一个简单布尔条件：

```text
four && samePacket && finalCheck && threeDays && receiver
```

建议分离现实档案状态与民俗解释状态：

```text
archive.packetRelation
  = unjoined
  | historically_same_packet
  | composite_record_created

archive.finalReview
  = not_started
  | signed_by_operator

archive.projectTransfer
  = not_due
  | due
  | accepted
  | overdue_unsigned

folk.previousGuard
  = compatible_only

folk.currentGuardVacancy
  = unresolved

folk.modernReconstitution
  = unresolved

folk.modernHandover
  = unresolved
```

现实字段可以确定，民俗含义不能由现实字段自动派生。

## 十、最终裁决

v3.3 已经证明这条方向值得继续，但尚未达到可开发状态。它的问题不是需要再补几句古雅文案，而是“契约本体、历史制度和现代触发”尚未成为同一套因果。

完成本报告七项P0修改后，项目才可能达到以下目标：

> 玩家在进行完全正常、职业上可信的工作时，亲手重组了一套曾经属于村社生活的责任关系；他无法证明旧契仍有效，却发现自己已经站在那个迟迟无人签收的位置上。

这是本作真正应该追求的中式恐怖落点。
