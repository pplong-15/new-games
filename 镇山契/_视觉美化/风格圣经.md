# 镇山契风格圣经 · VP1 · 2D 真网页

北星能力句：玩家在屏上用眼睛完成「判断这是五家停更站点中的哪一家、以及此刻是工作台 / 未命中 / 禁页 / 已保存」，不靠文案解释。

## 相机与比例

- 正交文档。无透视、无视差、无 Canvas 粒子。
- 工作台全宽石板桌；五站用栏宽差当身份：980 / 1120 / 780 / 1180 / 1200。
- 角色:道具比 N/A。

## 线宽

- 论坛桅底 4px；档案身份底 6px；民俗双线 5px；旧报金条 8px；地质 1px 钢边。
- 未命中虚线井 3px；禁页双线 4px；保存厚左边 8px。
- focus-visible 3px，outline-offset 3px。

## 主材质

系统字体栈 + CSS 斜边/双线/纸纹。禁止照片底、禁止真实 Logo。证据图只用既有原创内联 SVG。

## 三色锚

| 角色 | 色 | 用途 |
|---|---|---|
| 主 | `#37474f` | 工作台顶栏与保存框，不出现在五站桅 |
| 次 | 按所有者（见合同 palette_by_owner） | 只有该站能用该桅色 |
| 功能 | `#17333a` | 键盘焦点；保存用勾形；禁页用「禁止/BAN」戳 |

强调色绑功能，不绑情绪。

## 五站可指认（至少三项）

1. 论坛：980 · Tahoma · 蓝斜边钮 · 深蓝导航
2. 档案：1120 · SimSun 字距 · 青绿目录条
3. 民俗：780 · 纸黄 + 双线楣 · 居中下划线文字导航
4. 旧报：1180 · 宋体大字 · 酒红桅 + 金条
5. 地质：1200 · Arial/YaHei · 钢青代码块

## 工作台限色

只用石板灰家族。禁止抄若依 `#1890ff`。禁止把五站桅色铺到工作台。

## 状态（不唯色）

- 未命中：虚线井 + 「0」方印 + 半圆缺口
- 禁页：45° 斜纹 + 「!」+ 「禁止」或 `BAN` 戳
- 已保存：左边 8px + 「✓」方框
- 表单错：双线棕框，不是只变红字
- 待取回执：虚线横纹条
