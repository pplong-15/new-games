# GATE_B　开发验收

## 数据与路由

本局是仿真手机，不是搜词引擎。来源即 HTML 页，token 靠打开页写入 `localStorage`（`gys_seen0314` / `gys_seen0812` / `gys_seenmemo` / `gys_seencalls` / `gys_seencal` / `gys_seenlocker`）。后仓口信不按「第几步」开门，未见两张也能交，正文随 flags 变。已读日历或隔板照时多一句理由，不弹未打开。

## DAG

按 `PLAY.md` 拓扑：纸条 PIN → 桌面 → 短信（含店群早线）/ 两张白底 / 隔板与黄纸 / 五则备忘 / 通话详单 / 通讯录名片 / 日历 / 设置与拦网 / 闹钟 并行 → 后仓四选。无环。PIN 来自引言，不是悬空。暗线（取底、矿上、列车失败）不挡主线。四口信键仍是 `end-return / end-new / end-old / end-off`。

## 可点性

- 锁屏数字盘，3716 进桌面，错码有系统句。
- 桌面九图标：信息、图库、备忘、电话、通讯录、日历、设置、浏览器、闹钟。
- 米棠/方镜名片从通讯录进入；米棠已接从通话列表进入详单。
- 图库六张：两白底、隔板、黄纸、货道、秤。
- 备忘五则可读，柜门反光插入「下」链。
- 后仓四链各进一口信页，可回到纸条。

未做站内搜索（对标禁止）。无 `approve`，只有口信。

## 语法

入口与机壳为静态 HTML + 短脚本。浏览器实点一条主线后记入 PLAYTEST。
