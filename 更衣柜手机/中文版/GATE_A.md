# GATE_A　故事层七维

验收对象：`STORY.md`（2026-08-21 本局）。本闸只验故事，不写 HTML。

## 1. 人物立住

PASS。沈梭是夜班经办，怕多事；卜田穗在货单里漏私事；匡守业只要能过检的脸；米棠重复家里规矩；方镜只谈底片日期。换掉名字腔还在，不是扁平「失踪同事/严经理」。

## 2. 台词像真人

PASS（文本层）。设计声口：匡短催、米棠带嘞爱重复、方镜谈钱和日期、容婶哎哟、韦渡省字、穗的备忘改口。屏幕文案按此写，不在本闸代写 HTML。

## 3. 剧情顺

PASS。三月办证 → 七月丧期放镜 → 八月店逼换证 → 十二日补拍 → 十八至二十日短信拧紧 → 二十日凌晨通话后机子留柜 → 二十一日夜班沈梭被要求回口信。匡与米棠不是突然对立，是店规和丧期同时压在同一个人身上。

## 4. 恐怖类型成立

PASS。信息层：两张白底日期对不上，店认的「人」和家里认的「人」裂开。不靠照妖、遗容、偷拍。反派不是单纯恶人——匡要过检，米棠要守月内规矩，穗两边都想顾。

## 5. 线索可闭环

PASS。工号开锁；方镜给出三月十四/八月十二；相册拍摄时间对上；备忘回收「哪张印过、哪张后来贴」；通话回收最后开口时间。多结局各有触发。容婶马甲、韦渡矿上是干扰/暗线，不挡主线。

## 6. 设定可单列、故事够厚

PASS。
- 第2段有起承转合、沈梭弧光、两处抉择、四个口信。
- 关系网：穗—匡（工/证）、穗—米棠（丧/照面）、穗—方镜（两底片），沈梭被塞进命名。三角互锁，不是单向失踪。
- 反转两层：先信人跑了机子落了 → 她还在谈换证 → 更深是「在」取决于认哪张脸。
- 暗线：有人来取三月底片；韦渡要她别续证。

## 7. 可英文化

PASS。核对照的是日期、底片用途、谁有权把脸交给店，不靠拆字谐音。术语表已随 STORY 交付。无功能谐音梗。

## 结论

整体 **PASS**，可进玩法与开发。

开发期红线：
- 必须让玩家亲手对照两张白底的日期，不能用旁白替他宣布「哪张是假的」。
- 「人还在不在」必须保持双义，结局只表态，不改成侦探公布凶手。
- 不写照妖实操、遗容、偷拍；不出现禁用人名；不把芮秋写进来。
- 屏幕不出现机制词与「本游戏」。
